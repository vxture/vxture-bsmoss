# 来源配置变更预检

2026-11-06，接续255／998。用户授权继续配置管理建设。

## 本批范围

来源配置当前详情内增加只读“变更预检”，历史审计页无入口。可拟调整登记active／paused、适配版本、转换版本、UTC整点覆盖起点、站址／服务／设备／指标清单与物理参数标志；配置ID／来源ID／租户固定由已授权当前定义派生，浏览器不能传入或替换。来源身份替换需另建受审绑定，本批不提供原地转移来源。登记revision必须numeric(30)字符串精确加1，expected固定原revision和binding摘要；旧基线变化409，只有版本加1而配置没有实质变化拒绝。

输入字段严格白名单；四维列表去重前即拒绝重复、规范排序，不接受通配／控制字符／空站址／空指标。UTC起点要求完整canonical毫秒整点，真实日期且无year 0000，不把覆盖起点等同已接收或分析更新时间。指标以现存code@version核对目录登记，不据此宣称来源能力激活。依据引用与原件SHA-256仅用户声明，未验真、不假批准人，不拉取用户URL。

## 读取授权及关联

独立admin.sources.preflight，不继承来源查看／审计／映射预检／ingest／owner；交互会话与平台订阅门先于业务解析，机器拒绝。完整原scope SQL过滤后读取head；原新scope五维及物理参数都必须完全在当前授权内，不能以共同地域偏好代授权，不能仅任意重叠可见。配置来源仍唯一且固定。

同一只读可重复读事务：当前head＋摘要核验、原新授权、旧基线、拟资源引用／关联和目录、捕获时间。所有资源查询在拟范围完全验权后，station以workspace／已提交ID查，service／device还按拟station限定；不返回不符关联的真实归属站址，仅报告用户已提交标识未满足条件。metric_version全局目录按完整code@version精确匹配。未知资源／未登记指标／错误父关联是阻断项，检查通过仍“仍需复核”。不查询隐藏历史绑定／任务／回执，也不枚举无权关联。

读完重新resolve主体／工作空间／权限／完整scope及有效期，成功、missing、stale、SQL错误均最终复核再返回或抛错；撤权优先屏蔽记录存在性。SQL错误不成为空态或成功预检。

## 接收位置与下游语义

SourcePosition绑定完整SourceBinding摘要，revision也是摘要的一部分；任何新修订（包括只改登记状态）均不能直接继承旧接收位置。结果固定requires_reviewed_rebaseline，提示需受审重新基准，不凭本批读取断言已经有回执或任务。existingReceipts／existingTasks为not_assessed；拟暂停不等于远端请求已停止，拟启用不等于可恢复接收。适配兼容未验证、来源指标能力未评估，聚合／报告影响未评估，不能计0、自动失效旧报告、终止任务或推进截至。覆盖起点变动也不等于可直接重拉历史。

结果前后对比、四维新增／移除清单、物理参数变化、具体资源问题、待复核事项和草案摘要。摘要绑定租户／当前revision+摘要+status／提案及新binding，既不是签章也不是未来写入授权凭证。后续受审写入需可信提交／批准契约与完整写事务并发重验。
