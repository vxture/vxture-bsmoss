# 正式报告异步HTML导出

接续设计209／210。导出对象为明确的活跃发布事件及其不可变报告快照；新生成版本、来源变化、撤回或替换发布均不能通过旧文件继续冒充当前结果。

## 任务与执行

请求只包含reportId、publicationRevision、commandId，当前主体及完整scope由可信组合根提供。reports.export为显式权限；生成、发布和owner权限不隐含导出。服务器绑定报告修订／SHA与固定rendererVersion，同租户命令幂等且绑定请求主体。重复请求不复活撤回任务，不切换到新发布版本。

任务持久化后由内部单步执行器处理，reports.export.execute为独立显式权限。执行器只接受明确jobId，不先全库抢任务再检查范围。当前机器身份与平台权益、完整历史scope在工作前后重新核验；不保存用户令牌，也不伪造生产机器身份。真实provider及常驻调度仍需后续接线。

HTML为有界纯计算，没有事务外网络／文件写。单个数据库事务以FOR UPDATE SKIP LOCKED持有任务，SAVEPOINT包含可信发布读取、渲染、制品、成功回执及状态；连接中断整事务回滚，任务仍pending，不存在悬挂租约。失败先回滚工作，再追加固定分类失败回执及数据库时钟退避（5／10／20／40秒），最多5次；过期／撤回／超界为terminal。身份／权限／scope故障及序列化冲突全回滚，不能当作普通渲染失败消耗任务。未来事务外渲染需另加租约，不能沿用此锁模型。

report_series增加由发布触发器维护的current_publication_revision及精确FK，运行角色不能更新该列。发布、撤回、导出请求与执行锁同一series；RR中等待之后若发布已变化，行版本冲突会回滚，不能按旧事件生成已撤回制品。

## 制品与下载

最多2MiB自包含HTML，不发网络请求、不运行脚本。三类章节、原生精确值与单位、比率分子分母、状态时长、温度口径、逐日依赖及原证据均保留；配置隐藏面板仍可展开查证，不抹缺数。所有来源／标题文本按HTML转义，证据保留为文本而非外链。超界明确失败，不截断证据。制品保留rendererVersion、内容SHA、操作者和数据库时间，运行角色只追加。

公开本批只提供授权任务状态和HTML下载GET。每次下载独立重查当前身份／权益／reports.export、完整原报告scope、精确活跃发布与当前新鲜度；重新渲染并核验制品SHA，状态或内容不匹配拒绝。历史成功制品可保留审计，但撤回、替换或数据过期后不可通过下载接口取得。无公开文件地址、对象存储签名URL或样例回退。响应no-store／nosniff／Vary Cookie／CSP sandbox及attachment文件名。

读判断以一个RR快照为准；撤回提交后开始的下载拒绝，已经交付的离线副本无法回收，并发中的既有快照不承诺追溯撤销。该边界不等于可绕过下一次下载验权。

实际PG核验命令／租户隔离、完整范围及两端撤权、双连接抢占和连接回滚、失败退避／终止、制品与回执原子、发布替换／撤回／旧RR、超安全整数与三类证据、SQL列权限／外键／内容SHA；HTTP验证匿名和演示不能下载正式制品。正式命令／页面、真实机器身份与常驻任务仍待，不以本地导出测试替代Beta或正式上线。
