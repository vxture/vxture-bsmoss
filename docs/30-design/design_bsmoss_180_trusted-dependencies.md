# 可信依赖指标输入规划

2026-11-02。I08内部聚合入口扩展，承接首批字典中的总流量与接通率；实际来源仍须D05/I06核验。

## 计算与选择

上行字节＋下行字节推导双向总流量；接通次数／尝试次数推导接通率。每个原生时间窗必须同时具备两个合法、已验证的依赖，才能计入该窗。比率汇总原始分子、分母，不平均百分比。

来源能力的已审阅`intervalAggregation`策略选择`direct`或`dependencies`，请求不提供该参数。总流量只能依赖推导；接通率可使用直接比率分项或依赖次数，必须明确二选一，不同时计入。依赖顺序、指标版本、对象和单位由产品字典定义，不由来源样例猜测。

目标与每个依赖均要求完整周期内唯一、active、已核验的来源能力。依赖能力须为direct，原生频率与目标一致。混合频率不自动插值或分摊计数；来源版本跨界、缺失或歧义拒绝。后续支持混合频率须另行设计适用窗口与无重叠证明。

## 权限和快照

先检查平台能力、产品aggregate权限及有限数据范围，再读取授权站址／服务的有效映射。目标和两个依赖必须全部位于metricKeys授权清单，拥有结果指标权限不能取得依赖原值。只有输入规划通过才读取测量事实。

同一REPEATABLE READ事务读取目标与依赖能力、指标定义、有效映射、最新事实／质量和完成证明。事实先按来源／事件／组件／指标取最高修订，再按对象和时间取交集；修订移出原窗口时撤回旧值，不回退旧事实。一次请求总输入上限100000，超限拒绝，不能分别截取各指标前一批。

## 证据与完成

原始输入保留各自指标代码、版本、事件／质量修订、映射和摘要。权威摘要额外绑定两个依赖的能力ID、核验引用、策略、有效期与频率；任一依赖权威变化均使旧完成确认失效。

同一映射下，可以使用目标指标的完整快照完成证明：证明须明确覆盖两个依赖的同一输入指纹，而不是拿某个依赖的确认冒充目标确认。没有目标确认时保持preliminary；依赖缺数／质量未通过时保持partial或missing，正式value为空，knownValue只列成对完整窗口的已知量。

现有source_completion仅表达一个映射。多映射组合仍不能复用单段确认；组合完成证明另行实现。本文未增加可自签完成的API，也未向工作进程授予来源证明写权。
