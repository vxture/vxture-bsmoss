# 受审跨对象区间汇总

本批承接 I08／I11，提供正式只读汇总数据链路。仅覆盖经营服务计数、总流量、接通率、PRB 利用率与物理站级电耗。设备状态分布和温度不进入求和，本批不关闭整个 I08。

## 权威配置

新增 `bsmoss_integration.object_rollup_revision` 空库基线表。配置由受审管理路径追加，运行角色只能读；修订严格连续、同一编号并发串行，禁止改删／截断。数据库绑定 JSONB 原文 SHA、session_user 和记录时间。它们是数据库留痕，不是业务审批签名。`review_ref` 和逐成员 `coverageRef` 必须指向实际计量口径审阅资料；本地测试仅使用 fixture 引用。

最新修订决定 active／paused，不回退旧 active。配置包含指标、有效期、有限原子覆盖总体（最多 256 个）、选定来源映射（最多 64 个）及审阅时的 authorityVersion。业务原子为同租户实际 cell（站址＋服务＋小区），物理电耗原子为站址。不能同时把父网络对象和子小区列为原子。总表可以通过明确审阅的覆盖清单覆盖同站同服务的多个小区；分表各覆盖自己的小区。选定成员的原子覆盖必须不重叠，跨来源同原子也互斥；留空的预期原子明确缺覆盖，不能根据现有事实倒推总体。

站级电耗不带服务、网络对象或设备，不产生运营商分摊。业务原子和实际映射必须同站同服务；总表不能跨服务代算。PRB 和接通率要求一致的分母依据：配置 `basis={kind,ref}` 与每个目标能力的 `intervalAggregation.objectBasis` 完全一致；PRB 仅接受 `prb_capacity_time`，接通率仅接受 `voice_attempts`。依据必须由来源提供并审阅，不能用任意百分比冒充分子分母。

配置跨有效期边界的周期暂拒绝，权威 generation 变化使当前审阅过期，改回旧值也不能复活。新审阅须追加修订。未知配置字段拒绝。

## 一致读取与授权

请求仅 `rollupId/grain/at`。RP 身份、权益、metering.view 和有限 scope 均由已有生产组合根构造；读取前后重新验权，不接受请求传入成员／值／租户／scope。全部预期原子及全部选定成员必须授权，不静默裁剪。

一个 REPEATABLE READ READ ONLY 事务读取最新配置、完整真实归属、各成员可信当前快照和已发布结果。抽取原单对象查询事务内核心，避免各成员独立开事务。只读快照不取配置写锁；返回精确修订与摘要，期间新配置只在下一次查询可见。结果代表此快照，不宣称查询返回后不发生变化。

读取器只合并实际发布结果，不临时发布、不回退演示。配置权威过期、当前来源不可用、未发布、发布过旧分别留痕，均不贡献可信小计。数据库故障和授权错误不能被吞成缺数。已发布但部分／未确认的可信窗口仅进入 knownValue；只有总体覆盖齐全且每个适用成员 complete 才提供完整 value。全部不适用与缺数分开。零分母保留为 0/0 证据，总分母为零时无比率。大整数按 BigInt 加和输出字符串；比例先合分子分母，禁止平均百分比。

输出配置精确修订／原文和语义摘要、成员发布 seriesId／revision／输入指纹／当前指纹／权威依据、缺覆盖／未发布／失效原因、水位、完整性，以及去重的物理站数和独立服务数。这不是全省忙时算法，不把各站各自峰值相加。

## 验证与边界

以实际 PostgreSQL 验证运行权限、修订串行、总分表互斥、跨来源去重、同租户／完整范围、真实归属、未发布与部分值、权威变更恢复、统一 RR 快照、发布失效、物理电耗归属、比率权重和末次撤权。纯规则另验证超安全整数、零分母和非可加指标。

无旧库迁移、真实接入、部署或生产审批。正式面板、持久报告／导出、常驻机器调度及容量验收继续推进。
