# 登记分区下的输入变化消费

2026-11-03。接续206，将登记配置、输入发现、历史影响、任务、失效、成功回执及异常控制放入同一事务。目标是为正式worker提供可靠内部入口，尚无真实机器身份或常驻进程。

## 权威配置与范围

抽取共享配置读取器：锁当前head、读取精确修订、核验JSONB摘要并规范化。周期扫描与变化消费复用同一读取器。入口只接受分区id和必要的事件／恢复选择器，不接收调用者policy、scope、主体或种子。

登记subject必须匹配当前可信身份，配置的完整有限scope必须是当前grant子集；父grant扩大或撤回未使用的范围不改变该登记订阅。所有历史旧新对象仍须在登记scope中，跨分区修订不能只处理有权的一半；须另行审阅覆盖全部旧新对象的分区配置，不默默并集或扩大授权。

订阅摘要加入分区id、精确配置修订、原始配置SHA和规范语义SHA。同scope／policy的不同分区、不同修订及无登记内部调用都有独立消费和退避进度。配置恢复为新修订，重放全部有关已提交变化；旧回执／失败／隔离不被删除或篡改。

## 原子工作单元

抽取既有输入消费、恢复及发现的事务内核心。外层唯一RR事务持有登记head共享锁，消费核心不自行COMMIT或伪造pool。单步入口在同事务发现最多64事件并监督一个可用事件；直接指定事件入口同样核验当前配置、全历史范围和真实证据。

任务／发布失效／成功回执与配置绑定原子；失败先回滚工作SAVEPOINT，再以同配置追加退避／隔离事件。回执、失败和恢复记录保存可空分区id／修订并用同租户FK引用配置。未登记旧内部调用保持原摘要、空指针和原有行为，不复制两套消费器。

成功、重放、延迟、隔离、发现和恢复返回前重新解身份、权益、权限与完整登记scope；授权失效不写消费或失败。配置暂停／修改等待在途事务释放共享锁；取锁前已变化head使旧RR快照回滚。暂停不取消已排队任务，任务执行仍须当前实际授权。

## 验收与边界

实测不同分区／配置修订隔离、周期与变化共享配置、测量／质量／完成／权威路径、全历史范围、故障原子性、持久退避隔离恢复、晚提交、并发同事件fence、配置暂停竞态及最终撤权。空库仍41表，仅扩展两张既有证据表的可空配置指针及约束；Prisma标量同步，无旧库迁移。
