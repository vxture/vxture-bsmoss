# 观澜产品顶栏

用户要求参考 yucer，使用现成 vxture Design 的完整面板与操作组。本包仅完善门户顶栏及其配置入口；地图保持独立工作台。

## 组件与信息结构

- Launcher 采用 yucer 的 Popover＋ShellPanelContent／Section／Row 组合。站网监管、分析与报告、运行管理三栏；只有真实已建路由，当前页高亮。桌面按栏展示，窄屏纵排，宽高受弹层实际可用空间约束；真实链接保留新标签打开能力，选中即关闭。
- 产品 SVG 标识以观测点、环形视野与波纹表达“观澜”。品牌图形色值仅在 SVG 内，不建立应用配色或覆盖 DS token。标识、观澜、BS-MOSS＋描述组成两块，无竖线；手机隐藏英文副块以保留操作空间。
- 右侧沿 yucer：官方 ShellHeaderTools 的帮助、消息抽屉、配置入口，以及 ShellUserMenu。帮助沿用平台 docs.vxture.com；配置进入 /settings。消息尚无真实通道，不显示虚构未读数量，提供任务工作台入口。
- 头像面板复用 ShellPreferencePanel：简体中文、浅／深／系统主题、紧凑／标准／宽松密度、小／标准／大字号。偏好由官方 provider 持久化，不自建存储。

## 身份与配置边界

服务器只投影真实 active RP 会话的名称、头像、账户识别行及组织工作区名称。访客无在线点、无认证标，不伪造演示管理员。真实登录后才展示切换账户与原生 POST 登出；账户中心只使用已配置 HTTPS console URL。没有角色或 token 进入顶栏。

/settings 的外观偏好公开可用。业务配置只链接既有指标模板与两个任务工作台，各目标继续独立执行正式权限检查；本次未新增授权接口或后台配置能力。
