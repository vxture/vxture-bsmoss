# 对象映射有效期变更预检

2026-11-06，接续254／997。用户授权继续配置管理建设。

## 本批定位

先交付现有对象映射的有效期只读预检。来源配置变更、聚合报告与接收任务的实际影响枚举分后续批次继续，不把此批称为完整影响评估或治理闭环。source_mapping数据库权威固定来源、外部类型／标识和站址／服务／网络／设备关联身份；这些字段不允许原地改关联。拟变更仅有效期，版本按本批产品预检策略严格加一（不是宣称数据库已有强制递增约束），numeric(30)字符串保真。

## 输入与依据

固定expected的版本与六位UTC微秒起止，拟新版本／起止、依据引用和原件SHA-256。未知字段／范围／审批主体拒绝；区间左闭右开、起止必须有效且递增、原新区间相同拒绝、旧版本或有效期变化返回409。依据引用和摘要仅用户声明，不读取原件、不验真、不代表批准；不保存浏览器或配置库。草案摘要绑定本次读取的完整定义与提案，不是签章、批准或未来写入凭证。

已有身份固定约束保护现有ID，不把客户端旧版本条件当未来写入的完整并发协议。后续正式提交必须加入租户、authority修订／证据摘要和服务关联基线，并在写事务重新验证，预检结果绝不能直接授权提交。

## 授权及数据库

独立admin.mappings.preflight，无自动角色赋权；现有查看权限、来源权限、ingest、owner无绕过，机器拒绝。scope五维及物理参数规则与现有映射同源。交互会话和平台门先于业务解析；只读可重复读事务中读取当前定义、核验旧基线和查询冲突，所有SQL绑定租户及完整关联范围。末次重新核对主体／租户／权限／完整scope和过期，成功、missing、stale及SQL错误都执行，避免撤权后通过错误泄露记录。

重叠仅查询授权可见同一source／external_type／external_id的其他ID，严格半开区间比较，不查询隐藏关联的存在、数量或标识。未发现可见重叠只代表授权范围内无重叠，全局始终未确认；结果只能是发现阻断项或仍需复核，不提供可发布／通过状态。服务有效期按精确微秒覆盖拟区间，未完整覆盖在本预检策略中阻断，不宣称原存储定义全无效。

时间覆盖差分精确展示扩展／移除区间；版本变化可能影响原新完整区间的依赖，差分不等于完整重算范围。aggregates／reports／intakeTasks固定not_assessed，不查无权任务／报告、不把未知记0、不使旧报告失效或自动重新基准。

## 界面和HTTP

在对象映射详情内增加可展开“变更预检”，复用官方DS Input／Button／StatusBadge及语义token。原始UTC输入显式标注格式保留微秒，不用精度较低日期控件静默截断。展示版本变化、前后区间、依据声明、重叠／服务覆盖、时间覆盖差分和未评估边界。不是新增空编辑／保存按钮。

POST /api/management/object-mappings/[id]/preflight，同源Origin、JSON、8192字节有界请求、无query、no-store／Cookie Vary／nosniff、同步200结果，不返回202假任务。GET／PUT／DELETE不可用。输入修改立即清结果、取消在途请求；关闭详情销毁草案，收起预检清结果，401／403清列表和Drawer，迟到响应不复活结果。正式身份未配置仍显示原门槛，不注入合成数据。

空库baseline仅一项permission种子、67表和Prisma不变，不改业务库。数据接收／更新留业务、不推进分析截至，无push／外部部署或上线。
