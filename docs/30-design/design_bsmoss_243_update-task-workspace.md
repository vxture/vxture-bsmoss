# 数据更新任务工作台

2026-11-06，接续设计241/242。P1本子批提供已接收证据任务的查询、恢复与页面内状态通知，真实上游连接与共同可用版本发布仍待。

## 入口与权限

工作台归属配置管理域 `/settings/operations/data-updates`，从配置导航、配置中心及业务更新面板的“任务记录”进入。业务launcher不增加运维模块。关闭OIDC时显示接入门槛，未登录引导登录；显式preview也不能借用正式身份或任务。任务创建继续由既有正式POST接口负责，本批没有新增来源选择或创建表单。

新增GET `/api/data-updates`，每页1–10条，以提交时间微秒精度与任务ID降序做不透明keyset分页。完整清单的来源、站址、服务、设备、指标及站级参数开关必须在SQL LIMIT前满足当前授权；校验清单摘要和全部必要scope后，再次验证平台身份、权益及job_view权限。只提供可见条目及下一游标，不提供隐藏任务总数。未知、重复参数和非法游标拒绝，响应no-store。

## 页面布局与恢复

复用发布DS的ShellPageContainer、PageHeading、PanelCard、Button、Input、StatusBadge和EmptyState，以及系统双层留白。宽屏任务列表与详情分栏，窄屏纵向排列，长任务ID和配置ID可换行；仅一个页面H1。

初始不默认选择任务。选择写入严格64位十六进制 `?task=`，重开、刷新及浏览器返回重新查询服务端状态。URL只保存任务ID，不保存授权、任务清单或恢复命令；不使用localStorage保存敏感载荷。列表与详情错误分别显示，查询失败不能冒充空列表或完成，失权清空旧详情及旧状态通知。

活动详情在可见页每10秒查询，隐藏暂停，重新可见复查；单次请求15秒超时，离页中止浏览器请求而不取消worker。processed、配置变更或读失败后停止定时查询，支持人工重新核对。阶段或数量来自实际已提交回执与job，绝不以时间制造百分比、ETA或worker在线判断。

## 恢复与通知边界

输入隔离可填写复核依据并通过既有独立job_recover接口重开。网络/服务器结果不确定时，在当前挂载表单内保留完全相同命令，显式“使用原命令重试”；明确拒绝后锁定，需重新核对任务。关闭或刷新页面后先从服务端重读，不能声称未确认命令跨页面持久保存。服务端原修订CAS与原因引用幂等仍为最终保护。

结果失败跳既有聚合任务工作台，并带精确job参数初始选择；该页自行验权和审阅恢复，不借输入恢复权限。配置已变化时隐藏输入重试并保留原配置记录。阶段变化通过本页aria-live状态提示，processed文案明确“增量处理已完成，数据可用版本仍以分析页为准”。没有全站消息中心、浏览器推送或后台通知承诺。

## 验证范围

使用独立loopback组件测试页运行实际工作台与DS，合成HTTP任务不接DB、真实身份、产品路由或worker。它只能验证页面交互，不替代实际平台授权与来源UAT。正式API另以实际PG角色和HTTP门槛验证。
