# 正式报告工作区与交互命令

接续209–211。演示地图保持原入口和布局；关闭演示时首页进入`/reports`。正式报告使用真实RP、平台注册状态、权益、本地权限与有限scope，不使用样例身份或回退数据。RP未配置显示未开放，未登录显示平台登录入口；无可见报告显示空态，不默认选中。

## 查询与分页

`GET /api/reports?limit=20&after=...`仅列当前生成修订元数据。limit为1–25，游标是严格base64url的北京时间周期起点对应UTC ISO与reportId，不携带授权。按period_start、id的C排序同时降序，用键集分页；不使用全局offset或总数。每次分页均以当前授权重新读取，新增或修订可能改变后续页，不承诺跨请求冻结目录。

在SQL中先对manifest.requiredScope的租户、来源、站址、服务、设备、全部指标和独立物理站参数开关过滤，再取limit+1。返回前校验完整manifest及SHA／模板／周期／scope，并再次核验返回和分页边界记录的必要scope并集。越权记录不占页、不暴露数量或正文；损坏记录和数据库故障不是空列表。

列表只有capturedCompleteness和freshness=unchecked，不宣称当前完整或已发布。详情沿既有GET读取原报告与实时失效理由；发布状态另读，可能与详情来自不同快照，操作事务仍为最终裁决。无发布事件的当前查询返回200 JSON null；明确eventRevision不存在仍404。null仅表示该快照没有事件，不证明报告存在；发布查询失败不能显示“未发布”或开放相应操作。

## 交互写入

| 路径 | 行为 | 权限 |
| --- | --- | --- |
| POST /api/reports | 按明确模板版本、周期内时间及expectedRevision生成 | reports.generate |
| POST /api/reports/{id}/publication | 精确报告修订／SHA、发布事件CAS、commandId及依据编号发布／撤回 | reports.publish |
| POST /api/report-exports | 针对明确发布事件请求导出，202返回持久任务 | reports.export |

POST统一要求有效RP入口条件、与配置appOrigin完全匹配的Origin、application/json（可带UTF-8字符集）、无query及最多16KiB实际流字节。不能从request URL、Host或转发头推导可信origin。纯规则拒绝未知字段／伪造scope，publication正文reportId必须与路径匹配。上下文CAS／数据不完整或过期返回409，要求重新核对；授权401/403、对象与范围404，其他服务故障503，内部异常不回显。所有响应no-store／nosniff／Vary Cookie。

HTTP只是边界，服务继续核验同主体／租户、平台权益、本地权限、有效期和完整历史scope，写入与末次再验权同事务。owner不隐含生成／发布／导出权限。执行导出仍是独立内部机器权限，本批不开放普通用户run接口。

## 页面交互

两块品牌“观澜”和“BS-MOSS／描述”无分隔线。左侧报告目录和可收起模板生成，右侧宽详情展示完整性、新鲜度、当前修订、水位、三类指标、逐日证据和原始精确值。沿用导出纯显示函数及BigInt转换，不在浏览器重复计量。隐藏面板可展开，不删缺数；未配置／未接入明确可见。

可按修订回看／切到最新。发布针对此处显示且最新完整可信的修订；撤回及导出明确针对当前活跃发布，可与正在回看的历史生成版本不同。依据编号必填。每个写操作保留不可变命令，响应不确定时提供同commandId重试；切换上下文／刷新后重新查询，不推断成功。禁用并发按钮，并用同步锁阻止重复提交；卸载中止客户端请求不等于回滚已提交服务端命令。

导出任务每5秒轮询，成功／终止／HTTP错误立即结束，最多60次；卸载取消请求与定时器。状态与downloadable独立，下载仍经过既有再次验权和内容核验接口，不展示公开制品地址。重新打开页面需要重新请求或通过任务ID查询；本批未提供全任务历史目录。

## 验收边界

实际PG验证完整scope过滤先于分页、相同周期稳定顺序、各范围及物理站参数开关、读后撤权、无关授权撤回、损坏及SQL故障。命令单测验证可信Origin、流限额、严格选择器、精确命令传递及私有错误。生产构建HTTP验证未配置／预览不能解锁正式读写。

授权页面交互使用独立localhost合成夹具服务器加载实际React组件，验证发布响应丢失后的同命令重试、撤回／重发、导出轮询和下载、桌面／窄屏。夹具只在忽略的tmp与artifacts，不增加任何正式路由身份后门，不代表真实RP或客户来源验收。登记报告调度、机器身份、常驻worker、真实环境Beta与上线门禁仍待。
