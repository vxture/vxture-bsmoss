# 授权周期聚合结果查询

2026-11-03。I11 首个正式数据读取切片，承接既有 I08 区间／比率／设备状态持久化。不替代正式面板、真实来源对账或 I12 报告发布。

## 请求与授权

GET /api/aggregates，仅接受 sourceId、mappingId、metricCode、metricVersion、grain、at 和可选 revision。metricVersion 为正安全整数，修订为最多30位正十进制字符串；禁止重复键、未知键及超过4096字符的参数。at 按 Asia/Shanghai 定位15分钟／小时／自然日／周／月周期。请求不含 workspace、身份、主体、角色、数值或授权范围。

入口从 RP opaque cookie 解析 C1 身份、C2 交互权益及本产品 metering.view 权限和有限 data_scope；不要求聚合写权。数据平面 bundled 覆盖不能成为交互查询授权。每次构造独立范围 reader，来源、指标、站址、服务和设备均沿可信快照规则验权；依赖派生指标同时要求依赖范围。历史修订也不得绕过当前授权。

数据库读取后再次解析身份／权益／产品权限，比较主体、workspace 及规范化完整scope并核对两次有效期。读取期间撤权、范围改变、过期或开通失效时丢弃结果。响应及错误均 no-store／nosniff／Vary: Cookie，无身份401、权限403，范围外或无记录404，依赖不可用503；不返回内部错误正文。

## 一致读取与修订

单次显式对象／周期使用一个 REPEATABLE READ READ ONLY 事务：由当前有效映射和核验能力读取最新事实、质量与完成证明，解析稳定主体，再读取同一主体的当前发布指针和选定修订。计算当前输入摘要用于比对，但不写结果、任务、outbox或任何回执，不在GET中隐式重算发布。

未持久发布或指定修订不存在返回404，不制造零值或正常状态。成功返回 seriesId、选定revision、currentRevision、发布者／时间、selection、freshness、当前输入摘要、原因和原样持久结果。整数／比率及状态时长继续用精确十进制字符串；部分、缺数、未知和未签认按原聚合结果保留。

revision为空读当前指针；显式指定时读取不可变历史。freshness=current只表示选中版本为当前指针且与本次可信输入摘要相同，不表示来源已complete。旧历史标记older_published_revision，输入／质量／映射／能力／完成证明或算法变化标记latest_input_or_authority_changed；任一存在即stale。旧结果仍显示原完整性，但消费者必须结合stale提示“等待重算”，不得将旧complete冒充最新签认。当前结果和现有来源无法核验时拒绝返回，不绕过核验去获取历史。

并发发布时整个读取快照保持旧事实与旧指针的一致组合，或后续请求读到新组合，不混合新head与旧输入。无自动签认、无写权限升级，也没有从样例库回退取值。

## 容量与后续

此入口只支持单个明确对象／周期；可信读取沿原10万输入上限等边界，摘要检查需要读取该对象的事实，不是全省列表接口或容量结论。尚无跨对象权威汇总、省市县正式分页总览、瞬时值结果读取、正式面板配置接线或异步报告导出。正式来源、机器身份／常驻调度、Beta及生产验收继续待办。
