# 数据时间与按需更新

2026-11-06，B03-04，用户已确认。系统定位为事后分析决策，不实时监控。本设计优先于页面上旧“快照/刷新”文案；其他语义问题排队。

## 时间与版本

标题区只显示一次“数据更新至”，值为当前分析已提交数据版本的共同可用截至。来源完整水位取所需来源最小值，最多到已闭合整点；缺来源/未确认不推测。窗口右端不包含，00:00表示前一日已经覆盖，不意味着当天全日。实际缺数、设备未采集与核验质量状态独立表达，不以来源库截至冒充全量测量完整。

“最近同步完成”是实际成功的任务完成时间，只在详情显示；没有记录就明确没有记录。“分析时点/区间”是用户选择，保留在内容操作行；不能把18点选择或本机当前整点当来源截至。例：14:08完成同步而数据完整至13:00，页面显示更新至13:00，详情显示完成14:08。同截至发生迟到/修订也形成新版本；仅重新读取或同步执行时间变化不构成数据修订。

站网日数据覆盖2026-10-25的24小时，整点边界2026-10-26 00:00。周期库与24月历史至2026-11-01 00:00，核验场景库独立，不能混同站网来源。总览混合三个来源，主水位取共同值，详情各列。预览水位由现有版本化能力常量推导，与电脑时间无关，无同步执行记录。

## 更新面板

时间详情及“更新数据”打开同一DS对话框：当前更新至、最近可更新至、更新范围、预计耗时与来源详情。打开时通过no-store只读接口重新检查来源能力，保留区域/运营商/站址/周期/原调查。无新增显示“已是最近可用数据”，不创建任务、不修改报告版本和截至；检查失败可重试，旧结果可继续使用。来源拓扑变化、回退或未知不得直接更新。无可用估算不编造数字。

第一子批实现上述规则、固定来源只读适配与八个页面接入：运行总览、站址管理、容量质量、运行能效、运营商用量、用量报告、经营分析、用量核验。档案证据时间、核验事件记录、固定报告文件时间不改成更新水位。地图/决策分析及正式数据查询将在后续统一，不因本批宣称全部收口。

## 后台更新目标与边界

第二子批接既有注册来源输入派发及refresh-jobs，不能另建浏览器队列或定时器模拟后台任务。来源完整窗口/水位、授权范围由服务端读取；权益、产品权限、workspace及每主体指标在创建和执行时重验。前端不提交可信水位/actor/workspace，不得匿名正式写。现队列结果聚合粒度为day/week/month，小时来源增量获取与可用水位编排仍需补齐，不以周期调度冒充小时更新。

获取新增与迟到/修订，按既有近72小时回补，更早修订定向重算；去重幂等、只重算受影响结果。按授权范围/来源/目标版本合并重复请求，任务离页继续；真实阶段、数量和有依据的耗时估算，不虚构百分比/倒计时。失败保留旧可用版本，实际失败原因可查且可重试。预览目前没有可追加上游批次，不启动任务；检测到新版本但未接执行器也不得显示成功。

第三子批接已提交新结果与通知：“数据已更新至… / 查看最新结果”，用户主动查看，原筛选及历史分析周期不跳回今天。固定报告绑定原版本；新结果另修订，week/month依赖修订与stale重算沿现有规则。跨域共同版本发布需原子可用，部分来源失败不将所有域当已更新。

第四子批盘点地图、决策分析及所有二级页，收敛剩余时间与动作；六场景验收后才关闭B03-04。正式来源授权/完整标记、运行worker、平台身份及任务编排尚未联调，不能把第一子批只读检查说成后台同步已交付。
