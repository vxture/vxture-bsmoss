# P1来源拉取契约与只读准备

2026-11-06，接续设计241–243。此批解决来源适配边界及可本地验证的拉取准备，不声称已接入真实来源、执行后台同步或发布可用版本。

## 分层与信任

integration新增内部SourceReadPort、SourceBinding、SourceHead、SourcePage及SourcePosition。它们是产品适配协议，不是某厂商接口，也不直接暴露给浏览器。可信组合根提供已审阅binding、持有凭据的适配器和将来持久化的输入位置；请求不提交actor、workspace、可信截至或授权范围。

binding绑定版本、单一来源、适配/转换版本、有限站址/服务/设备/指标范围及整点覆盖起点，规范化后计算指纹。已有位置必须匹配该指纹；配置变更不能默默继承旧游标。SourcePosition只是将来持久接收的位置，不能代替来源完整证明或分析可用版本。

prepareSourceUpdate通过现有data plane ingest授权；来源接触前、读取后、逐页及返回前重新解析平台权益、主体和完整所需范围。当前机器身份仍无ingest，不扩大ACL、不借worker身份。本批没有生产组合根、网络适配器、路由或写入路径。

## 拉取和分页

适配器提供可重复读取的snapshotId、数据修订、可接收截至及历史变化游标，窗口扫描与变化流必须固定在同一个来源快照。来源截至未知、未来、回退、字段或来源不匹配均拒绝。目标只取已闭合整点，来源原声明留在head，不能用服务器时间制造数据时间。

增量起点为上次持久接收截至向前72小时，最早到binding覆盖起点；终点是来源已闭合整点。首次拉取从显式覆盖起点开始。新增跨度超过31天需后续审阅bootstrap计划，本批拒绝而不截断后确认最终游标。年度历史是独立批量导入问题，本限额不限制已有经营分析的12个月查询。

历史变化流从旧changeCursor读取到本次固定changesThrough，必须同时包含超出72小时的首次迟到和修订。没有旧游标的首次窗口拉取不能声称已追踪历史变化。相同截至但修订或变化游标改变仍拉取；只有截至、修订、变化游标均相同才免读数据页。源适配器须保证这些字段覆盖对应数据/声明变化，并在真实联调时验证游标可恢复和保留期限。

每页绑定planId、snapshotId与请求after；拒绝快照漂移、空页续传、游标环。单页最多200条/1MiB，共最多64页、4096条/8MiB，单次调用10秒且支持取消；超限整体失败。限额是内部保护边界，不是耗时估算。真实适配器还须在响应反序列化前限制传输字节，并实现自己的连接/读取截止；通用层不能替代协议层的资源限制。

## 原量与证据

使用既有测量规范校验指标、整数/比率/定点/状态、时段、摘要和修订；绑定source、station、metric、transform及窗口。超窗历史数据仅可来自固定变化流，且不得早于覆盖起点或超过拉取目标。来源不能提供quality、decidedBy或workspace。所有准备测量的本地质量均为pending，后续通过既有受控质量流程审阅。

同一来源/event/revision/metric/component重复值合并；同键内容冲突整体失败。不同修订全部保留，不只留下最新值；记录排序后计算内容摘要，分页顺序不影响摘要。设备/服务的有效映射仍须在最终现有PG append事务中验证，准备阶段不批准映射或声称已入库。

来源completionClaim只有声明引用、摘要和时间的结构校验，返回名为unverifiedCompletionClaim；未验证签名/授权真实性，未绑定本地快照指纹，不写source_completion。确认、撤销都不自动批准质量，不改变分析截至。

## 执行边界与后续

成功结果只返回prepared/current、applied=false、publishesAvailability=false及有界原量清单；没有写入、创建任务、更新游标、最近成功同步时间或完成百分比。任意页失败/撤权/取消返回错误，无部分成功回执；调用方可从原持久位置重新准备同一计划，实际适配器快照过期须明确重启。

下一批需受控持久接收器：绑定配置复核、原量/回执/游标的一致提交、失败恢复，再连接现有派发任务。不得直接以此只读准备结果推进来源完成账本或分析可用版本。真实激活依赖D05来源授权与字段样例、原件保存与签认协议、稳定快照/变化游标契约、服务ingest权限审阅、凭据及环境。P1/B03-04继续in_progress。
