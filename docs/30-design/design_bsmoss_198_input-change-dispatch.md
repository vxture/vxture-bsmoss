# 测量与质量变化的持久传播

2026-11-02。承接195／196／197，接通持久事实到刷新队列的内部链路。不是常驻生产调度或实际来源接入。

## 事务变化记录

新增bsmoss_metering.input_change。measurement与quality_decision的AFTER INSERT触发器在原事务追加变化指针；测量和初始质量各有独立变化，后续质量修订也有独立变化。冲突重放没有实际INSERT，不新增变化；任一捕获失败使原载荷、测量与质量整体回滚。变化引用原测量及质量修订的同租户外键，不能先确认不存在的证据。

捕获函数由空库初始化所有者创建，SECURITY DEFINER、固定pg_catalog search_path、限定两张源表并完全限定目标表；PUBLIC无执行权限。运行角色只有变化表SELECT，不能直接伪造、修改或删除变化。运行角色没有主数据／来源能力审批写权。

## 输出订阅与范围

服务器提供有限输出指标与自然日／周／月配置，每订阅最多16个输出，不能提供身份或授权范围。每次发现／消费都重新解析data访问面的平台能力、aggregate权限和有限scope。订阅摘要绑定产品传播版本、规范化的完整有限scope、输出指标版本和粒度，列表顺序不影响摘要。相同范围的多个合法worker共享消费回执；范围／输出／粒度变更产生另一订阅，旧回执不能把新增范围或新增输出标成已消费。

这是内部服务器契约，尚无已登记的生产订阅表、机器账号或配置入口。正式组合根必须从受控配置提供订阅，不能将HTTP参数直接传入。

## 从持久证据解析影响

服务只接受changeId，不接受客户端传来的旧／新对象或影响时间。读取变化所指事实，再取同workspace／来源／事件／分量／指标的所有不可变事实修订，包含乱序到达或已经有更高修订的情况。旧与新映射、站址、服务、设备全部须在当前授权内；任一范围不足整体拒绝，不部分确认。历史最多1000条，单批最多64目标，超限不截断或确认；后续需要登记分区或持久分页，不能手动删证据绕过。

区间计数和比率按各修订实际半开区间规划，不受72小时回看限制。按字典反向依赖找配置输出，例如上行变化触发上行及总流量；目标与依赖仍经可信快照验权、验核验能力和有效期。接通率若来源核验策略为direct，则呼叫次数变化不影响该直接比率，合法零任务回执保留输出配置和原证据；不能将未知、缺失或含糊的能力当作可跳过输出。

状态事件即使TTL很短或质量pending，也可能在失效后继续阻断更早心跳。影响结束取max(原事件结束,事件开始+产品最大保持24小时)，并限制在其映射有效期内；允许保守多算窗口，不能漏掉失效后的unknown时段。具体结果仍由目标周期核验保持策略计算，不把24小时当真实有效期。相同映射／指标／窗口先去重，相同稳定对象的映射别名在可信快照解析后再次合并。

## 原子消费与并发

input_refresh_receipt以workspace／changeId／订阅摘要唯一，保存不可变消费清单及摘要：变化种类／事实／质量版本、完整历史范围、目标、job ID与队列清单摘要。消费在一个REPEATABLE READ事务里读取证据、验证所有目标、全批入队和写回执；入队或回执故障、授权过期全部回滚。回执证明任务已持久入队，不表示聚合已成功或来源已确认。任务执行继续走原租约／CAS／结果outbox／执行回执事务。

同事件／订阅通过事务级try advisory lock竞争，忙时返回busy，不确认。崩溃释放锁，回执缺失的变化可重试；并发提交导致序列化／唯一冲突时重试整个消费调用。重复消费先重新检查授权与历史对象，再校验已有清单摘要并返回同一回执，不新增任务。

## 不使用全局高水位

发现器按当前范围和配置输入指标读取最多64个未有本订阅回执的变化，没有时间或自增ID消费高水位。较早事务晚于新事务提交时，旧事件仍可发现；不能用max(id)或max(created_at)跳过它。当前没有持久退避／隔离队列；持续失败的旧事件可能占满发现页，正式worker需要失败分类、退避与可观测处理，不能将该有界发现器称完整调度服务。
