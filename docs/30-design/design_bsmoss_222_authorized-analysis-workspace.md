# 正式分析工作台与个人配置

I11新增/analysis及/api/analysis，实际RP身份／权益／metering.view和有限scope沿正式链路；演示不授予访问。固定服务端template_selection.scope_key=analysis:default选择page模板，不接受客户端模板代码、来源、映射、租户或主体。模板采用analysis-template-v1，最多16面板，复用字典Panel及aggregate／rollup／not_connected绑定，支持15分钟／小时／日／周／月。模板发布和默认切换仍由受审管理路径负责，不开放任意HTTP模板编辑或变更来源权威。

每次查询一份REPEATABLE READ快照读取模板、本人偏好和全部面板。真实指标和必要依赖／来源／站址／服务／设备／物理参数范围先验证；未授权面板不返回标题、绑定或值。隐藏面板仍需授权但不读时序，返回安全可配置目录。未接入和授权后无结果、权威不可用、缺数、真实零、过期与SQL故障分别表示；未知故障整体503，不能吞成missing。不同指标不汇总成总用量，比例不平均，物理电耗不分摊。

个人配置仅visible/order/displayUnit/grain/precision，复用既有合法语义校验，不改指标、绑定、公式、范围或正式报告。已撤权历史偏好不复活面板；模板换版偏好隔离，重置追加空偏好版本。user_preference按租户／可信subject／模板版本追加；CAS expectedRevision与唯一commandId，精确历史命令重放返回原回执，不回退head。保存前后验本人身份、权限、有效期和实际可配置对象scope，写后撤权全回滚；同命令不确定结果可重试。数据库捕获JSON SHA和session_user并禁止改删清空，无旧库迁移。

工作台三类章节、北京时间周期选择、紧凑卡片、状态分布／温度语义、可展开精确证据。趋势／表格组件按最近7个自然周期读取；卡片一周期，时序按真实自然边界且不跨1992业务日历下限。每个时间点保留自己的完整性／水位／修订／新鲜度，不连线跨过未知值；近似图形与精确表格分开，原始整数不转浮点。返回整体授权所需scope并集，末次真实授权复查后才交付。

正式导航连接分析／报告／任务，根入口正式模式进入分析，陕西地图演示保持既有独立开关和无默认选站。空态／未配置／过期登录／失败均无合成回退。浏览器合成QA仅验证实际React交互，不当作平台注册／客户UAT。
