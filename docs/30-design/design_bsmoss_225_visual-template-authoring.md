# 受审模板可视化编辑

接续设计224，补齐 I11 的页面／报告模板表单编辑；角色和工作区层级配置继续独立待办。

## 操作与边界

读取明确编码的版本后，编辑标题、指标、显示组件、单位、粒度、精度、显隐及顺序；可添加／移除面板，最多16个且至少1个。编码和版本仍由读取上下文控制，不在面板中修改身份或授权。面板保持稳定ID，排序同步为连续顺序；指标改换时主动清除旧对象绑定为“未接入”，要求重新指定，避免把另一种指标误绑旧对象。

对象绑定明确区分单对象聚合（来源ID／映射ID）、受审区域汇总（配置ID）、未接入。对象字段由管理员输入，表单不编造来源、映射或接入能力，不查询测量值。未接入只是模板配置状态，不生成样例测量或证明真实来源已验收。

报告只支持日／周／月，改变报告周期同步所有面板；页面允许每个面板独立选合法粒度。状态指标的卡片／时间线只支持状态单位，设备数或时长使用表格。单位和显示组件来自既有字典及规则，不开放自定义指标、公式、租户、权限、费用或执行控制。

## 单一草稿和失效控制

表单和高级 JSON 共用同一份内存草稿；每次表单编辑、重排、新建、删减或 JSON 修改均清除旧校验摘要、候选和操作回执。JSON 不满足可编辑结构时保留原文、显示修复提示，不将错误配置静默替换为默认草稿。未知字段不在转换时丢弃。

新建草稿仅在该编码已读取且无版本时提供页面／报告选择，默认三类各一块、全部未接入。已有编码保留种类。新建和可视化编辑本身不持久化、不发布、不切换默认、不生成报告；继续通过既有服务端校验、审阅依据、独立发布／选择权限和精确 CAS 命令。503保留原命令，409要求重读；编辑控件在请求／不确定命令期间锁定。

浏览器辅助规则只保证表单结构和联动，不代替服务端规范化、真实对象归属／完整范围、配置修订摘要及末次授权。隐藏面板仍在模板内并接受同样验证。既有已发布模板和报告快照不变。

## 验证与交付

使用纯转换测试验证稳定ID、不可变输入、报告粒度联动、指标变更清绑定、状态单位／组件联动、16面板及1面板边界、非法 JSON 原文保留。实际 React 组件验证表单与 JSON 同步、编辑失效旧校验、503原命令重试和桌面／窄屏可读。无数据库结构／Prisma／依赖变化，不重复已验证且未改的数据库合同。

保持陕西演示、新产品空库、费用预留、退役P2。此包只推进正式配置体验；真实来源、平台注册、生产环境、容量恢复演练、业务验收与生产批准仍是上线条件。
