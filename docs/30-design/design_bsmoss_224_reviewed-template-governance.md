# 管理员模板发布与默认版本治理

状态：页面／报告模板的有限管理出口已实现；角色／工作区层级发布仍待。接续设计150与222，不把个人显示偏好当管理员权限，不修改陕西演示地图。

## 配置与校验

草稿在管理页面编辑，通过只读配置校验后，显式提交审阅依据并发布不可变版本。支持既有 analysis-template-v1 页面和 periodic-report-template-v1 报告，最多16面板；不增加自定义指标、公式、阈值、租户或数据范围字段。服务端规范化面板／绑定顺序，逐项验证字典类别、单位、粒度、显示组件与固定绑定。

校验读取同一个 RR 中的真实映射、小区／服务／设备归属和最新受审 rollup 配置。隐藏面板同样验权；设备总体包括未覆盖设备，站级电耗必须独立站级参数权限。引用的映射完整配置、真实服务／网络／设备归属和 rollup 配置修订形成摘要。返回 candidateSha256、validationSha256、必要范围和引用依据。发布、默认切换重新校验并核对摘要，不能使用配置修改前的校验结果。

这是配置和对象归属校验，不读取测量值或聚合发布，也不替代来源字段／单位／采样频率签认、来源能力验证、数据质量核对或真实来源验收。模板的后续查询仍经过原能力与周期适用性检查；有模板不等于有数据。草稿不持久化，刷新前未发布的编辑会丢失。

## 版本、选择和审计

发布命令绑定可信 subject、commandId、模板编码、expectedVersion、规范候选及双摘要、审阅依据。首次发布从1开始，同编码保持模板类别；后续须精确命中最新版本才能追加。发布只创建模板，不启用默认，不生成／发布任何报告，不变更登记任务。

默认选择目前仅 analysis:default，目标必须是明确版本与定义摘要的页面模板。命令带当前指针 revision／code／version／sha256 整体 CAS；初始没有指针时为 null，历史 owner 种子可有指针而尚无选择审计修订。切回旧版本也是一条新的连续选择事件，不删除新版本或历史事件。必要范围是新模板与被替换模板的并集，避免窄模板间接撤下无权管理的原内容。

精确命令重放返回原版本／原选择修订，同时独立返回当前版本／当前选择修订与 isCurrent，绝不把旧命令重新应用到当前指针。历史重放按照原命令当时的完整范围及当前权限验权，不借今天的无关模板范围扩大权限，也不因当前配置修订而改写原回执。相同 commandId 携带不同字段拒绝。

两个新追加表 template_publication、template_selection_event，空库基线共61表，Prisma只做标量镜像。应用摘要与数据库 JSONB 摘要独立保存，数据库捕获 session_user／时间。发布触发器创建对应版本，选择触发器更新指针，记录和实际变更同事务。SQL独立检查版本连续、精确指针、同租户引用及真实最小对象范围；应用进一步检查指标依赖、完整拓扑与最终平台授权。版本及审计禁改／删／清空，运行角色不能直接插入模板版本或写默认指针。

个人偏好保存改用窄只读 security-definer 共享锁函数，不再持有默认指针 UPDATE 权限。默认切换触发器取排他锁，与偏好保存串行。旧 RR 在指针被替换后会回滚并重新读取，不能把旧模板偏好写到新默认上。RR竞争有限重试，仅处理40001／40P01及明确版本／事件唯一键竞态；新的过期 CAS 不自动改为成功。重试仍使用原主体、范围和原始有效期，写后再检查 C1／C2／C3、本地独立权限与完整必要范围。

## 正式入口和权限

新增 views.templates.view、views.templates.publish、views.templates.select，仅入权限字典，不自动赋角色，workspace owner／metering.view／个人配置／报告权限均不隐含模板管理。

- GET /api/templates?code=…&version=…：读取明确版本，省略version读该编码最新；默认指针另列，必要范围重复校验。
- POST /api/templates/preview：只读配置校验，需要模板查看权限。
- POST /api/templates：追加版本，需要发布权限。
- POST /api/templates/selection：默认切换／回退，需要选择权限。
- /settings/templates：实际RP会话管理页；JSON草稿、中文三类指标预览、完整版本／发布主体／北京时间、审阅依据和原命令回执。

写入口复用配置 Origin、实际流16KiB、严格字段与私有响应头。409清除旧上下文要求重新读取；503／网络不确定时锁定表单，用完全相同命令重试。没有正式身份或数据库时不回退演示。源码只有ASCII，中文以转义保存。
