# 对象映射查询与关联核对

2026-11-06，接续来源配置与版本审计253。用户授权继续配置管理建设，沿官方DS导航／页面规范，入口尽量四字。

## 本批定位

来源配置的transformVersion只是转换适配契约中的版本标识，source_mapping才保存外部对象到站址／服务／网络对象／设备的具体关联及有效期。两种版本独立，不按同名字符串推断一致，也不凭来源登记范围推断所有对象映射可见。

本批在数据接入组补“对象映射”，读取正式现存定义，检索映射／来源／外部对象／站址名称与标识／服务／网络对象／设备，按目标类型筛选、keyset分页、详情。当前存储定义含过去及将来区间，不冒充历史变更审计；source_mapping不含审批主体，不能填假审批人。定义检索不涉及指标值，也不宣称指标兼容、来源完整或业务签认。

## 授权和查询

独立admin.mappings.view，不继承admin.sources.view、metering.ingest或owner权限，机器拒绝。正式RP与平台订阅门先于解析。SQL在LIMIT前同时过滤租户、来源、站址、关联服务和设备；无服务且无设备的物理站址映射要求allowSiteParameters。网络对象从已授权服务关系间接限定，关联复合站址和服务必须一致。指标不在映射表中，本批不伪造指标分配或兼容结果。

只读可重复读事务，逐条及lookahead严格验证对象关系、numeric字符串版本、UTC微秒区间。任一授权记录损坏则整页失败，不当空页。列表、空页、缺失详情都在返回前重验身份、权限、范围和有效期。接口只有GET、no-store／Cookie Vary／nosniff、安全404。无真实会话显示身份门槛，无合成记录回退。

## 业务呈现

列表以外部对象为主列，展示来源／外部类型、归属站址和关联目标、目标类型、映射版本、有效期及服务期覆盖情况。详情完整显示所有目标，设备同时关联服务时不隐藏服务。目标类型按设备、网络对象、服务、站址参数顺序取主分类，用于检索，不改变底层关系。

有效期是左闭右开区间；服务期必须覆盖整个映射区间才显示“完整覆盖”，微秒也参与比较。未覆盖是待核对事项，不把整个映射判无效，也不代表交集外服务用量可接收。无服务则显示“不涉及服务”。不显示额外页面刷新时间，不借系统当前时间假装分析截至。

复用DS ShellPageContainer、PageHeading、InputGroup内置搜索图标、NativeSelect、PanelCard、DataTable、StatusBadge、EmptyState、Drawer和Button；窄屏表格内部滚动，详情限制视口，所有长标识换行。切条件清旧详情，取消迟到请求，详情401／403清整页和Drawer。

本批交付可核验的读取与关联检查；来源配置／对象映射写入仍待业务审批契约，不新增空编辑按钮。下一批需固定变更前版本、拟变更内容、真实依据引用与原件摘要、提交主体和批准主体的可信来源、完整原范围与新范围授权、并发版本冲突、关联有效期与外部键重叠检查、聚合／报告失效影响及任务重新基准处理。先完成不落库的校验与影响预览，再设计独立写权限及可追踪提交；不得以机器人自签代替业务批准，连接测试也需真实适配器及受控凭据。
