# D06 显示配置契约 V1

状态：内部设计完成；未实现页面、持久化与身份入口。

## 模型与解析

TemplateVersion包含workspace、templateCode、version、draft/published/retired、panels、audit。
Panel稳定id，category，metricRef(code,version)，view，grain，displayUnit，precision，order，visible。
指标版本必须明确，不使用隐式latest；组件配置只接受白名单字段。
来源能力、数据范围与模板分别存储。模板不包含可自行扩大的workspace/operator范围。

先由可信服务解析身份与数据范围，再计算指标权限；按workspace默认→角色模板→页面模板
逐层以panelId合并。缺失字段继承，显式visible=false隐藏，未知panelId拒绝。
多个角色由已发布角色优先级排序，同优先级冲突拒绝发布，不依赖数组偶然顺序。
个人偏好仅能改变可见性、顺序、合法单位、粒度和精度；不可改metricRef、公式或授权。
正式报告忽略个人偏好，固定模板与字典版本；查询和导出重复执行范围权限。

## 验证顺序

结构与未知字段→版本存在与生命周期→类别一致→合法组件/单位/粒度→依赖无环→
来源能力匹配→当前权限裁剪→应用个人偏好→输出固定质量、新鲜度及口径提示。
权限不足指标从服务端移除；授权但未接入返回not_connected，缺数返回missing，
0为有效零值；错误返回failed，结果修订返回stale/preliminary等独立状态。
数据可用性不等于授权；缺少依赖时仅禁用对应组件并说明，不把整页误显示成无权限。

## 发布与场景检查

草稿→校验与脱敏预览→发布不可变版本→切换默认引用；回滚切换旧引用并审计。
个人重置只清个人偏好，指标隐藏不暂停采集。样例模式固定标签不可隐藏。

走查：经营角色显示通话/流量；网络角色显示接通率/PRB；运维角色显示电耗/设备状态。
共享设备状态需额外授权，运营商服务关系不自动授予全部物理参数。
非法单位（字节显示为kWh）、状态均值趋势、小时来源选择15分钟均拒绝。
撤销权限后旧收藏和导出下载仍拒绝；官方报告不因个人隐藏指标变化。
本地技术演示可使用明确标记的测试权限，但不声明生产身份适配完成。
