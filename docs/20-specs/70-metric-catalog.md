# 三类指标体系与展示配置 V0.3

2026-10-28。按用户定义固定三大业务类别：经营服务性数据、运营状态类数据、运行参数数据。
这是规划指标全集，并非全部已经接入。当前仍为周期性分析，费用仅预留。
本文件覆盖 V0.2 中将资源负荷、电耗等统一称作“用量辅助指标”的分类方式。

## 一、分类原则

| 类别代码 | 固定类别 | 回答的问题 | 常见对象 |
|---|---|---|---|
| business_service | 经营服务性数据 | 向运营商承载了多少业务、服务多少连接 | 运营商、服务关系、逻辑基站、小区 |
| operational_status | 运营状态类数据 | 服务质量、资源负荷、网络运行效果如何 | 小区、基站、链路、区域 |
| runtime_parameter | 运行参数数据 | 站址及设备在什么物理条件下运行 | 站址、电表、电源、蓄电池、机房、设备 |

类别是业务分析视角，不改变领域唯一写入归属。每个指标只有一个主类别，可有多个检索标签。
同一个量的派生指标可归入不同类别，例如经营类的接通次数与运营状态类的接通率。
网络服务可用率归运营状态，设备在线/掉电原始状态归运行参数。
CPU 利用率归运营状态，CPU 温度归运行参数；经营数据不等于费用数据。

下表为可扩展目录。指标组内各项须分别注册稳定 metricCode，不能把多个单位塞入同一数值字段。
每项接入状态为 planned / unmapped / mapped / validated / active / retired，展示能力据此计算。

## 二、经营服务性数据

| 指标组 | 候选指标 | 单位与口径重点 |
|---|---|---|
| 语音时长 | 主叫时长、被叫时长、已接通时长、VoLTE 时长、VoNR 时长、电路域时长 | 秒；主被叫可能重复，不能无条件相加 |
| 呼叫规模 | 呼叫尝试次数、接通次数、主叫次数、被叫次数、语音会话数 | 次；明确统计点与会话去重 |
| 话务量 | 平均承载话务量、忙时承载话务量 | Erlang；区分实际承载与提供话务量 |
| 数据流量 | 上行、下行、双向总流量 | 字节；同层统计，总量与分项不重复加总 |
| 分制式业务 | 4G/5G、NSA/SA 流量与会话量 | 字节/次；分项是否互斥由源口径确定 |
| 分业务流量 | 普通数据、物联网、专网、语音承载相关流量 | 字节；子集和重叠标识必须明确 |
| 数据会话 | 建立次数、完成次数、会话持续时长 | 次/秒；成功率另归运营状态 |
| 短信业务 | 发送尝试、发送成功、接收成功、发送失败 | 条；MO/MT 与结果维度独立 |
| 彩信业务 | 发送/接收次数、业务字节量 | 条/字节；仅在可归属站址时启用 |
| 活跃服务 | 活跃终端计数、活跃连接计数、物联网连接计数 | 计数；不是可跨站去重的用户人数 |
| 服务覆盖 | 有效运营商服务关系数、承载业务小区数、产生用量站址数 | 个；基于有效期与完整率判断 |
| 业务强度 | 每有效站日流量、每有效服务日通话时长、每连接平均流量 | 派生量；明确分母对象与时段 |
| 使用结构 | 主体占比、上下行占比、制式占比、业务类型占比 | %；同指标内计算、显示未归属部分 |
| 业务变化 | 周期增量、环比、同星期对比、日均变化 | 原单位/%；零基期无可用变化率 |

优先开通已接通通话时长、上下行字节、呼叫尝试/接通次数与短信量。
用户指标只采集授权的聚合计数，不以新增个人标识采集换取跨站去重能力。

## 三、运营状态类数据

| 指标组 | 候选指标 | 单位与口径重点 |
|---|---|---|
| 无线资源负荷 | 上/下行 PRB 利用率、资源拥塞时长、拥塞发生次数 | %/秒/次；加权汇总 |
| 载波与承载 | 载波负荷、承载占用率、信道占用率、业务承载建立成功率 | %；设备厂家口径需映射 |
| 连接负荷 | RRC 并发连接均值/峰值、连接容量利用率、连接拒绝次数 | 个/%/次；峰值不可跨时段求和 |
| 接入效果 | RRC 建立成功率、接入成功率、呼叫接通率、短信成功率 | %；保留分子、分母与版本 |
| 保持能力 | 掉话次数/率、会话异常释放率、掉线率 | 次/%；明确正常释放与异常释放 |
| 移动性 | 切换尝试/成功次数、切换成功率、切换失败率 | 次/%；同站/跨站/跨制式区分 |
| 数据性能 | 上/下行平均吞吐、P95 吞吐、低速时长 | bit/s/秒；均值按时间/业务量定义 |
| 传输质量 | 时延、抖动、丢包率、误码率、重传率 | ms/%；测量点和探测方式必须一致 |
| 无线质量 | RSRP、RSRQ、SINR、覆盖弱信号占比、干扰水平 | dBm/dB/%；不是可加用量 |
| 业务可用性 | 服务可用率、不可用时长、小区退服率、受影响服务关系数 | %/秒/个；计划停机是否扣除需明示 |
| 计算负荷 | CPU 利用率、内存利用率、磁盘占用率、处理队列深度 | %/个；对象为设备或服务实例 |
| 回传负荷 | 链路带宽利用率、端口丢弃率、链路拥塞时长 | %/秒；需要容量及方向 |
| 稳定性 | 服务中断次数、重复异常次数、平均恢复时长 | 次/秒；恢复时长需完整事件链 |
| 周期评价 | 高负荷窗口数、低效窗口数、忙时分布、连续异常时长 | 个/时间/秒；阈值版本化 |

接通率、负荷率等名称不能脱离分子分母与测量对象。不同厂家即使名称相同，也需验证后才能比较。
P95 不能通过平均站点 P95 或每日 P95 得到；需合并兼容分布或以明细重算。
信号强度不直接平均 dBm 并宣称区域覆盖改善，须在字典内定义抽样与聚合方法。

## 四、运行参数数据

| 指标组 | 候选指标 | 单位与口径重点 |
|---|---|---|
| 电耗 | 站址总电耗、设备/运营商分表电耗、空调电耗、整流电耗 | Wh；累计表计先转增量 |
| 功率 | 有功/无功/视在功率、峰值功率、功率因数 | W/var/VA/无量纲；定义符号和方向 |
| 市电 | 供电状态、电压、电流、频率、缺相、停电次数/时长 | 枚举/V/A/Hz/次/秒 |
| 直流与整流 | 母线电压、负载电流、模块状态、整流效率、模块温度 | V/A/枚举/%/℃ |
| 蓄电池 | 电池电压/电流/温度、SOC、SOH、内阻、充放电状态、循环次数 | V/A/℃/%/mΩ/枚举/次 |
| 备电能力 | 后备运行时长、估计剩余备电时长、低电压事件 | 秒/次；估算必须标模型与置信限制 |
| 备用发电 | 油机启停状态、运行时长、燃油液位/消耗、启动失败次数 | 枚举/秒/L/%/次 |
| 新能源 | 光伏发电量、逆变器状态、储能充放电量 | Wh/枚举；仅适用配备站址 |
| 环境 | 机房/机柜/室外温度、湿度、烟感、水浸、漏水 | ℃/%RH/枚举；标明传感器位置 |
| 空调散热 | 空调状态、设定温度、送回风温度、风机转速/故障 | 枚举/℃/rpm；只读采集，不含控制 |
| 设备状态 | 在线/离线、运行/故障、启动时刻、累计运行时长、重启次数 | 枚举/时间/秒/次；缺心跳不等同物理故障 |
| 链路与端口 | 物理链路 up/down、光功率、接口告警状态 | 枚举/dBm；利用率归运营状态 |
| 硬件健康 | 板卡、风扇、电源、存储健康状态、设备内部温度 | 枚举/℃；CPU 使用率另归运营状态 |
| 安防 | 门磁、非法开门、门禁事件、防盗状态 | 枚举/次；授权范围内接入，避免个人明细 |
| 防雷接地 | 防雷器状态、接地电阻、漏电告警 | 枚举/Ω；区分人工检测值与自动遥测 |
| 铁塔结构 | 倾角、振动、结构监测异常 | °/按传感器量纲/枚举；有合规传感器才接入 |
| 维护上下文 | 检修状态、传感器校准时间、设备更换事件 | 枚举/时间/事件；用于解释数据变化 |

共享站址指标不必具备运营商维度；仅独立设备或分表有明确归属时才拆分。
运营商账号查看共享物理信息需单独授权，不能由其站址服务关系自动继承全部设备参数访问权。
设备资产型号、额定容量、固件版本属于主数据/属性，可作筛选维度，不伪装成周期遥测指标。
设备状态按窗口统计各状态持续时长、转换次数与最后状态，不对状态枚举求平均。

## 五、跨类分析与数据质量

可分析：业务增长与资源拥塞是否同窗、负荷变化与电耗变化、温度与硬件异常、
供电中断与业务下降、用量偏低但持续高电耗等。只描述相关关系，不自动宣称因果。
不同来源应先对齐对象、有效时间窗和覆盖率；没有共同有效窗口不输出相关系数。

数据完整率、新鲜度、归属率、映射覆盖率、校验失败率属于横向“数据质量”元信息，
固定附着三类结果，不增设第四类业务指标。采集失败不能伪装成服务故障。

## 六、指标字典

每个指标需定义：

- metricCode、name、主类别、子组、说明、版本、生命周期、适用对象与制式。
- valueType（整数/定点数/布尔/枚举/事件）、canonicalUnit、展示单位及可转换范围。
- sourceSemantic（累计计数/区间增量/瞬时值/比率/状态/事件）、统计点和权威来源。
- allowedDimensions（站址、主体、服务关系、设备、小区、方向等）及缺失维度处理。
- 原生粒度、允许分析粒度、时间聚合与跨对象聚合规则分别定义。
- 分子/分母、权重、去重键、总分关系、依赖指标、派生公式及公式版本。
- 有效范围、质量校验、阈值策略、最低覆盖条件、迟到与修订策略。
- 数据敏感级别、操作权限与行范围策略；不能靠隐藏列完成隔离。

注册不等于可展示：必须具备已验证来源映射、授权、可用粒度和必要依赖。
派生指标使用受控表达式与白名单函数，检查单位与维度，不允许任意脚本；依赖图检测循环。
基础口径及公式由授权管理员版本化发布，普通用户只能改变展示。

## 七、显示配置

配置与采集开关、分析任务开关分离；隐藏指标不停止采集，也不删除历史。

| 配置层 | 内容 | 约束 |
|---|---|---|
| 指标目录 | 类别、子组、定义、可用单位、合法聚合 | 稳定主分类由产品管理；不能随页面改统计含义 |
| 来源能力 | 哪些来源支持哪些指标/对象/粒度 | 通过映射及样例校验才启用 |
| 工作空间模板 | 默认三类面板、分组、指标及报告布局 | 管理员发布，记录版本及变更人 |
| 角色模板 | 省级、地市、运营商、设备运维默认视图 | 仅裁剪默认展示，不授予额外权限 |
| 页面/报告模板 | 卡片、趋势、表格、排行、阈值与周期 | 明确每个组件的指标和聚合方法 |
| 个人偏好 | 显隐、顺序、收藏、列宽、合法单位及粒度 | 不能改原始值、公式、权限或官方报告口径 |

解析顺序：先计算当前身份的可访问指标与数据范围，再应用工作空间→角色→页面/报告模板，
最后应用个人偏好；未知配置键拒绝，失效或已退役指标标记不可用并提示替代项。
无权限指标从服务端返回中移除，不能仅在浏览器隐藏。

可配置项：三类页签显隐、子组、组件顺序、图表类型、单位、小数位、粒度、比较基期、
排行数量、列与排序、阈值线、报告章节、无数据展示方式。图表与粒度只能在指标允许范围中选。
系统应固定展示数据质量/新鲜度和结果状态，不能通过个人配置隐藏关键口径提示。

告警阈值、异常阈值与图表参考线是不同配置，修改参考线不改变异常判定。
显示用四舍五入不影响计算精度。% 必须说明存储比例还是百分数，℃ 的单位转换不得简单按比例计算。

默认模板建议：经营分析人员以通话/流量/短信为首页；网络运营人员以利用率、接通率、
保持率为首页；站址运维人员以电耗、供电、设备状态、环境为首页。
运营商只查看授权主体数据；铁塔全省视图按区域下钻，可选择三类指标联看。
正式周期报告绑定发布模板与指标版本，个人偏好不影响他人或历史报告；重算产生新结果版本。

## 八、配置模型示例（设计，尚未落库）

示例 metricCode 需先注册验证后才能使用。

    {
      "schemaVersion": 1,
      "templateCode": "tower-periodic-default",
      "templateVersion": 1,
      "panels": [
        { "category": "business_service", "metricCode": "service.data.downlink_bytes", "view": "trend", "grain": "hour", "displayUnit": "GiB" },
        { "category": "operational_status", "metricCode": "status.voice.connection_rate", "view": "trend", "grain": "day", "displayUnit": "%" },
        { "category": "runtime_parameter", "metricCode": "runtime.energy.site_wh", "view": "table", "grain": "day", "displayUnit": "kWh" }
      ]
    }

GiB=2^30 字节，GB=10^9 字节，不能混用。配置校验需检查类别、单位转换、指标依赖和数据权限。
模板先校验/预览再发布；已发布版本不可原位修改，回滚引用旧版本，不删除审计历史。

## 九、实施与验收

先实现可扩展字典、来源能力矩阵、三类配置模型与模板解析，再按来源分批落指标。
不通过扩展 UsageType 把状态、温度、比率都塞进秒/字节用量记录；需要独立测量模型。
物理增量与 Prisma 镜像在实现批次同时落地，本轮不新增数据库表或声明已有页面。

验收包括：三类归属唯一、同名异口径不可混算、非法单位/粒度/依赖被拒绝、
无权限指标不返回、共享设备参数不越权、个人显隐不影响计算与正式报告、
模板发布/回滚可审计、未接入与真实零值可区分、三类数据均可按来源能力生成周期报告。

## 十、瞬时温度实施边界（2026-11-03）

首批字典新增 runtime.environment.temperature_c@1，为第12个planned定义：运行参数、设备物理归属、degC定点精度、不可跨对象相加。样本均值与有明确窗口时长依据的时间加权均值分别记录，均值分子／分母和极值时间保留精度；未核验或缺采不补零。已完成可信快照、持久修订、来源完成／撤销、授权刷新与单对象查询，见设计203／实施390；不代表真实温度源接入、演示温度样本、环境参数面板或跨设备汇总已交付。

## 十一、运行总览合成读投影（2026-11-04）

实施770在显式预览开关下提供24项三类首页读投影及个人显示配置，使用已有站时／日历合成观测，不改变核心12项字典的planned生命周期。已有metricCode只引用原定义；资源负载不冒充真实PRB，站群计数／样本均值／单位流量电耗为明确的只读展示口径，不宣称真实来源接入。全日累计与18:00状态分开，昨日同站群比较；率差用百分点，物理量差用原单位，零基期／缺数／空范围不造百分比。

每类选择2–4项、顺序及合法单位，仅保存当前浏览器偏好，入口位于settings域。隐藏不改采集和统计，不影响报告模板／版本；失效配置提示并恢复默认显示，保存可修复。正式身份／来源能力／授权读模型和管理员模板仍沿用原服务，不从浏览器偏好取得权限。
