## 数据与计算约束

- 全部值由当前和真实基期快照读取。两年参考历史按需投影，不增加全量小时事实，也不修改用户已有快照或已存报告。
- 参考历史附带固定 assessment-policy-v1；其来源、阈值与有效期可追溯，仅适用于参考数据，不激活或改写工作区规则配置。正式来源仍要求已确认且冻结的适用规则。
- 待确认规则覆盖当前已投影的配置型依据和计量依据，与计量依据相同范围的待确认数量一致。缺接入的两项服务继续保留，不构造虚假冲突或总分表差额。
- 贡献百分点＝对象增减量／全范围基期总量×100。以整数最小单位计算，不使用净变化作分母；正向增量＋负向减量＝净变化。基期零时保留增减量，贡献不适用。
- 退出站址从基期保留，站址跳转使用确实存在该站址的快照。当前源中不属于当前物理站址范围的记录不计入当前贡献。
- 缺源、未知数量、口径不一致、期间不完整均不能补零或判定正常；修订差异明确区别于业务增长。
- 贡献分解不是因果认定。新增／退出、持续对象、天数与季节性等进一步解释在后续专题逐步补充。
