# 能力领域与对象归属

| 领域 | 目录 | 唯一写入对象 | 主要职责 |
|---|---|---|---|
| D1 站址资源 | station | 站址、行政区划、运营商服务关系 | 铁塔运营主体、陕西省/市/县、来源站址映射 |
| D2 数据接入 | integration | 来源、接入批次、原始证据、映射版本 | API/文件/消息适配、游标、重试、质量隔离 |
| D3 用量计量 | metering | 标准化用量、归属结果 | 按站址、运营商、类型和时间窗计量 |
| D4 运行监管 | supervision | 指标、告警、处置记录 | 在线状态、性能与质量异常、告警闭环 |
| D5 费用扩展（预留） | settlement | 未来合同、费率与账单 | 当前不实现、不启用 |
| D6 智能分析 | analysis | 分析任务、结论、建议、证据引用 | 周期报告、忙闲与趋势、用量异常解释 |

同一对象仅一个领域可写，其他领域只读引用。使用量与平台 C3 的产品商业用量是
两种对象，基站业务数据不得直接写进 local_usage 平台契约表。

运营商：telecom / unicom / mobile / broadcast / other。other 是已知的其他运营商，
null 才是未归属。正式接入时补充运营商实体编码，不能将多个“其他”结算主体混在一起。
