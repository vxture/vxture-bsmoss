# 观澜·站址多域运营监管

**BS-MOSS — Base Station Multi-domain Operation and Supervision System**

铁塔为建设与运营主体，服务电信、联通、移动、广电及其他运营商。产品立足全国，
地域架构支持未来全国扩展；当前客户产品及演示仅展示陕西省和省内地市、站址分析，不增加跨省入口。
陕西首批规模规划约 11 万个站址，该数量不是全国总量，也不能当成真实在线站点数或实测容量。
全国可扩展地域模型与陕西客户演示路线见 [地域架构与陕西演示](80-national-map-demo.md)。

当前产品主线：站址建档 → 数据对接与采集 → 质量校验与运营商归属 → 分类计量 →
分粒度聚合 → 日报/周报/月报 → 忙闲、趋势与异常解释。

产品定位为基于数据快照与周期统计的分析决策业务，不承担实时监控职责。运行总览采用明确的分析快照，日期与时点在页首集中呈现；各板块不重复显示同一时间。证据详情及周期报告保留其独立统计窗口。刷新重新读取来源快照，有效时间仅随来源版本变化，不由电脑时钟推进。

本阶段只分析周期用量，暂不分析费用。费用仅预留扩展，详见
[周期性用量分析 V0.2](60-periodic-usage-analysis.md)。

“多域”包括站址资源、来源系统、运营商服务、运行指标、用量计量、费用结算和分析证据。
不包含无人机、机器狗、现场机器人控制等业务。

站址是基础设施对象，不直接等同于运营商逻辑基站、小区或设备；后续对接需要映射
来源系统标识及运营商标识，不能用站址名称猜测归属。

通话与流量首先是用量分类，是否及如何形成铁塔与运营商之间的费用，应由实际合同确定。
初始计价函数仅供验证口径，不能作为已确认的结算合同。

首批组织产品仓库及核心规则；真实接口、合同费率、地图边界、在线指标和业务数据均未接入。
