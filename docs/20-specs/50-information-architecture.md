## Launcher 现行结构（2026-11-13）

### 经营总览紧凑筛选与时间复位（2026-11-13）

经营总览左侧为经营概况，右侧为时间及汇总筛选，宽屏在同一行。运营商与对比快照收进官方Popover，默认只显示筛选按钮及已应用条件数。区域仅由Header统一选择，操作区不重复区域控件。窄屏允许自然换行，控件保持32px。

共用快照／历史时间控件和共享／入驻时间控件末尾均提供官方图标复位按钮。时间复位保留粒度、区域及业务条件，回到该粒度最新可用观测周期，并清除显式对比快照；演示以冻结数据边界为准，正式快照以授权目录的最新捕获及修订为准，不用系统当前时间伪造数据。原经营分析重置同时恢复默认周期及筛选，保留Header区域。

### 共用页面标题区（2026-11-13）

表格操作统一为左展示方式／维度、右查询筛选及重置导出，控件32px，统一间距、内距、圆角和hover；空间不足完整控件自然换行，搜索与筛选导出范围保持。分页总数左置、数量及页码右置，所有页码／方向及数量按钮32px方形，窄屏自然换轨。列表／卡片切换为两个无间隙拼接的32px图标按钮，仅保留外侧圆角、极淡外轮廓，列表使用三行圆点横线；共用官方ToggleGroup语义和交互。能耗时间范围归首个趋势卡片标题右上角，窄屏在卡内换行，删除卡片外独立时间行。详见[实施790](../40-implementation/790-page-heading-consistency.md)。

标题操作规格直接归PageHeading所有页面共用，包含迁移保留独立业务标题的原页面，不依赖site-analysis-page。DS文字按钮统一32px高、14px正文、16px水平内距；图标按钮32px方形、20px图标。共用DS圆角、间距及交互状态，主操作、选中导航、hover及焦点语义保留。标题前返回导航同规格；副标题时间入口维持紧凑文字样式。操作轨道可收缩和自然换行，宽屏右下对齐，窄屏靠右换轨。

所有使用PageHeading的页面统一两侧布局：左侧图标、主标题和一行元信息；有数据时间或状态上下文时，元信息替代原描述副标题。按用户后续要求，所有标题旁的口径说明图标及对应说明抽屉删除，仅保留时间；业务详情抽屉、全局Header帮助及更新时间的来源状态弹窗保留。无上下文时保留描述副标题。右侧只汇集页面操作与二级导航，靠右、底部对齐；“更多功能”采用32px竖三点图标按钮，保留可访问名称及原二级功能面板。窄屏操作组可换行，保持居右，导航与三点按钮集中展示，不截断按钮或时间。服务量化、资源底数、分析研判、报告及原功能共用同一布局，清理页面级旧标题覆盖。

### 共用二级标题与操作行（2026-11-13）

二级标题使用DS SectionHeader的level=2语义、字体与字重；业务图标通过共用SectionHeading组合，图文间距space-sm，标题轨道至少control-xl（标准密度32px）。PanelCard继续使用DS内置level=3标题和原有副标题留白，其操作控件同样control-xl。工具与筛选行不另加上下padding，行内组距space-md、标题与统计距space-lg；页面及卡片之间的间距仍由父级gap控制。标题保持透明背景，按钮沿用DS常态、hover、焦点、选中与禁用状态。加载提示保留32px胶囊，填满可用空间。

共用operation-row.css负责业务、报告、原分析及配置页已有操作行的尺寸与间距。快照控件仅作控件组，不再嵌套第二条操作行。宽度足够时标题、统计、时间操作单行对齐；窄屏按内容组增加轨道，每件控件保持32px，操作组靠右且不截断。明确的单行表格工具可局部横滚，表格及工具滚动边界承接绝对定位的可访问标签，避免撑宽整页。不在各业务CSS中重写同类行高和留白，不修改DS全局token。

## 首页与各业务工作区的边界

首页回答“当前概况、关注什么、下一步去哪里”，不承担批量编辑、详细核验或模板管理。三类指标独立呈现，不合成跨单位总分或总用量。日累计与时点状态分别注明时间口径。已授权的数据质量摘要、待核验事项及报告动态后续接入，当前不能伪造待办、完整率、任务成功或已发布报告。

地图回答“在哪里、周边和同类如何、单站发生什么”，保留全幅底图与悬浮面板。空间工具属于地图；独立列表、档案维护、来源管理、报告归档属于各工作区。地图的单站简览应链接统一站址档案，报告应链接明确版本，异常应链接同一核验对象。

分析中心回答“变化多少、由谁贡献、依据是什么”。三类分析共用区域／运营商／周期上下文，合法指标与单位由来源能力及权限约束。经营服务总量与运营状态比率不能用同一加总规则；物理站级电耗不按服务关系重复统计或摊给运营商。

异常核验回答“业务变化还是数据问题、原因是否确认、后续是否复核”。业务异常与数据质量问题使用可关联但不同的分类；先做人工核验记录与证据闭环，暂不引入完整工单派遣系统。

## 导航、路由与权限

产品分为“业务应用”和“配置管理”两个独立体验域。业务页面不设置统一侧栏，全部入口收进header的业务launcher，各工作区使用自己的业务布局。门户首页、决策大屏与站网地图独立位于顶行；下方五类业务中，容量质量及运行能效归运行监管，周期分析与运营商用量归经营分析，报告库与报告演示归报告中心，站址台账／关系及核验闭环按后续交付开放。header按钮区的配置管理icon为进入管理域的统一入口，不在业务launcher混排管理功能，也不从消息抽屉额外提供管理快捷入口。

配置管理域统一采用 `/settings` 路由前缀与独立导航：管理总览 `/settings`、指标与模板 `/settings/templates`、聚合任务 `/settings/operations/aggregation`、报告任务 `/settings/operations/reports`。域内launcher与侧栏只展示管理功能，并提供“返回业务应用”。旧 `/operations/aggregation` 和 `/operations/reports` 仅重定向兼容旧链接。此处“域”是应用内功能／路由域，不新增网络域名或部署服务。

管理目录不授予权限，各目标仍独立校验真实身份、平台权益、显式权限与工作区范围。报告查看／生成／发布／导出属于业务流程；模板配置及任务运行监控／受审恢复属于管理域。地图视角／图层等现场显示工具与个人外观偏好仍可就地调整。后续新增来源配置、规则、角色范围及审计等管理业务也归入该域，未交付功能不生成空壳入口。

首页固定为 `/`，不再自动跳地图或分析页。保留 `/product-preview` 及已有深链，地图提供返回首页入口。正式路由与 API 继续使用真实身份、权益、权限及工作区范围；导航仅为公开功能目录，不能当作授权。后续正式业务壳参照 yucer 从实际服务端授权结果裁剪导航及首页模块，不复制其销售领域对象或商业键。

预览关闭时首页只展示公开产品入口及登录／未开放状态，不查询或回退合成数据。正式首页总览未接授权读模型前不展示业务数字。登录、权限不足、无记录、数据缺失、失败及未知状态必须区分。

跨工作区上下文目标包括行政区、运营商实体、指标类别、自然周期、站址及证据版本。仅传目的页支持的字段；服务端独立校验，不将 URL 作为授权或来源依据。首页显式点击重点站址才选站，普通进入地图仍不选站。
