# 周期用量分析门户信息结构 V0.2

此处为功能结构，尚未创建页面。

| 一级入口 | 内容 | 核心动作 |
|---|---|---|
| 用量总览 | 陕西省域、主体、地市汇总，完整率与数据水位 | 省内筛选、下钻 |
| 周期分析 | 15 分钟/小时/日趋势、忙时、结构与排行 | 切换指标、同周期比较 |
| 周期报告 | 日报、周报、月报与修订记录 | 查看、重算、异步导出 |
| 异常核验 | 用量突变、持续零量、缺数、基线不足 | 追溯证据、标注原因 |
| 站址资源 | 档案、主体服务关系、来源映射 | 检索、导入、查看版本 |
| 数据接入 | 来源、批次、指标字典、隔离与质量 | 失败处理、归属核验、补传 |
| 管理与审计 | 成员、操作权限、数据范围、导出记录 | 授权与审计 |

全局筛选为区域、运营商实体、指标、时间窗和粒度。展示实际数据新鲜度与完整率。
全国能力仅作为内部地域架构扩展，当前产品只展示陕西，不加入省份切换或其他省份演示。
见 [地域架构与陕西演示](80-national-map-demo.md)。地图演示入口为 `/product-preview`，原指标配置样例保留于 `/product-preview/metrics`。
运营商占比只在同一指标内计算，通话和流量不合并为一个“总用量”。
未接入、缺数、真实零值、加载失败与无权限分别展示。
费用入口本阶段不展示；不保留可操作的试算或账单入口。


## 三类展示更新 V0.3

总览、周期分析和报告提供固定三类页签：经营服务性、运营状态、运行参数。
支持子组、指标、卡片/表格/趋势、顺序、合法粒度与单位的模板化配置。
增加“指标与视图配置”管理：指标目录、来源能力、角色模板、页面模板、周期报告模板。
个人收藏与显隐不影响官方报告，未授权指标不从服务端返回。
完整配置规则见 [指标体系](70-metric-catalog.md)。
