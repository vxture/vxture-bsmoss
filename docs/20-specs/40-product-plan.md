# 产品规划 V0.2

2026-11-10：产品规划按[站址服务与费用依据分析](100-site-service-analysis.md)收敛。先核对服务目录及实际依据，再按服务资源、期间履约、费用依据顺序迁移；本站不执行结算。下文原通信用量规划保留为历史记录，现有过度展开的分析内容保留待迁移，未建独立板块暂缓扩展。

## 使用角色

| 角色 | 当前任务 | 范围 |
|---|---|---|
| 省级分析人员 | 全省周期趋势、主体结构、区域对比 | 授权省域 |
| 市县运营人员 | 区域站址用量、数据缺口与异常核验 | 授权行政区及站址 |
| 数据接入人员 | 来源、映射、批次、质量与修订 | 授权来源 |
| 运营商人员 | 本主体周期用量与证据 | 获授权实体及服务关系 |
| 审计人员 | 历史结果、修订与导出记录 | 授权范围，只读 |

## 当前优先级

P0：站址/运营商实体/服务关系、来源证据、通话与上下行流量、质量与归属、
15 分钟/小时/日聚合、日报、权限与证据追溯。
P1：周报/月报、忙时、同周期对比、异常核验、异步导出；来源具备时增加呼叫次数及资源负荷。
P2：可选短信、电耗、连接等指标适配，以及基于确定性结果的智能解释。

周期报告与规则分析是当前核心；自然语言交互不是首批数据接入的前置条件。
不纳入费用试算、合同、账单、付款、机器人控制或通信网络控制。

## 配置治理基础推进（2026-11-06）

组织管辖与成员权限先落实只读查询：管辖范围、成员管理两个四字入口，正式资源与成员授权目录、完整范围隔离和独立查看权限。组织主档／责任分配与受审授权写入尚未交付。业务参数补齐站址分类（11项）与分析规则（9项）只读目录，统一词汇与内置判定定义，支持检索、维度筛选和详情。正式资源赋类、规则回放签认／发布、来源配置与配置审计后续分批；目录不等于生产规则已启用。数据更新仍是日常业务，本批不推进数据截至或真实接入／上线。详见设计252／实施995。

后续实施996补齐来源配置与配置审计只读工作台：独立查看权限、当前登记及不可变历史版本、完整范围过滤和精确详情。审计覆盖仅来源版本，登记启用不代表连接正常／数据完整。下一受审来源配置治理、对象映射与连接核验，先核对真实来源授权原件和变更契约；不把只读能力计为完整接入治理。接收执行与数据更新仍归日常业务，不属于配置管理。

实施997进一步补对象映射查询与关联有效期核对，独立查看权限及全部目标范围隔离，真实映射定义检索／分页／详情，准确区分来源转换版本与对象映射版本。下一变更预检与影响预览，固定原新版本、授权、真实依据、关联／重叠及聚合报告／任务重新基准影响，再按可信审批契约建设写入；不以只读关联检查代替业务批准或生产接入。
