## 1. 定位与边界

本板块回答：服务数量或用量来自哪里、是否有足够依据、适用什么口径。服务量化负责展示规模和变化，本板块不复制运营商服务矩阵、趋势或区域分析。

仅使用同步快照。呈现数量、单位、计量边界和版本，不输出金额，不办理结算、核验工单、审批或规则编辑。省级交付、地市汇总，按权限下钻到站址；县级沿用行政维度。

## 2. 统一页面框架

- 保留三个独立二级入口：依据汇总、明细查询、口径对照，位于标题区右下方；更新时间后放问号帮助，侧栏承载统计说明。
- 区域只使用Header，不再增加本地选择器。运营商范围承接Header及来源链接，不重复配置区域入口。
- 分析行左侧为中性图标、二级标题、必要的依据数量；右侧为时间选择。全部操作控件32px。
- 加载时仅信息条高亮，高32px，占剩余可用宽度；相关切换禁用并防止重复提交，不显示虚假百分比。
- 依据汇总及明细采用开放式展示，页面自然滚动，无外层卡片、无内部纵向滚动区；规则对照保留主内容卡片。Header固定，标题和分析行随页面滚动，避免固定层挤占高度。
- 行操作复用现有聚合菜单：32px按钮、20px图标。无有效操作时保留位置但不伪造操作。
- 页面正文不重复展示演示标签，仅Header保留来源标识；空值显示待接入或待确认，不能替换为0。

## 3. 依据汇总

### 内容与布局

一页一个主板块：按服务大类组织依据清单。首层为服务大类，展开到具体服务项；同行显示适用依据项数、完整实测、完整分摊、授权估算、待补充、冲突。条目名称承接服务量化目录，不能重新缩减目录。

首层默认展开到大类，不在汇总中铺开所有站址。状态使用紧凑数量与同尺度状态条，点击数量进入该服务及状态的明细。来源尚未接入的服务显示“依据待接入”，不制造空记录参与统计。运营商仅作为已选范围说明和明细维度，不另建重复矩阵。

### 统计口径

| 指标 | 定义 |
| --- | --- |
| 适用依据项数 | 当前权限、区域、期间、服务范围内，适用清单明确的独立依据项去重计数；不是站址数或运营商数 |
| 完整实测 | 输入记录连续可靠、绑定与冻结规则有效，且评估通过的实测依据项 |
| 完整分摊 | 实测源有效、客户绑定与版本化分摊规则有效且评估通过的分摊依据项 |
| 授权估算 | 具备授权和引用记录的估算项，独立显示，不归入可靠实测用量 |
| 待补充／冲突 | 沿用现有评估结果；未归属、缺输入、缺规则等在明细中给出具体原因，不把所有缺失解释为业务异常 |
| 完整依据占比 | 完整非估算依据项数／适用依据项数；适用清单不完整或分母为0时不展示百分比 |

汇总跨单位只加“依据项数”，不把kWh、平方米、挂载数量加成一个服务总量。现有模型的complete包含estimated，不能直接复用为“完整实测”或上述占比；实施时新增明确分类字段，保留原评估语义。

## 4. 明细查询

### 开放式列表

工具行左侧复用列表／卡片标准切换组件；高频外放最多两个筛选：服务、依据状态。搜索与其余条件纳入复合筛选：归属方式、计量维度、来源、客户等。沿用现有真实导出能力，导出全部筛选结果而非当前页。

主列：序号、站址、客户／服务、依据对象／期间、数量与单位、依据方式、状态、操作。长协议ID、源记录ID及重复期间说明收进侧栏；站名点击打开同快照单站详情，整行打开依据侧栏，互不冒泡。

相同单位也必须同时满足scale及boundary一致才可合计。无结果区分筛选无匹配、来源未接入、权限无范围，不引导用户把缺失理解为零用量。

### 依据侧栏

1. 结果与推导：数量、单位、期间、方式、完整性、具体缺失原因；展示可还原的读数差乘倍率、区间求和或分摊公式。
2. 原始记录：源快照、数据截至时间、计量对象、读数或区间输入、可靠性、重置／换表分段。
3. 归属关系：站址、客户、服务、计量绑定及有效区间；总表／分表关联只在授权范围可见。
4. 冻结口径：协议引用、规则版本及有效期；需要共享条件时展示对应月租户数、锚定租户与月内适用策略。

规则只读，追溯必须使用历史冻结版本，不自动补当前规则。共享条件不改变原始物理用量，不在本页计算费用。

## 5. 口径对照

一页一个对照面板。选择器按“运营商／客户 → 服务 → 协议及规则版本”组织，业务名称优先，ID放辅助信息或tooltip。默认同服务的可用版本；不足两套时明确提示，不默认拿两个无关规则比较。

对照为固定字段列加A、B两列：计量对象、单位、精度、边界、有效期间、计量方式、读数处理、分摊依据、估算授权、月内策略、共享档位及锚定条件、协议引用与规则版本。仅真实差异轻量高亮；单位或边界不一致时提示不可直接比较数量，不阻止查看口径差异。

仅展示快照中冻结且有权限的规则。广电及其他客户未确认口径明确标待确认；不存在的规则不以默认规则补齐。价格字段不进入本前台页面。

## 6. 联动与数据适配

- 服务量化跳转携带snapshotId、operator、city、county、服务及指标；未建立映射时说明缺少对应依据，不静默跳到全量列表。
- 汇总状态跳转明细保留范围，切换二级页面保留快照与区域；旧筛选不能造成新页面空白且无提示。
- 依据项追溯到sourceVersion、mappingVersion、ruleSetVersion及具体冻结规则；历史页不得使用当前规则覆盖。
- 复用EvidenceCapture、BasisItem、Meter、MeterRecord、MeterBinding及现有评估器、权限投影和CSV导出，不另建一套证据计算。
- 视图模型补充服务分组、方法与状态交叉计数、可读规则描述及服务指标映射。权限裁剪先于计数及聚合。
- 当前证据模型偏计量表记录。资源配置型服务（位置、面积、容量等）先检查已有服务快照能否提供源对象、有效期、单位和冻结规则引用；缺少时列为依据接入缺口，不硬塞成电表读数或生成虚假证据。其适配另按来源确认，不在本轮随意改数据库。
