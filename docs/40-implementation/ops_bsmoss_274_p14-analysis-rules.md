# P14 分析规则配置整理

## 定位

既有/settings/rules将三套参数表单和其他只读规则纵向堆叠，原表单布局、按钮、错误反馈不一致。本阶段整理为一个配置工作区，沿用已有参数能力；不新增分析维度、后台配置项、规则执行或权限。

## 页面与交互

- 运行监测、承载能力、用量核验、其他规则在共用图标分段组切换，当前只展示一个分类。三套编辑器保持挂载，分类切换保留各自未保存草稿。
- 原#monitoring-parameters、#capacity-parameters、#verification-parameters链接继续选择对应页签；未知锚点回运行监测，切换写入浏览历史，支持前进后退。原入口/settings/rules及导航不变。
- 表单共用参数行、版本和更新时间、恢复默认、取消修改、保存、只读提示、错误重载及生效说明。参数标题正文色；关注与严重采用橙／红语义色，负载和接通比较符保持不同方向。
- 恢复默认只填写草稿，显式保存后生效；取消回已读取值；失败保留草稿；冲突或失权后禁止继续编辑，显式重新读取版本后才能继续。重复点击只发送一次进行中的保存请求。
- 其他规则只读列表，不为单条经营规则增加无意义筛选和分页。名称或整行打开共用连续非模态侧栏，同行收起、其他行切换、空白或Escape关闭；版本、事实、适用功能和边界完整保留。

## 公共组件与边界

只使用官方DS15及既有site-analysis语义样式。控件32px、正文14px、操作行48px，组内8px、组间16px。提取业务层ParameterEditor、ParameterRow和编辑生命周期hook，不创建按钮、表格或卡片基础组件，不添加CSS、依赖或全局token覆盖。窄屏成对阈值共一行，电池开关与条目同行，分段组局部横滚。删除无使用者的parameters/catalog.tsx。

三个域的API、参数验证、CAS版本、权限、存储和刷新通知沿用原实现。核验大整数以原十进制字符串提交，避免浮点失真；温度／强度严重阈值大于关注，接通率严重阈值小于关注，比较符和有效范围不变。固定基线、持续零量条件及历史证据边界保留，双命中不新增阈值。运行监测参数继续覆盖运行能效。时间显示统一秒级。未接入或失权不返回演示成功，不新增正式写入能力。
