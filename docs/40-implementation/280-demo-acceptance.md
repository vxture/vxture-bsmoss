# 演示链路收尾与六场景验收

2026-11-02。五项持续交付中的第2、3项，本记录以实际脚本结果为准。

## 体验修复

实查发现月报排行下钻默认回到时段，且单站请求失败的按钮跳到样板站并重置范围。现从日报／周报／月报进入站址时，直接进入对应经营周期；运行与经营仍可独立选择周期。增加返回原周期报告，保留运营商、行政区、精确选区与报告周期；返回报告章节为概览，需要时重新选择环比排行。切换站址恢复时段；改变范围清除旧返回标记，防止误导。

单站失败改为重试原请求，保留站址、市县、运营商与小时。无效站址仍提示范围不符，不替换其他站址。首页无site时无默认选择或单站请求，显式链接仍恢复选择。

范围／小时切换会清空旧站址详情后重取，确保旧小时数据不会伪装成当前数据；单站周期内部日期／指标焦点未做跨刷新持久化。所有周期仍固定在演示窗口，不能当成当前真实业务日。

## 六场景讲解路径

| 场景 | 站址与地图小时 | 讲解重点 |
|---|---|---|
| 商圈忙时 | SX-DEMO-001 / 18 | 忙时流量、通话和负载，经营与运行并排 |
| 交通潮汐 | SX-DEMO-002 / 18 | 小时潮汐与同星期参考，线索定位 |
| 园区业务 | SX-DEMO-003 / 18 | 周／月趋势、超过8条的完整波动证据导出 |
| 供电保障 | SX-DEMO-004 / 12 | 电池供电、运行参数与业务同步观察 |
| 能效观察 | SX-DEMO-005 / 03 | 低业务与物理电耗，避免运营商能耗摊分 |
| 多方共享 | SX-DEMO-006 / 18 | 五类运营商用量守恒与一处物理站址 |

统一演示路径：省市县／选区 → 周期报告 → 环比排行 → 单站同周期 → 小时波动与参考原值 → 离线导出 → 返回范围报告。默认标准底图、浮动面板和底部布局保持用户确认的效果。只演示陕西，不新增其他省份。

## 可复现脚本和制品

`node scripts/demo-acceptance.mjs`检查六场景API、三周期计数守恒、报告同快照及18份离线报告。

追加`--browser`检查1440／390真实触屏配置／1024三个宽度的全部六场景、无默认站址、下载和水平溢出。通过`BSMOSS_PLAYWRIGHT_MODULE`指定已安装Playwright模块，`BSMOSS_CHROMIUM_PATH`指定浏览器；不新增产品运行依赖。浏览器验收阻断在线地图请求，检查本地行政区与分析交互；不能作为在线瓦片授权或网络可用性证明。

结果与截图位于忽略目录`artifacts/demo-acceptance/`。最终回归日志作为参数传给`node scripts/demo-release.mjs <unit日志> <http日志> <types日志> <build日志>`，生成源码逐文件SHA256、总摘要、Next BUILD_ID、报告及验收摘要。无Git提交时明确gitSha=null，以内容摘要固化本地版本。不是生产镜像digest，不推送公开仓库、不打发布标签。
