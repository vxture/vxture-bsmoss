虚线只分隔标题区；可选toolbar位于虚线之后，作为内容区操作行，不再包含在虚线上方。首页地域选择从toolbar提升到标题旁，不保留空操作行；四类业务分析、核验、决策分析同步。站址面包屑及收起按钮进入标题旁地域槽位，数据截至单独右上；档案／核验详情返回导航只保留返回动作，地域移至标题旁。档案日期与快照在右上，内容操作行保留小时选择但不重复日期。

用户布局草图的“刷新时间”在本系统沿用来源快照／数据截至口径；刷新只重读，不用墙钟伪造水位。业务筛选、权限、事实及地图独立全画布保持。验证记录及截图见agent memory和artifacts/page-heading-grid-qa。
