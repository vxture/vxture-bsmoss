## 用户指定标题矩阵（2026-11-05，覆盖上一版两层排布）

采用明确的两列两行：左上常态标题紧跟区域选择或静态范围，右上来源时间；左下副标题，右下板块全局按钮。通过官方ViewHeader的secondary承载公共region槽位，右侧context／actions纵向分层，原DS标题字体、按钮、24／40／56页面留白保持。长标题或范围自然换行；窄屏右侧时间／按钮组流至下一行，仍有序且不横溢。无地域或无来源时间的配置页不生成占位文字。

虚线只分隔标题区；可选toolbar位于虚线之后，作为内容区操作行，不再包含在虚线上方。首页地域选择从toolbar提升到标题旁，不保留空操作行；四类业务分析、核验、决策分析同步。站址面包屑及收起按钮进入标题旁地域槽位，数据截至单独右上；档案／核验详情返回导航只保留返回动作，地域移至标题旁。档案日期与快照在右上，内容操作行保留小时选择但不重复日期。
