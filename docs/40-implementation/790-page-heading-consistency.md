# 页面标题区域统一

## 范围与结构

2026-11-05用户要求统一标题、副标题、标题至主操作行的布局、按钮及相关细节。本次使用官方DS ViewHeader的业务组合PageHeading，未修改DS组件或全局token，地图全画布保持独立。

- 页面仅一个常态H1，使用DS heading-1；副标题使用DS body与muted-foreground，说明业务用途。标准密度实测18px／14px，不在各页写独立字号。
- 共用navigation、title／description／secondary、actions、context、toolbar槽位。详情返回与地域导航在标题前，状态紧邻标题；地域、来源窗口／数据截至与筛选独立组织，不把状态说明代替模块标题。
- 操作区使用官方Button：至多一个强调主操作，导出／保存用default，地图／关联跳转用outline，刷新／全屏用ghost图标按钮。默认md与icon-md同尺度，标准密度24px，不修改DS尺寸。页签与行内操作保持各自DS角色。
- 标题与操作宽屏左右排布；窄屏操作组左对齐换行，不使用固定高度。上下文与筛选可换行；底部采用DS细虚线、space-lg留白，内部使用space-sm／md／lg，保留已确认的24／40／56px响应式页面水平内距。
- 覆盖运行总览、决策分析、站址台账／关系、站址档案、容量质量、能效、运营商用量、用量报告、核验列表／证据、配置管理／显示设置、正式分析／报告、模板、两类任务、指标及版权辅助页。报告／任务标题从侧列提升到整个工作区上方；旧原生标题操作改官方Button／Input。
- 未接入／未登录分支保留稳定模块名与副标题，接入状态放内容卡；登录、权限与来源门槛不改。旧报告与指标辅助页CSS排除共享标题后代，避免覆盖DS字体、按钮及焦点样式。
- 台账侧栏按钮仍在地域面包屑前，常态无背景。所有地图链接保持newtab；地图本体及浮层不套业务标题区。
