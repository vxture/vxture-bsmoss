## 实现

- `display-rules.ts` 提供版本化显示偏好解析、白名单及去重、独立专题默认、排序、概览单位转换和地图点位显示规则。
- Zustand 保存完整展示偏好，每次更新经纯规则规范化；与查询上下文、专题阈值和原始证据分离。
- `display-controls.tsx` 提供顶部概览、三类指标勾选／排序／恢复默认及专题折叠配置；不增加固定布局栏。
- 顶部六选一至三：流量、通话、短信、接通率、负载率、电耗。使用已有服务端摘要，保留零值与未知差异。
- 每专题保存全部／关注与未知点位、区块显隐与顺序、三／四／六站、站点指标证据；完整／精简两种快捷模板。
- 视图过滤在点位交给 MapLibre 之前执行，聚合数跟随实际显示点位；分析摘要与走势继续使用完整服务器结果。
- 本地存储键为 `bsmoss.map-display.v1`，初始化解析后才自动保存，兼容已有 `bsmoss.map-view.v1` 图层设置。
  非法 JSON／版本／字段不会成为查询参数或规则，存储失败不影响本次交互。

具体默认、单位和边界见 [地图规格](../20-specs/80-national-map-demo.md)。这是演示浏览器偏好，不是正式配置发布或账户级偏好存储。
