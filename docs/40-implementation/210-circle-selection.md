# 圆形圈选分析

2026-11-02。本批在矩形选区之上推进圆形观察范围，供陕西客户合成演示。

## 实施

- geometry纯规则新增圆形解析、规范序列化、球面距离、边界包含、外接边界及96段闭合轮廓；Selection为Bounds或CircleSelection。
- service复用统一selectSites及单站范围判断，地图、专题、对比、运营商核查、日报与下载均沿用圆形交集。
- URL与API保留原矩形，圆形使用selection=circle:lng,lat,radiusMeters；非法、重复、越界参数拒绝。
- 地图绘制条提供矩形／圆形，支持拖动与两点、取消恢复；区域面板可输入公里值或选1／3／5／10km。
- 重画、改半径清除旧对比清单；取消保持原范围，切小时／运营商保留，切市县清理。
- 圆形是观察范围，不推断无线覆盖、供电持续时间、退服影响或费用。外接矩形仅用于相机，不能代替精确圆内筛选。
- 未改变已确认的标题、底部信息行／回放／图例、右下四图标与版权入口展示。
