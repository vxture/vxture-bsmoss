# I08设备状态可信快照与持久化

2026-11-02。内部实现完成，未真实接入、未外部部署、未上线。

## 交付

新增state-period纯规则、pg-state-snapshot可信读取、state-service两道授权门与pg-state-store。设备保持时间来自唯一已核验event能力，回看不早于能力生效；事件／质量修订、映射有效期和整对象完成证明均保留证据。未验证／过期事件阻断更早状态，无证据时段保持unknown。

pg-repository抽取共享追加修订／CAS／outbox／租约原子提交；pg-store成为interval薄适配，state使用独立计算器。两适配器拒绝另一语义的读写。refresh-snapshot按产品字典分派，refresh-enqueue与refresh-execution接通状态任务，外层一致快照不变。

空库DDL的aggregate_revision新增state_value及类型／结构／非负整数检查，result_payload绑定；Prisma镜像同步，共33表。无新依赖、无旧库迁移、无业务UI变化。

## 验证

395项单元测试通过，含7项状态周期测试：回看／失效、时长守恒、确认／撤销、质量与事实修订、17分钟映射切换、同刻冲突、过期／pending阻断、授权与适配器语义边界。

实际PostgreSQL合同新增10个子项：可信读取精确时长、结果／历史清单复算、最新确认及撤销、同事务证明快照、非网格映射切换、最高修订移窗／移设备撤回、能力与设备权限／生效边界、调度原子回滚及重放、状态旧快照与新head竞争、SQL类型与结构拒绝。适配器仍SET ROLE bsmoss_svc，只创建删除随机bsmoss_contract_*数据库。

最终DB数量、类型／生产构建／HTTP／Prisma及守卫、Git提交与运行版本以本包收尾检查点和agent记录为准。旧六场景UI未改动，不重复浏览器验收；不将本地检查记作真实来源／生产验收。
