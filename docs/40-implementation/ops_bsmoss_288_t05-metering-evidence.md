## 2. 冻结计量模型及规则

新增可选EvidenceCapture，与物理、租户、服务载荷分别保存和校验：捕获清单、具体客户、总／分／独立表计、原始记录、客户绑定、依据项目、冻结规则。数量使用最小单位整数字符串和BigInt；不同单位或边界不混算，未知不作零。历史捕获身份及同ID规则内容不可覆盖。

- 实测：完整、连续、可靠区间或累计读数差乘倍率；总表不得直接作为客户实测量。
- 换表／复位：原记录跨事件时待分段，已有明确独立表计段才可累计；不按时间比例推算。
- 协议分摊：要求明确分摊绑定及冻结整数比例，比例总和不得超过100%，不得与同范围分表实测重复申领；不能整除最小单位时待确认。
- 估算：要求确认规则及估算依据引用，单列估算状态，不计入可靠实测客户合计。
- 共享条件：引用当月不可变租户快照、具体客户及该客户锚定状态，按整月／分段／参考日规则匹配；缺月、未知或跨期变化待确认。共享系数只呈现条件，不折减计量数量或计算金额。
- 发布时选取适用的已确认激活规则并复制精确修订；已提供引用不被替换。跨版本、冲突、未确认、单位／边界不符均不回退默认。

同周期A/B显示修订差值；来源、单位、映射、规则及范围不可比时不显示误导性增长。客户、区域权限先投影后聚合。受限客户既看不到其他客户依据，也不通过分摊原始记录看到整站总表量；该分摊在缺少授权输入时待确认。全权限下的运营商筛选与权限边界分别处理。
