# I08 区间聚合结果版本存储

2026-10-29。本批延续 yucer 的纯规则、服务、存储适配分层，完成区间增量、比率及同窗派生结果的 PostgreSQL 存储子任务。I08 保持 in_progress。

## 数据与版本

空库基线新增 bsmoss_analysis.aggregate_series、aggregate_revision、aggregate_outbox，总计 29 表；Prisma 仅镜像标量结构。仍为新产品首次初始化，无旧库迁移，也不在应用启动时执行 DDL。

series 以租户、来源、主体、指标版本、粒度和完整自然周期唯一定位。revision 保存精确整数或分子分母、完整性、水位、规则版本、输入指纹、结果快照、原始输入清单及可信操作主体。缺数与零值分别表达，依赖缺失时保留 knownValue 和原因。

input_manifest 保存首次成功发布的 plan 与 inputs，可重新执行相同规则核对结果。result.evidence 引用事件、测量/质量修订、原件摘要、映射及转换版本。当前保存的是内部输入快照及引用，不是对来源真实性的独立认证；正式接入仍须从已验证测量构造输入。来源权限和适用窗口不能由请求体指定。

本适配器仅接受 aggregateIntervals 支持的区间结果；瞬时均值与状态时长的结果类型、版本存储另行实施。历史规则升级后的重算应保留对应实现版本，不能只凭字符串保证旧算法可重现。

## 发布事务

服务先检查 metering 功能授权、metering.aggregate 产品权限和租户，再将 ctx.sub 作为发布人传给 store。读取使用 metering.view。新增权限只进入空库种子，不自动授予用户、owner 或生产任务。

store 使用显式有限的来源/主体/指标三元组，构造时复制授权集合，避免独立列表产生笛卡尔积扩权。查询必须提供完整 series 键；支持当前版本及明确历史版本，没有全库列表入口。

发布在同一事务中锁定 series，先按输入指纹检查重放，再核对 expectedRevision，插入不可变结果、切换 current_revision、写入 aggregate.revised 事件。初次发布 expectedRevision 为 null；新输入必须匹配当前版本。同输入重放返回首次版本和当下指针，不回退指针，也不重复生成事件。相同指纹但不同结果被视为冲突。

并发不同输入只有一个 expectedRevision 匹配者成功，另一方须重新读取并重新决策；不可无限盲重试旧快照。任何步骤失败均回滚，包括首次创建的 series。锁只约束本适配器的调用；DDL 的列级权限允许更新指针，CAS 与自然周期语义由服务/适配器保证，不能声称数据库自身验证所有业务规则。

运行角色禁止更新、删除和清空 revision/outbox，禁止更改 series 锚点。DDL 通过同租户外键、唯一键、数值与 JSON 类型一致性检查保障结构；这些约束不替代用户级授权。

## 尚未完成

此服务仍是可信组合根使用的内部端口，没有新增 HTTP 路由，也没有将客户端参数直接变成计划。生产聚合身份、有效来源和测量查询到输入的编排尚未接线。

outbox 目前仅为事务内追加事件账本，没有消费者、游标、投递确认或重试调度；不能据此宣称下游已刷新。I09 将补充周期任务、72 小时回补、质量/测量修订传播；累计读数修订须重算相邻两个区间。

区域/运营商汇总必须先验证对象互斥及来源权威，总分电表不能直接相加。正式面板与报告仍归 I11/I12；门户继续使用样例数据，费用只预留。

## 本地验证

229 项单元测试、根/app 类型检查、Prisma validate、29 表静态镜像、文档编号及交付守卫通过。聚合源码、本批数据库及测试改动的本地密钥扫描无发现。

独立 PostgreSQL 18.4 空库合同测试 36 项通过（35 个子测试及父测试），其中新增 8 个聚合子测试：并发同输入幂等、修订/旧重放、并发 CAS、事件写入故障回滚、比率/零/缺数/部分值往返、有限范围隔离、运行角色不可变权限、类型/JSON/跨租户约束。实库列结构与 Prisma 一致。日志位于本地忽略目录 artifacts/aggregate-unit.log 和 aggregate-db.log。

测试二进制来自 @embedded-postgres/windows-x64 18.4.0-beta.17；此次恢复临时工具后新建 aggregate-data 测试集群，只监听 loopback，测试结束已停止。测试脚本仅创建并删除随机 bsmoss_contract_* 数据库，不连接业务库。未运行远端 CI 或部署，本批不涉及页面变更。
