地图入口及返回地图均使用新标签页和noopener/noreferrer。地图客户端地址重写保留调查上下文，默认不选站。地图返回按钮使用发布DS的局部深色主题，避免深色底图上的浅色主题文字不可读。

核验新增精确site条件，区别于模糊搜索。无对应UV案例的站址显示空态，不能构造发现。不同来源清楚说明：UV独立核验场景库、站网固定快照与calendar经营历史彼此独立。关联调查不表示原量一致、结论迁移，也不把HE历史依据转为可人工操作的案件。历史报告跳转保留原调查，HTML/JSON载荷与报告摘要不受返回参数影响。
