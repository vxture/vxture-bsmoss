# 报告worker循环与授权待办

设计见[214](../30-design/design_bsmoss_214_report-worker-loop.md)，接续3207974登记报告调度。I09／I12继续in_progress。

## 实施

新增workers/rules、loop与report-worker。可信配置固定机器租户／主体、最多64登记与可选导出通道，不能传入token／scope。各通道独立轮转、每轮1–25步，失败5／10／20／40／60秒单调时间退避，连续成功复位。无自动发布或任务次数重置。

显式run才启动，空闲等待可中止；run与tick互斥，停机不派新通道，跨事务边界也检查停止信号，在途事务结束后才返回。宿主负责真实信号、Pool及进程托管，未接真实provider或Next启动生命周期。snapshot及轮询事件仅进程内固定诊断，不回显异常正文，不冒充持久监控或上线。

导出store与授权门面增加pending，仅execute权限；精确历史scope先SQL过滤再limit，C顺序稳定，逐份验证完整报告／SHA，再验返回必要scope并集。撤回和stale任务仍可发现，执行器持久化终止；没有run HTTP或普通用户队列列表。55表和索引沿用，无DDL／Prisma／依赖改变。

## 验证

单元回归包括有限轮转／独立退避封顶、无异常正文、重入和重复run拒绝、实际60秒空闲timer被中止、在途等待／观察器失败、单调时钟倒退及固定配置校验。既有exports授权测试增加pending阶段，覆盖身份／权益／权限／范围／过期再次验证。

真实PG新增授权导出待办／worker场景：未授权较早任务不挤占满页、due／terminal区分、完整五维和物理站独立开关、租户／生成与请求权限不隐含execute、末次撤权／损坏与SQL错误、撤回任务dead、事务中断与新实例恢复、暂停通道不阻塞其他生成及导出、身份／租户固定、扫描提交后停机不启动生成、导出制品事务中停机仍等待成功提交并保留第二个pending任务。使用真实三类计量与完成证明夹具，不能代替实际来源授权。

首轮损坏证据夹具匹配了不存在的SQL文本，未触发注入；改为实际读取语句后核验拒绝。新物理电耗夹具使原列表测试出现两份同日合法报告，旧断言误以为新建报告必排首位，改为验证其确实可见，完整排序已有独立全集合断言。未改产品排序或放宽权限。最终计数、双层类型、构建／HTTP、编号文档／55表／交付／SCA、ASCII和密钥扫描见`artifacts/formal-checkpoints/report-worker-loop.json`及`tmp/report-worker-{unit,db,types,build,http,guards,ascii,staged-scan}.log`。

本批无UI变化，不重复稳定地图六场景与报告视觉QA。实际PG只用专用随机合同库，收尾stop；预览恢复到本包SHA，正式匿名接口继续拒绝。没有push／PR／远端CI／外部部署或上线。
