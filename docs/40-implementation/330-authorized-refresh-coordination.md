# I09授权周期与修订协调

2026-11-02。内部代码进展，无真实来源接入或生产上线。

## 实现

refresh-coordination提供有界目标规范化、服务器小时扫描引用、自然周期与历史旧／新区间规划；refresh-enqueue重新解析授权和可信快照，在单事务写全批任务；refresh-supervision提供当前授权候选、限定ID领取和失败分类的单步监督。subjects集中稳定对象身份，沿用原有编码。

pg-refresh-jobs新增事务绑定批量入队和限定候选ID抢占。pg-snapshot、pg-store支持外层事务绑定；refresh-execution在同一REPEATABLE READ事务内读取来源／输入／head及原子写结果、outbox、任务和回执，避免旧输入采用新head。

## BUG-001：旧快照覆盖新结果

严重性P1，影响内部刷新执行器，未部署生产。复现：执行器先读取通话／流量旧事实，另一执行器修订并发布110，再读取到新head后用旧事实发布100，当前结果回退。

新增实际PG回归先在旧实现上失败（100而非110，日志tmp/refresh-race-before.log），再修复事务边界。修复后较旧执行触发序列化／版本冲突，head保持110且任务未确认；重试读到新快照，复用正确结果。原有回执失败回滚、过期租约与并发修订测试继续通过。
