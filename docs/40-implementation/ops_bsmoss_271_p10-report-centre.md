# P10 报告能力收敛

## 范围

按用户确认，报告库、生成与任务记录围绕报告中心组织。Launcher只有报告中心；生成仍为中心内显式动作，完整工作区保留。无新后台流程、调度、审批、统计、配置、依赖、权限、DDL或存储迁移。

## 页面与交互

- /reports 默认本机报告库（显式预览）或正式授权报告库，原历史内容和下载使用原文件。
- /reports?view=tasks 为中心内部任务记录，生成／导出切换、状态筛选、原API与游标分页。
- 任务行打开连续非模态侧栏，同行切换／其他行换内容、空白／Escape关闭；旧复核／原命令重试语义保留。
- 任务结果固定平台report和revision读取，演示开启也不误入本机库；没有权限时拒绝，不回退本机或最新版。
- /reports/new 原完整生成流程不变，导航激活报告中心。
- /reports/tasks 仅兼容重定向，合法参数保持，重复或错误任务不误选。
- 官方DS15及site-analysis统一操作行、分段组、表格、侧栏与字体；删除原jobs专有布局及已无消费者的operations.css。
