## 统计依据与边界

`domains/monitoring/rules.ts` 为纯规则，以物理站址去重，按供电、温度、能耗三项分别评估证据。有效数值 0 仍为有数据；无效时间、非有限数值及负能耗不算有效记录。相同站址/指标/时点不重复计数。

- 有数据：周期内存在有效记录，不代表实时在线或运行正常。
- 应采缺数：已确认指标适用且应有记录，但没有有效记录。
- 未接入：有明确未接入依据；不能从空记录反推。
- 待确认：其余无法确定的状态。缺少某项指标的证据时，也保留待确认。

站址状态优先体现已确认应采缺数，其次有记录、全部未接入、待确认；“有记录站址数”独立统计至少一项有记录的站址，包括局部缺数站址。各指标适用范围完整已知时，才以适用站址为分母计算覆盖率；分母未知或为零时显示 `--`。

当前数据无完整接入名单、指标适用清单和应采频率，因此仅展示实际记录数量、最近有效时间与待确认口径，不生成应采完整率或设备在线率。图表进度条用于数量比较；地域按行政编码排序，支持省→市→县→单站址与标题右侧返回上级。

运营商只限定其入驻的站址集合，供电/温度/能耗始终使用物理站址记录，不能把未分摊电耗当作运营商缺数。明细搜索、记录状态选择不改变顶部概况及区域统计；明细筛选分组计数基于当前搜索结果、在状态选择之前计算。

## 运行监测参数维护（2026-11-09）

配置入口沿用“配置管理 → 业务参数 → 分析规则” `/settings/rules`，运行关注底部提供“参数配置”链接。三类运行规则逐项展开：蓄电池供电关注开关、温度关注/严重阈值（°C）、能耗强度关注/严重阈值（kWh/GiB）。默认值仍为开启、35/40°C、0.15/0.30kWh/GiB。取消恢复最近保存值，恢复默认仅填入草稿，保存后生效。其它分析规则继续保留内置目录；此处配置仅作用于已迁移的运行监测，不改变旧版专题、地图或不可变报告快照。

关注/严重必须为有限数值且严格递增，能耗强度关注阈值必须大于0，温度不得低于绝对零度；拒绝空值、字符串数字、NaN/Infinity、多余字段及客户端工作区。比较仍为大于等于、严重优先。每次分析读取一个完整配置快照，供当前状态、周期等级、地域统计、筛选、详情时序、阈值提示共同使用；历史观测按当前参数重新判定，不修改原始记录。保存后同页事件与跨标签通知刷新服务端分析；聚焦、可见性恢复及60秒巡检兜底，避免只改说明未改计算。详情保留规则参数版本，配置页显示版本及更新时间。

纯参数规则、服务鉴权、文件存储分层。存储按服务器确定的工作区散列隔离，写锁+乐观版本检查+临时文件fsync/原子替换，写入前重查身份、工作区、订阅及权限；失败不覆盖已保存配置。服务重启后保留，损坏文件失败关闭而非静默回落默认。正式环境需设置 `BSMOSS_MONITORING_PARAMETERS_DIR` 到持久共享目录；本地预览默认 `private/monitoring-parameters`，不依赖浏览器本地存储和构建目录。当前记录包含版本、参数、修改时间和修改主体，不声称已实现完整审计历史。

独立权限为 `admin.analysis_rules.view/edit`，不借用运营主体或数据源编辑权限。正式接口使用既有RP会话、产品权益和工作区授权，所有响应私有禁缓存；写接口限制同源、JSON及8KB请求体。只有明确开启、未启用OIDC且回环绑定的本地预览允许维护预览配置。基线DDL仅新增权限定义，未应用DDL、未自动分配权限、未开放正式监测数据。
