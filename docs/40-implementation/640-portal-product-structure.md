# 门户首页与产品结构补齐首批

对应 [设计228](../30-design/design_bsmoss_228_portal-product-structure.md) 和 [门户信息结构V0.4](../20-specs/50-information-architecture.md)。本批实现P01与完整缺项盘点；P02–P08仍待实施及实际验收。

## 实现

`/` 从自动重定向改为独立门户首页。演示明确开启时，同一map-demo适配器提供概况、三类指标、地市分布、运营商结构、重点站址和业务入口。全日累计、18:00小时窗口分别标明，1,080为模拟站址，3,902为服务关系，不引用约11万规划规模冒充真实接入。

新增纯导航目录、共享ProductHeader。周期分析、报告、聚合任务、报告任务、模板管理五页统一品牌、首页入口与管理菜单。导航不作为授权结果，正式路由与API继续真实校验；未新增正式读权限、测试身份、接口或DDL。预览关闭首页不运行演示适配器，仅展示公开入口和登录／未开放说明。正式授权总览尚待P06。

地图继续全幅独立工作台，已有深链保留；顶部可见品牌提供返回门户链接。原左侧rail品牌在HUD布局隐藏，实际浏览器核对后将返回入口放在顶部可见品牌，未把隐藏元素当可用入口。

普通进入地图仍不选站；点击具体站址才带site。运营商、地市下钻链接只带目标支持的条件。正式API未回退为演示，模拟数据不写入测量证据。首页不加载地图画布和底图。
