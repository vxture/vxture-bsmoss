# I08可信总流量与接通率依赖入口

2026-11-02。五项持续交付第二轮的内部进展，未接入真实来源或部署。

## 实现

新增`domains/aggregation/input-policy.ts`纯规则，按首批字典解析目标和依赖引用、合法模式与指标权限；`PgAggregateSnapshotReader`扩展可信读取，沿既有service/store链发布，不增加客户端输入字段或HTTP入口。

目标能力的策略决定直接／依赖模式；两个依赖均须唯一active能力、明确核验依据、direct策略和相同原生频率，数据库定义须与产品字典一致。目标与依赖指标授权都检查。双向流量以精确整数相加，接通率合并接通数与尝试数；同时存在的直接比率在依赖模式下不读入。

保持同一只读可重复读事务、有效映射交集、最新事实／质量语义、总输入上限、原子发布与输入指纹重放。方向依赖缺失不输出貌似完整的总量；修订移至其他窗口时原窗撤回旧事实。依赖策略／核验／有效期纳入权威摘要，目标的完整快照确认绑定全部依赖；多映射仍不采用单段确认。

未改聚合规则版本、现有直接模式的权威字段或DDL／Prisma结构。原有直接增量、直接比率和单映射完成证明路径保留。

## 验证

新增3项纯策略测试与扩展既有授权测试，验证目标＋依赖授权、字典固定顺序、明确模式、不可变引用、非法版本／粒度及状态拒绝。

新增6项真实PostgreSQL合同子测试：超53位方向计数的精确总量与持久复算／重放，依赖权限及能力拒绝，依赖权威／质量变化使完成证明失效，事实移窗撤回及历史版本保留，直接／派生比率互斥与分子分母合并，以及并发修订时跨依赖仍处于同一快照。独立loopback PostgreSQL 18.4运行62项报告测试（61子项＋父项）通过，运行适配器实际SET ROLE为bsmoss_svc。

最终单测、类型／构建、HTTP、守卫及源码扫描结果见agent最新记录。本批只创建和清理随机bsmoss_contract_*测试数据库，不连接业务库，不执行旧库迁移。
