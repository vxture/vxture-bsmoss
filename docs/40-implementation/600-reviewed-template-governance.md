# 受审模板治理实施与验证

日期：2026-11-03。设计224；本包为I11管理员页面／报告模板发布及默认版本切换的有限切片，不代表I11、五项任务或生产上线全部完成。

## 实现

新增 templates 纯规范化／命令契约、TemplateStore、PgTemplateStore、配置绑定验证器和独立授权门面。复用现有字典／报告模板规则、RR拓扑证明、范围并集和正式RP组合根。页面／报告不可混用，隐藏绑定也验完整范围，不读时序。配置摘要包含真实映射与受审 rollup 版本，设备总体含未覆盖对象，物理站级参数开关不代替设备授权。

空库基线新增两张追加审计表，61表／Prisma镜像；版本不可变，发布与版本、默认事件与指针在同事务落地。运行角色撤销版本直插和默认直写；个人偏好沿窄共享锁函数，默认选择触发器取排他锁。无旧库迁移／升级脚本，无依赖变更。

GET／POST /api/templates、preview和selection及 /settings/templates 正式页面已接线。管理员使用独立查看／发布／选择权限，不自动授予owner。发布不启用默认、不生成／发布报告；默认替换核对被替换范围。精确历史命令回执与当前head分开，回退追加事件；503保持原命令、409清上下文。草稿只在页面内，角色／工作区发布与可视化编辑继续待办。
