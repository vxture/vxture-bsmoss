日期：2026-11-11。依据[PRD120](../20-specs/120-tower-service-page-prd.md)和[固定八批计划70](../70-workplan/70-tower-service-migration-batches.md)。T07本地验收完成，当前7/8；下一批T08待开始。本地功能验收不代表正式来源接通或投产。

## 1. 页面与入口

- `/tower-service/overview`：无页签驾驶舱。只组合资源底数、服务量化及冻结研判读模型；可用指标进入概况，缺来源不生成整排空指标。区域站址条形图、运营商×服务度量矩阵、最多3条重点关注，严重事项优先；提供同版本专题入口。
- `/tower-service/network`：区域级行政区划地图，无站址点位。资源、服务、共享率三个图层；度量及单位随图层切换，当前值／A-B差值可选。地图和对照表直接使用同一数组，未归属仅进表，缺数据区域灰色，不据边界补零。
- Launcher上方现在可访问六个新业务板块，下方原有功能及待迁移标记保留。跨新业务页携带快照、A/B、运营商和区域，不泄漏图层、度量等局部条件；旧页不注入新快照参数。完整导航切换仍留T08。

沿用DS15、PageHeading、SnapshotControls、AnalysisSummary、PanelCard、DataTable、Progress、ConfigurationDetail及已有通用布局。概况仅对主动提供href的指标增加链接，原消费者保持原行为。未新增样式表、tokens、依赖或平行按钮／卡片／表格组件。地图字体从通用字号反算投影尺寸，窄屏标注避让；隐藏的重叠名称仍可在区域表及悬浮中查看。

## 2. 数据口径及联动

资源复用T03聚合：品牌筛选选中关联站址，设施仍按整站物理资源去重。服务复用T04读模型，矩阵各度量保留独立单位，不合计挂载量、容量和用电量。共享率复用固定月度租户事实，分母为入驻站址；无完整月份或权限不足不推算。重点关注复用T06固定规则结果，摘要限制3条不改变完整事项数量。

地图数量保持BigInt精度，只将归一化强度转成Number用于着色。A/B验证资源映射、服务度量身份及期间可比性；同一时点展示修订差异，零基准／不可比不强算。共享差值使用百分点，图例以0为中心。增加蓝色、减少橙色，避免把资源增减视为严重告警。悬浮展示当前、基准、差值、A/B版本及占比／分母；同版明细可进入资源或服务专题。

点击省内地市下钻区县，返回上级置于标题操作区；县级叶子显示同范围侧栏／明细入口，浏览器返回保持查询。地图侧栏在版本或范围改变时关闭。取消B恢复当前值模式。当前已有边界及来源仅覆盖陕西，不能据此宣称总部多省数据接通；市级权限只读取所属区域，县级能力依来源条件启用。

所有新页面通过既有授权读服务获取已裁剪快照，再聚合并裁剪区域边界；不序列化全量原始资源图。重复、伪造、未知或越界查询拒绝。正式预览关闭时不展示演示底数及地图数据。无实时监测、告警／故障、SLA、工单、审批或金额计算。
