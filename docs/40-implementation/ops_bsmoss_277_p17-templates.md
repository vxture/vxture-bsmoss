# P17 模板配置迁移

## 目标

保留 `/settings/templates` 原有读取、编辑、校验、发布和分析默认版本切换流程，迁移到官方DS15与既有site-analysis基础布局。版本读取在上方，草稿与校验结果按屏宽并排或纵排。原生输入、选择、复选框和按钮改用官方组件，删除无消费者的templates.css；不添加新的CSS或基础组件。

## 保留的业务行为

页面／报告草稿、面板增删排序、指标绑定、粒度、展示方式、单位、精度及可见性保持。高级JSON编辑保留原文；结构无效时允许修复，不清空内容。编辑后原校验失效，重新校验才能发布；校验结果仅证明配置与对象归属，不等于数据质量验收。

发布与默认版本切换仍为独立命令，保留审阅依据、候选摘要、校验摘要、预期版本、已发布不可变版本与原授权检查。网络或服务端错误导致结果未知时锁定草稿，仅可重试同一个命令；冲突或失权要求重新读取。默认版本只能选择已经发布且未改动的页面模板，不自动发布或切换。进行中重复点击仍由原inFlight保护。

模板配置不改变P6本机报告生成器、已保存历史文件及正文内容。正式身份和数据未接入时保留明确边界，不使用预览样例冒充已发布模板。

## 验收证据

最终结果及拦截测试说明见[阶段收尾278](ops_bsmoss_278_p18-closure.md)。验证涵盖发布／选择未知结果重试、冲突、失权、无效JSON与多屏宽布局，不执行真实模板发布。
