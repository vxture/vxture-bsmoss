# I10 样例门户验收

日期：2026-10-28。I10 在“样例门户骨架及纵向切片”范围完成，未接真实来源、平台身份或业务环境。

## 交付范围

- Next.js 页面 `/product-preview`：经营服务性、运营状态、运行参数三类入口，窄屏提供分类导航。
- `/api/product-preview`：服务端持有固定样例身份、指标授权、来源能力与显示模板；客户端只提交分类、区域、运营商及显示偏好。
- 复用 I01 指标字典及 I02 配置解析，覆盖首批 11 项定义，提供卡片、趋势、站址证据和数据上下文。
- 显示配置支持显隐、顺序、合法单位、粒度；即时预览，显式保存和恢复默认。

个人偏好使用当前浏览器 localStorage 的 `bsmoss.sample-view.v1`，带 version=1。
这只验证本机体验；账户级持久化、配置发布、正式报告模板及跨设备同步仍待后续实现。

## 样例口径

6 个虚构站址位于西安、宝鸡、咸阳，覆盖五类运营商；日期固定为北京时间 2026-10-25，
与陕西约 11 万站址规划规模分别展示。样例水位为 2026-10-26 08:00 +08:00。

小时源窗口支持小时/日展示；15 分钟、周、月在当前样例中显示粒度不可用，不能生成虚假细分数据。
短信未接入显示空值；一条下行窗口缺失导致总流量标记部分窗口，趋势保留缺口。
空筛选、未接入、缺数、无适用归属分别展示。站址级电耗和设备状态不按运营商关系分摊。
设备状态按窗口末状态分布展示：4 台运行、1 台故障、1 台未知。
样例计算只服务本次纵向切片，不代表 I07 标准化、I08 通用聚合或 I09 周期任务已完成。

## 启动和边界

依赖 Node >=22.18、pnpm 10.30.3。根目录执行 `pnpm install`、`pnpm build`，
设置 `BSMOSS_PRODUCT_PREVIEW=on` 及 `PORT` 后执行 `pnpm --filter @bsmoss/app start`。
本地可使用 PORT=0，由启动输出取得临时端口；固定环境端口须由注册资料提供。
默认绑定 127.0.0.1，不需要数据库。开发模式使用同包 `dev` 命令。

开关默认关闭：样例页及 API 返回 404，根路径只提供未开放入口；开启时根路径跳转到样例页。
该开关不是身份认证，不得以此替代 I05。API 拒绝客户端提交授权字段、非法配置或超过样例长度上限的请求。
当前长度检查在读取请求文本之后执行，真实入口仍需传输层限流/流量边界及可信身份。

Windows 使用标准 Next.js 构建；其他平台配置 standalone 输出。Windows 已构建验证，Linux 打包尚未验证。
本次仅本机预览，不代表 R03 Beta 部署或 R05 上线；没有产品固定端口、域名或远端发布。
