# P16 组织与权限

## 目标与页面

`/settings/access` 作为唯一组织与权限入口，切换管辖范围与成员权限。原 `/settings/jurisdiction`、`/settings/members` 307跳转到对应分类。旧导航标识兼容保留，侧栏和Launcher不再重复列出。使用P15共用配置布局、搜索、筛选、图标重置、游标分页与连续侧栏，不增加统计分析或组织树页面。

## 数据边界

管辖范围读取实际授权站址、服务和设备数；责任组织主档与分配仍待接入。成员展示角色、状态、有效期，侧栏完整展开产品权限以及来源／站址／服务／设备／指标授权，时间统一到秒。当前只供查阅，不增加成员创建、角色编辑、权限授予或主档维护。

继续使用原OIDC会话和正式管理API；是否展示导航不构成授权。列表及详情每次按API权限读取，详情401／403使清单失效并关闭侧栏，避免继续显示已撤销数据。读取失败无旧数据回退，提供重新读取。搜索去除两侧空格以满足严格查询约束；不透明游标原样编码传递。
