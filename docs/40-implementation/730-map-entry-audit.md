## 实现

保留的原生链接统一`target="_blank"`及`rel="noopener noreferrer"`；官方ActionMenu当前仅支持onSelect，因此三个业务行菜单及大屏点位回调同步使用`window.open(url, "_blank", "noopener,noreferrer")`。不改DS接口、不造并行链接组件，其他业务导航继续原行为。菜单“查看时段用量”改“地图时段用量”，使目的地明确。

首页快捷区删除地图卡片后宽屏改三列。所有地图查询参数继续由原构造函数生成，不改变筛选、数据口径、默认选站规则或预览开放边界。全局入口负责进入地图，上下文入口负责从当前业务对象下钻；两类入口职责不同。
