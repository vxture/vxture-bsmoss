# Launcher 三层整理与核验记录收敛

日期：2026-11-10

## 目标与结构

按用户指定顺序，顶部运行总览、综合研判、站网地图；中部运行、运营、经营三域；底部报告中心、数据更新、用量核验。入口名称沿用原导航，不根据分组描述擅自缩写。报告与核验从领域列移至底部；记录不再单列。当前有效入口无重复、无遗漏，待建设项保留禁用。配置管理导航保持原八项。

## 布局与访问

复用 DS15 EntryCard、ShellPanel、Popover 和 Separator。桌面三域等宽，顶部和底部各三列；窄屏域内双列收紧，隐藏辅助描述和待建设徽标，保留禁用语义及样式。统一令牌间距，无新基础组件或视觉系统。修正履约保障、营收分析的无效图标名，使用官方 seal-check、currency-cny。

首项键盘焦点、Escape 触发器恢复、当前页高亮、原地域参数及地图新标签页行为保持。地图仍仅显式预览开放，正式核验仍待接入。导航不替代目的页面授权。

## 核验记录

/usage-review 统一清单和人工记录，默认清单，view=records 为记录。切换保留相同范围与周期、会话、原始依据；记录原因只对记录有效，未知或重复 view、非法会话及原因拒绝。记录默认月范围沿用旧路径，主动切换保留当前周期。

/review-history 仅兼容307，原始参数、重复条件、会话、原因及调查上下文全部带入规范入口；正式关闭继续404。删除无消费者的旧记录包装工作区。更新详情返回链接和调查来源验证，支持规范记录视图与旧记录来源。保留独立 /usage-review/history 经营历史证据路径。

原 IndexedDB 键、会话、事件、幂等及证据不可变规则保持，无存储迁移、权限扩展、后端接口、依赖、DDL或生产配置修改。综合研判重构未在本次实施。

864 项单元测试、63 项 HTTP 检查及生产构建通过。新增测试覆盖三层顺序和唯一入口、规范记录视图严格解析、重复参数保留、调查返回上下文。浏览器18组检查覆盖390／475／577／846／984／1440六种宽度、三层布局、初始焦点及Escape、唯一入口、地域、新窗口地图、同页记录切换和前进后退、实际事件、原因筛选、历史会话、证据返回、旧路径及正式开关。运行与控制台错误为0。验收结果见 artifacts/launcher-qa/checks.json；仅在独立浏览器配置中生成测试核验记录，不触及用户存储。

## Launcher 宽度与留白（2026-11-10）

业务 Launcher 宽度由 container-page-xl（1280px）收敛到 container-page-md（768px），仍受 Popover 实际可用宽高约束。桌面保持顶部三个全局入口、中部运行／运营／经营三域、底部三个工作工具。三域列间隔24px、入口行间隔16px，分组及分隔线上下间隔24px；手机保留域内双列，采用16px外边距与组内间隔，超出可用高度时在面板内部滚动。

复用官方 ShellPanelContent、ShellPanelSection、EntryCard、Separator 与既有语义间距。业务入口显示图标、名称、当前项和待建设状态，移除长段辅助说明，保留可访问描述。原入口名称、链接、地域参数、地图新标签页、禁用项、首项焦点及Escape恢复行为保持。

最终生产构建与类型检查、2项既有导航测试通过；实际服务26组浏览器检查覆盖8种屏宽的明暗模式、键盘焦点与Escape、配置导航和实际跳转。无运行错误和横向溢出，所有名称、唯一入口、地域参数及地图新窗口行为保持。证据：artifacts/launcher-spacing-qa/checks.json及前后截图。本地服务已使用最终构建重启。

纵向密度补正：取消描述后的业务入口显式使用items-center覆盖EntryCard默认顶部对齐；图标与标题垂向中心一致。入口行距收至8px，域标题与列表间距8px，三层间距16px，横向列间距继续24px、面板宽度继续768px。桌面面板高度由628px降至556px，手机由840px降至768px。构建及类型检查、26组实际浏览器检查通过，8种屏宽下图标与文字中心差均为0px；证据见artifacts/launcher-align-qa。
