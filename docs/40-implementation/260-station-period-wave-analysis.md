# 单站周期趋势与波动定位

2026-11-02。本批将日／周／月确定性用量下钻到单站，提供逐日趋势、逐小时定位、同星期参考与可复核波动线索。

## 业务设计

运行检查、经营统计面板各增加“时段／日／周／月”入口。时段保留原10月25日地图小时快照；日取10月25日、周取10月19—25日、月取10月1—31日，均为北京时间半开区间。两个面板可以独立选周期，入口不改变底图、底部信息或品牌布局。

流量、通话、短信分别展示周期总量及相邻完整自然周期变化，月增加日均环比，保留9月30天／10月31天差异。周期总量沿用既有CalendarUsage口径；运营商筛选、行政范围及实际圈选几何取交集，物理总表电耗不分摊。

逐日图选择日期后显示该日24小时趋势，曲线、日期按钮、前后日按钮及小时选择均可定位。显示选定日期合并接通率／负载率和物理总表电耗。历史日期不更新地图日期；仅选定10月25日时提供显式“同步地图小时”操作。

## 波动规则

每个小时取此前7／14／21／28天相同小时的四个样本，中位数作为同星期参考。所有参考均早于被分析样本；参考窗口随当前日期滚动，可以包含本期较早日期，不等于自然周期环比基期。10月1日最早参考9月3日，现有9—10月合成采样器即可覆盖。

逐日参考线是24个逐小时参考中位数之和，不是四天日总量的中位数。曲线实际值、参考值、参考日期和四个原始样本可核查；参考值不得替代真实用量或作为结算依据。

规则默认同时满足绝对变化与相对变化门槛：相对偏离至少15%；流量至少1GiB、通话至少300秒、短信至少20条。上下偏移保持中性。全零参考且本期非零只检查绝对门槛，百分比为空；双方均零不标记；不足四个参考样本时不输出波动判断。

四样本中位数保留中间两个整数之和／2；变化保留`2×本期−中位数分子`／2。计数、阈值比较与排序交叉乘积均使用BigInt，原始值以十进制字符串传输，显示时才换单位和百分比，不先舍入半计数。

按相对偏离幅度提供前8条达到双门槛的小时线索，同时保留全部线索数、影响日期数、上下偏数量和完整逐小时结果，未入榜线索可在日期／小时控件查看。最大偏离也覆盖未达门槛样本，避免将“未发现线索”表述成无波动。

波动仅为规则筛查线索，不代表故障、业务损失或因果。现有交通／园区站样例已存在足够波动；本批不注入异常或修改旧样本，周期报告、贡献排行和旧地图数值保持一致。

## 技术实施

新增station-period-rules纯规则及GET /api/product-preview/station/[id]/period，period=day|week|month，缺省day。沿用地图参数白名单与精确站址范围匹配；关闭演示404、站址不在范围404、非法参数400、过长URL413、成功no-store／nosniff。不开放任意日期、参考窗口或客户端阈值参数。

返回周期用量、自然周期变化、逐日／逐小时实际计数、四样本参考证据、规则版本和线索统计。上下文包含站址、真实筛选范围、周期与规则版本；镜头、地图小时及专题不修改周期结果。采样器和缓存均为单请求范围。

前端station-period-panel与station-period-chart复用现有ECharts依赖。请求可取消、上下文不匹配即隐藏旧结果，失败可重试；线索点击滚动回所选日内定位。周期选择为面板本地状态，刷新恢复时段默认，不伪装成历史地图回放。完整样例标记complete_synthetic，不表示真实来源完成签认。
