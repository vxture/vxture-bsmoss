## 实现范围

经营分析增加同资源、同周期的容量负载、业务接通率、物理电耗与单位流量电耗。容量及能效独立页面支持显式历史模式，完整保留地域、运营商、资源条件、时间窗、单站、参照范围和时段证据；原固定快照页面保留。跨域调查表按当前指标显示前20座，完整清单进入历史报告。

逐日及月度聚合共用calendar-v3。接通率先合计接通/尝试，负载先合计等长小时占用/容量。物理电耗每站每小时只算一次，单运营商不分摊能耗。温度为等时样本均值/极值，备用供电为站时样本数，不等于事件持续时长。关联展示不自动诊断原因或生成维修任务。history模型升v4，测量来源仍calendar-v3。

历史报告覆盖完整资源筛选和分析时间窗，分层与页码仅保留作返回条件。页面包含三业务产出/同比、趋势、区域/运营商/站群结构、分页资源明细、跨域统计及适用单站证据引用；HTML及JSON导出包含全部匹配资源和原始整数、分子/分母、四周参考、范围及来源/模型/模板版本。

报告页规范化到snapshot摘要URL，下载必须携带SHA；内容变化返回409，非法条件/格式拒绝，preview关闭页面和下载404，正式API仍走原鉴权。摘要绑定载荷及发布DS token摘要。HTML转义全部动态内容，JSON以非执行数据块嵌入，无外部脚本/样式/字体依赖；离线样式由构建时打包发布DS运行时token并使用语义变量。无当前电脑时间伪造修订、持久报告发布或审批回执。

省级默认跨域结果构建预生成；只缓存固定合成站址/月，全年不向浏览器分发小时明细。正式读模型、OIDC和来源授权未变化；无新增依赖、DDL或权限。
