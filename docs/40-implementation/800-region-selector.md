# 系统通用区域选择器

## 目标与职责

按用户2026-11-05确认，将省／市／县筛选定义为本系统通用业务组件 RegionSelector。使用已发布 @vxture/design-system 的 Button、Popover、Command 等组件组合，不创建平行基础组件，不修改DS包或全局token。

组件接收最小 RegionCatalog（省 id／name、cities、counties）、受控 RegionSelection（cityId／countyId）和 onChange；不依赖router、地图引擎、合成数据仓库或接口。父页面负责授权数据目录、URL、刷新和筛选提交。当前只提供陕西省，扩展目录不等于开放额外业务范围。

## 交互与显示

一个按钮回显完整路径，例如“陕西省·西安市·雁塔区”。省域仅显示陕西省、市域显示陕西省·西安市；不追加“全部地市／全部区县”。按钮超长时省略，title及无障碍名称保留完整路径。

弹层顶部统一搜索；桌面省／市／县分列、窄屏省份上置及市县双列。点地市仅浏览下级，点区县提交并关闭；全省／全市提供中间层级提交。重新打开按已选范围定位，Escape／点外部不提交浏览状态。搜索名称、行政编码、完整路径和空格／中点／斜线分隔词，结果均带完整路径，支持上下键与Enter，保留无结果状态。

normalizeRegion防止无效上级、跨市区县残留；服务端既有严格校验继续作为权威。组件不把本地刷新时间当作数据水位。

## 采用范围

- 运行总览。
- 容量与质量、运行与能效、运营商用量、用量报告。
- 用量核验。
- 站址管理筛选弹层：更新本地草稿，父层“应用筛选”才提交；地域计一个筛选条件。
- 决策分析：补齐county URL校验、同范围指标／24时趋势／运营商统计、镜头适配及地图跳转。地市对比仍全市口径，县级选择时明确标注；选择对比地市返回其全域。
- 站网地图：替换header三个原生选择框，保留既有选区／比较清理、时段和全画布布局。

业务页面地域变化清除旧空间选区，核验回第一页；运营商、周期及其他查询保留。地图打开方式仍为newtab。独立地域导航树作为站址管理浏览工具保留，不等同重复筛选组件。

## 实现与验证

源码：portals/app/app/portal/region-selector.tsx、region-selection.ts；仅局部业务组合CSS使用DS间距、字体、overlay和media语义token。最小目录不含坐标，避免组件绑定地图库。

纯规则测试覆盖三级路径、非法父子关系、名称／代码／完整路径检索及唯一目录。决策分析测试增加区县数据一致及非法／跨市参数拒绝。构建、HTTP回归和浏览器实际交互结果记入agent memory；截图及可追溯检查在artifacts/region-selector-qa。


## 常态纯内容显示（2026-11-05）

按用户补充，公共选择器触发器采用官方DS ghost按钮：常态显示前置区域图标及地域文字（按用户随后纠正保留图标）；透明边框，箭头透明但保留尺寸。hover／active／键盘focus-visible／弹层展开时显示control-border及下拉箭头；通过DS语义工具类实现，保留官方焦点反馈、禁用语义、可访问名称及点击热区。状态切换不增删边框或箭头占位，因此不引起标题布局跳动。所有采用公共组件的页面同步，无业务查询变化。


## 常态对称留白（2026-11-05，覆盖箭头占位策略）

用户指出隐藏箭头占位导致右侧空白偏多。保留常态透明背景、前置图标与文字，悬停／展开使用官方ghost淡底；取消箭头的文档流占位，触发器仅按图标＋文字和对称px-md内距定宽。交互箭头改为DS xs尺寸绝对定位在原有右侧内距内，不增加右padding、不移动文字，也不改变触发器宽度；原hover／active／focus-visible／展开可见规则保留。仅改公共业务组合类，不更改DS内部样式／token／筛选行为。

## 常态淡底与交互箭头舒展（2026-11-05，覆盖上一节）

用户纠正：隐藏箭头不占位是为了常态背景左右留白合理，显示时需要独立空间，不能挤进原内距。公共RegionSelector恢复常态DS bg-muted淡底；图标常驻，箭头常态display:none不占位，hover／active／focus-visible／展开时恢复sm尺寸文档流布局，文字与箭头使用gap-sm，按钮随内容自然增宽，外侧仍对称px-md。取消绝对定位和强求前后等宽策略，保持透明常态边框及交互边框规则，未改DS内部样式／token或区域筛选逻辑。
