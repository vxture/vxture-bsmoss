# 日／周／月周期分析

2026-11-02。本批在既有单日地图与日报基础上，扩展确定性周／月用量核查、报告和离线下载。

## 周期设计

- 统一Asia/Shanghai及[start,end)。日报保留2026-10-25，24个小时；自然周为2026-10-19至10-26，7个完整自然日；自然月为2026-10-01至11-01，31个自然日。
- 多日合成快照固定截点为2026-11-01 00:00，不依赖机器当前时钟。地图回放仍是10月25日，周／月面板明确展示独立统计窗口。
- 这是固定历史演示周期，不开放任意日期或自定义周期；后续真实查询、周期调度与数据水位单独推进。
- period-rules为纯规则；calendarSampler按日期、星期、站址类型和运营商产生确定性差异，保留原10月25日所有小时数值。周／月不能用单日总量乘天数代替。
- 样例中每站的运营商关系在整期内固定，不冒充真实服务启停窗口。每站逐日逐小时取样，物理站数去重、服务关系数不乘天数，站时样本数另列。

## 指标与精度

- 周／月提供通话、流量、短信总量与日均值；日均分母为完整自然周期天数，日均值不是整数事件计数。
- 运营状态先合并接通／尝试、占用／容量，再计算比率。容量保持场景归一化单位；不平均百分比。
- 运行参数包括物理总表电耗、温度样本、备用供电站时观测。单运营商电耗始终null；不按流量、服务关系或运营商数量分摊。
- 全省1080个样例站月流量超过Number.MAX_SAFE_INTEGER。周／月字节原始计数以BigInt累加，bytes／upBytes／downBytes在JSON中统一使用十进制字符串；其他整数计数经安全整数检查后输出number。
- 图表／GiB为显示换算，可使用浮点数；原始证据与合计核查使用字符串／BigInt，不能用展示值回写或判断守恒。时／日接口的既有number结构保留。
- 峰值按同日期同小时的站群实际合计取最大，保留日期与小时；不累加各站各自峰值，不把跨日同刻累计当作同时峰值。
- 周／月日明细、运营商构成、站址排行、运行参数和下载均共用同一地域／县区／运营商／检索／真实几何交集。相机bbox、地图小时、专题不改变周／月范围或报告引用。
- 当前不提供同比／环比基期，也不输出推测变化率。费用只预留，退服影响继续P2。

## 接口、页面与下载

- /api/product-preview/operators增加period=week|month；原hour／day兼容。新增queryCalendarUsage适配器，不改变旧单日纯规则入口含义。
- /api/product-preview/reports增加period=day|week|month，缺省仍为day。日结果保留既有内容和标识；周／月使用DEMO-WEEK／DEMO-MONTH引用、独立模板及规则版本。
- date只接受原样例锚点2026-10-25，不允许任意日期、重复period、未知周期或伪造范围字段。开关关闭404；合法响应no-store；HTML下载重新校验范围并保留CSP／nosniff／attachment。
- 报告周期按钮为日／周／月；运营商核查为时／日／周／月。URL report=day|week|month、usage=hour|day|week|month，刷新恢复，各面板保留自己的周期选择。
- 周／月独立浮窗复用概览／运营商分项／口径证据章节；逐日堆叠柱可选择某日查看构成，不切换地图日期。切换周期或范围取消旧请求，以上下文键阻止旧结果及错误范围下载。
- 概览提供三类指标、逐日趋势、同刻峰值与站址排行；证据页显示真实原始字节、样本数、规则版本和窗口。手机端压缩卡片，章节与范围变化复位内容滚动位置。
- 新HTML离线报告保留完整逐日明细、运营商分项、六类章节、原始计数、窗口与几何。动态文本转义，无脚本／远程依赖。
- 样例sampleStatus=complete_synthetic只表示已生成完整样例窗口；不等于真实来源签认、正式complete、报告持久化或发布状态。报告仍为demo／draft。
