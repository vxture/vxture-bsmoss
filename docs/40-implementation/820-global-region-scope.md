# Header全局区域与跨板块记忆

## 已确认规则

区域选择提升到header，替换功能域名称；页面标题、副标题、时间及全局操作保留。业务页标题旁不重复区域选择器。沿用公共RegionSelector的三级级联、名称／编码搜索、区域图标、常态淡背景和箭头舒展交互。当前目录仍仅陕西。

- 总览、决策分析、站址台账、容量质量、能效、运营商用量、用量报告及核验列表使用同一地域上下文。launcher和品牌返回入口显式携带city／county，地图继续newtab。
- 没有区域参数时，服务端先读取记忆，再生成同范围数据，避免仅改变标签；显式URL优先，包括all／all。只指定city时不能混入旧县，非法／重复参数仍走既有校验，不静默修正业务范围。
- 以一年期、SameSite=Lax、HTTPS下Secure的第一方cookie记忆。正式登录按sub／组织／工作空间组合的SHA256摘要隔离cookie名称，不写入凭据或原始身份；预览访客使用独立preview名称。偏好不授予访问权限，正式服务仍独立校验授权范围。损坏／外省／父子不匹配的偏好回退全省。
- 当前页面URL补齐明确范围，用于刷新、复制、新标签及历史回退。站址地域树通过显式URL与header同步；筛选重置只重置业务条件，保留区域。切区域清除分页、检索、站址、选区、对比和不适用报告版本，保留适用的视图／时间／周期／运营商等条件。
- 单站档案及核验详情展示对象真实归属，不修改为全局区域；header改变区域时返回对应列表。直接查看某站不会把站点归属写成全局选择。固定档案的来源时间和经营事实不变。
- 配置管理展示／记忆区域上下文，但不按地域过滤系统配置。正式周期分析和报告中心继续授权门槛；现有正式API未提供行政地域筛选契约，本次不伪造过滤结果、不加载合成目录到正式环境。接入授权目录和读模型之后再扩展正式过滤契约。
- 全画布地图在自身header沿用同一组件及偏好命名空间。无参数打开地图时继承记忆，首次摘要和站数按范围生成；地图修改区域后业务页可继承。区域变更清除不适用选区／对比／站址，默认仍不选站。

## 实现与验证

纯规则region-scope负责偏好编码／解码、缺省继承及区域导航；region-preference在服务端请求内缓存目录、身份隔离键及偏好；useHeaderRegion负责当前URL、cookie及header交互。目录投影仅发送省市县必要字段，不把完整站址资源送入chrome。新逻辑不引入依赖、DDL、业务权限或新数据来源。

生产build含类型通过tmp/header-region-build.log。16项区域／台账规则测试通过tmp/header-region-unit.log；32项HTTP边界通过tmp/header-region-http.log，其中新增cookie首屏范围、显式链接优先、all重置及父子错误不被记忆覆盖的回归。既有关闭预览、授权入口、导出和严格查询边界均通过，不重复PG。

浏览器证据在artifacts/header-region-qa：

- 雁塔区选择后launcher各业务链接均带同县，容量实际观察16站；刷新保持。无参数访问总览、决策、站址、能效、用量、报告、核验、正式门槛和配置，共10个入口保留同一区域。
- 配置改宝鸡不改变settings路径，返回台账140站；显式雁塔链接优先，地域树选长安后header与62站同步，业务筛选重置仍长安。
- 查看蓝田县站址档案时header仍保留原分析范围，档案归属显示蓝田；切全省返回台账1080站。
- 无区域参数的新地图标签继承雁塔、首屏16站／0.68TiB，无默认选站；地图改宝鸡后总览继承宝鸡。
- 1280／904／390，5页共15组，无文档或header横溢，每页唯一H1和唯一区域触发器。手机使用截断文字、title及完整弹层路径；紧凑header优先保留品牌、区域、配置及用户入口。warn/error空。
