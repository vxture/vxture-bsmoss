# 报告库、文件版本与下载贯通

2026-11-06。接续用户“继续下一批”，按B02及设计237实施。B02-01/02复用BA01–BA04已有历史分析、日周月口径和三业务聚合，本批完成B02-03/04本地留存与调查互链，不重建生成引擎。

## 业务结果

显式preview下，报告中心读取本浏览器实际保存的完整报告包。日、周、月用量报告和历史经营报告新增保存入口；服务端只生成文件，不写报告发布、审计或服务器归档。页面看到的报告JSON摘要必须与保存请求一致，内容变化返回409，避免点击期间保存另一份报告。原HTML/JSON与精确计数、完整范围、来源和模板版本一起留存。

文件内容SHA标识不可变版本，同内容重复保存不更改原保存时间；同范围/周期、不同展示内容集中显示为独立文件版本。SHA只用于一致性，不代表业务签认或真实来源背书。保存时间为实际本机操作时间，与数据区间和来源水位明确分开，无虚构发布人、修订人或调度回执。

报告库支持Header区域、运营商、日/周/月/历史类别和关键词筛选。精确版本可刷新重开，从留存内容下载原HTML与JSON，不重新计算。当前来源报告与原分析条件提供独立入口，最初调查仍可返回，经过核验后也保留原版本定位；不同来源不转移结论。主动Header换区域清除旧版本和调查，地图沿用新标签页规则。

## 存储和正式边界

原生IndexedDB固定DB/schema，事务complete后才提示成功；并发相同内容幂等，写失败回滚，跨标签仅通知重读。每包上限24×1024×1024字符、最多50条、总内容64×1024×1024字符；浏览器仍可因自身配额拒绝写入，不能把字符限制称为文件字节配额。损坏、未知schema、不可用和满额显式失败，不清空旧数据、不显示假成功，无删除入口。

仅接受固定合成dataset、严格报告包字段、摘要与内部链接。留存HTML仅作为下载文件，不注入页面执行。GET artifact仅在preview开放，重复参数/非法范围拒绝，未提供POST写API。preview关闭时正式/reports、OIDC与/api/reports保持原路径，正式401/失败不回退合成。无依赖、DDL、PG权限或真实来源变化。
