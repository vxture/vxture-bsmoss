# 陕西地图工作台与悬浮交互修订

2026-11-02。当前产品/演示仅服务陕西首个客户，全国仅是内部地域架构扩展能力。
无其他省份、全国入口或省份切换，没有真实接入、远程部署或数据库迁移。

## 工程与数据

保留 Next.js 15、React 19、pnpm 与 yucer 分层，新增 MapLibre、ECharts、Zustand、Lucide。
`domains/map-demo/types/resources/rules/service` 分开定义地域、合成资源、小时指标与查询。
`scripts/build-demo-geography.mjs` 从本地地市边界生成固定种子/版本的 1,080 个模拟站址，覆盖陕西 10 地市。
六类场景为商圈、交通枢纽、园区、山区供电、能效观察、多运营商共享；固定日期 2026-10-25，原生小时窗口。
多运营商计数独立归属，接通率合并分子分母；物理总表电耗不自动分摊。
地域通过 ID、父级、名称、中心、范围和边界配置；当前服务只接受陕西。11 万仍为陕西规划输入。

## 页面与接口

`/product-preview` 改为全幅地图；原三类配置页保留于 `/product-preview/metrics`。
新增 `/api/product-preview/map`、`/api/product-preview/station/[id]`，预览开关关闭时均返回 404。
演示接口只读合成资源，不接受客户端授权字段，校验地域/时段/运营商/bbox，响应禁止缓存。
摘要及排名是选定地市/全省和业务筛选范围，点位按视口返回，最大 1,500；当前样本不是 11 万性能证明。

用户反馈首版过于看板化后调整：

- 地图固定覆盖整个窗口，产品/地域/时段状态采用轻量叠层。
- 图标工具栏、图层面板、单站详情悬浮；面板默认收起，点位有轻量提示卡。
- 侧栏展开不改变地图容器尺寸，只调整镜头 padding；窄屏仍保持地图全幅，面板内部滚动。
- 移除默认大标题、大号样本计数与重复说明，详细解释进入完整分析和说明弹层。
- 底部为当前快照驱动的连续站网动态，可暂停、悬停暂停、点击定位。
- 时间回放、主题与双主线详情联动，旧上下文请求取消；个人图层偏好本地保存。

## 静态资源

worker/shared 模块通过 `prepare-map-assets.mjs` 随 dev/build 本地准备；地市边界与数字字形随包。
默认 OSM 标准底图，Esri 卫星影像按手动切换懒加载，可切换倾斜镜头。在线底图不可用时保留本地边界及分析。
原 CARTO 无令牌端点实际返回 API Key 水印，已替换。
资源及许可说明见 [地图资源](../30-design/ops_bsmoss_160_map-assets.md)。

## 省市县与独立分析面板修订（2026-11-02）

- 顶部省／市／县级联：省选择仅有陕西；覆盖 10 地市、107 个公开边界区县单元。切市清县、筛选清选站，县级上下文写入 URL。
- 地图按地市加载县界，高亮所选县并适配视野；URL 首次恢复直接定位县域，避免初始化镜头动画相互覆盖。
- 两个演示 API 共同校验 cityId/countyId 父子关系，地图摘要、排名、点位和单站限制共同使用县级范围。
- 生成脚本通过 Polygon/MultiPolygon 外环与孔洞判断归属区县；保留 1,080 站及精选站坐标，资源版本不变，县级归属是地理补充。
- 运行检查／经营统计拆为独立窗口，分别关闭／放大；可并排打开，保留整个窗口替换入口，共用站址、时段、运营商上下文。
- 单窗 470px，双窗各 360–440px；宽屏利用右侧高度，时序移至左下，去掉重复底部展开入口，关联提示横排。
- 1440×900 浏览器实测：双窗各约 403px；运行常用窗体仅约 1px 舍入滚动，经营窗约 32px 滚动。地图容器仍为 1440×900。
- 390×844 实测省／市／县均在视口内，单次聚焦一窗并保留另一窗状态，页面无水平／垂直溢出。

新增 4 项有效测试，263 单测通过（区县总计守恒、父级校验、独立窗口状态与镜头空间）。
生产构建、双层类型、7 项 HTTP 测试（6 子项＋父项）通过，县级 API 和静态边界已纳入验证。
文档编号／交付／SCA一致性与30表静态镜像守卫通过；未改数据库或正式接入，不执行迁移或外部部署。

## 地图矩形分析（2026-11-02）

新增 geometry、area-rules 纯规则与选区服务过滤，沿用 rules/service/store 分层；不增加依赖或数据库表。
工具栏框选入口支持拖动、两角点及当前视野，地图显示半透明填色与虚线边界，Escape／取消恢复旧选区。
区域分析为 370px 悬浮窗，镜头适配浮窗但地图容器不变；提供三类指标、24 小时流量、运营商构成及重点站点下钻。
服务过滤与单站详情共同限制选区，摘要不随镜头改变；上下文指纹屏蔽过期点位和分析，检索空白标准化。
选区写入 URL，可与省市县／运营商／时段一起恢复；无 site 参数时不自动选中默认站点。

新增 6 项行为测试，总计 269 单测通过；最终修订后区域 5 项回归通过。双层类型检查、生产构建和 8 项 HTTP 测试（7 子项＋父项）通过。
浏览器已实际拖出雁塔区 14 站选区，验证移动／12 时联动、共享电耗未分摊、重点站点下钻、返回区域与取消重画。
补验两角点生成选区、清除选区、链接刷新恢复及空选区提示；全省空选区不会默认选中无关站点。
390×844 DOM 检查：浮窗宽 290px、左 51px，页面宽高无溢出；桌面地图容器保持全幅。
最终选区截图保存在 artifacts/map-workbench/spatial-area-analysis.png。当前为合成演示数据，未部署或执行数据库迁移。
文档编号、交付、SCA一致性和30表静态镜像守卫通过；SCA一致性仅核验扫描配置，不代表在线漏洞扫描。
