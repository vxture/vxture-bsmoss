# P15 数据接入配置

## 目标与范围

将数据来源、对象映射、来源版本收敛到 `/settings/data-access`，以 `view=sources|mappings|versions` 切换。配置管理侧栏、Launcher、管理总览共用唯一入口。原 `/settings/sources`、`/settings/mappings`、`/settings/audit` 以307跳转到对应分类；未知或重复分类回数据来源。

复用官方DS15与既有site-analysis布局：图标分段组在左，搜索、筛选、重置和已有新增操作在右。控件32px、正文14px、操作行48px，组内8px、组间16px；窄屏操作行与表格局部横滚。行或名称打开连续非模态侧栏，同一行关闭、其他行切换、空白与Escape关闭，保留完整来源与版本依据。

## 数据与交互

显式预览模式仍使用原本机配置存储、校验与版本冲突检查；支持实时、回车、中文输入法搜索和10／20／50／100页容量。保存失败保留草稿，并发修改阻止覆盖；重置清理当前查询筛选并重新读取。来源版本不伪造本机审计，继续使用正式身份与API。

正式来源和映射沿用原授权API、只读列表及已有预检、定位预览、接入影响与完整证据。列表沿用服务器不透明游标，不伪造总数或可变页容量；搜索编码保持安全。切换查询、翻页清理旧选择；失权清除受保护数据，失败显示重新读取入口。没有新建接入器、数据库结构、正式同步或配置写入权限。
