## 实现与业务边界

数据接入组增加“对象映射”（/settings/mappings），管理侧栏／总览／launcher同源，官方DS组件与全局标题、留白规范保持。读取真实source_mapping与关联站址／服务／网络对象／设备，按外部对象、来源及业务目标检索，按主目标类型筛选，keyset翻页与详情。支持服务与设备同时关联，详情完整列出，主类型不覆盖或修改底层关联。无正式会话显示身份门槛，不回退合成配置。

来源transformVersion和对象mapping.version独立，目录不宣称一致；source_mapping是当前存储的定义，可有过去与将来区间，不是配置历史审计。有效期为左闭右开区间，服务期覆盖检查按UTC六位微秒比较，字符串版本保留numeric(30)精度。未完整覆盖保留真实提示，服务用量仍需按交集和接收规则验证，不把定义检查说成指标兼容或数据验收。网络对象类型按中文显示，日期正文按本地时间显示，time元素title和dateTime保留精确UTC边界。

新增独立admin.mappings.view与两个GET管理接口。来源查看、ingest、owner均不隐式赋权，机器拒绝；身份和平台门先于参数解析／读取。SQL先完整过滤租户、来源、站址、所有关联服务和设备，无服务且无设备的物理映射要求allowSiteParameters；再搜索、类型、C排序与LIMIT。网络对象权限由原服务关系限定，复合关联再逐条校验。映射无指标字段，不伪造指标授权或兼容性。

存储使用只读可重复读事务，逐条和lookahead校验，损坏定义整页失败，错误回滚释放。完成后重验主体、工作空间、完整scope、权限和有效期，空页与missing详情也重验。GET返回no-store／Cookie Vary／nosniff，404保持安全且不改变原成员／来源协议。客户端取消过时请求，切筛选立即清旧结果，详情401／403清整页及Drawer，仅显式重读恢复。

空库baseline只补1项权限目录种子，无角色赋权、无新表或Prisma变化，仍67表；DDL仅应用于随机专用本机合同库，没有改业务数据库或迁移。无配置写入／启停／连接测试，不写原量或推进截至；数据接收与更新仍属业务域。
