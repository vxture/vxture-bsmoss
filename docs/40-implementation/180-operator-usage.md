# 运营商使用核查

2026-11-02。按用户要求将退服影响分析置为 P2，暂缓开发，先推进确定性业务。
本批沿用陕西合成场景、yucer rules/service/store 边界和全幅地图，无 DDL、数据库、迁移、依赖或外部部署变更。

## 实现

- `operator-rules.ts`：小时／全天的整数计数、物理站址／服务关系、合并分子分母、时间窗和证据版本；不做费用或退服推断。
- `service.ts`：地图与使用核查复用服务端站群筛选；镜头 bbox 与结果范围分离。
- `/api/product-preview/operators`：独立演示开关、周期白名单、重复参数及未知字段拒绝、no-store。
- `operator-panel.tsx`：独立浮窗，展示运营商分项、合计、24 小时结构、原始计数和物理总表电耗；窄屏表格内部滚动。
- Zustand 和 URL：`usage=hour|day` 恢复，面板互斥保留选区与对比清单，取消旧请求并核对上下文。

全天为固定样例日 2026-10-25 的完整 24 小时；合成站时样本不等于真实采集覆盖率。
业务分项守恒仅为本演示内核查，不是上下游对账通过。容量是合成场景归一化单位，无实际资产规模含义。
共享站数、等长样本负载和电耗边界详见 20-specs/80-national-map-demo.md。
