# P18 全站收敛与阶段验收

## 阶段边界

P15至P18原计划为本轮迁移收尾批次。用户随后指出 Launcher 的经营分析 `/analysis` 尚未迁移，核查属实；本记录的验收覆盖不包含该工作区，不能据此宣称全站迁移完成。补漏范围和验收见[实施279](ops_bsmoss_279_business-analysis-migration.md)。缺少正式来源或大模型依赖的能力后续另立接入任务。

| 批次 | 结果 | 入口 |
| --- | --- | --- |
| P15 | 来源、映射、来源版本合并为数据接入 | `/settings/data-access` |
| P16 | 管辖范围、成员权限合并为组织与权限 | `/settings/access` |
| P17 | 模板读写流程迁入统一布局 | `/settings/templates` |
| P18 | 导航去重、旧入口兼容、共用样式与全站回归 | `/settings`及现有业务入口 |

## 清理与统一

管理导航、Launcher、管理总览共用入口。去掉重复成员、映射、审计独立项和过时迁移进度卡；保留旧地址兼容，删除失去消费者的模板样式。运营主体、来源／映射预检及预览表单统一控件字号尺寸。业务层只复用DS15与site-analysis，不新增按钮、卡片、表格基础组件或CSS体系。正常工具行只有一个重置，重新读取仅在读取失败时出现。

全站HTTP冒烟断言按已批准的P3至P14最终页面行为修订，保留正式API、严格查询、报告摘要、越权和预览开关校验。历史地图选区分析与历史报告继续保留，不为通过新断言删除旧功能。

## 验收记录

验收日志与浏览器证据在 `tmp/p18-*.log`、`artifacts/p18-closure-qa`。完整单元测试859项通过，最终HTTP冒烟62项通过。生产构建与类型检查通过，最终浏览器回归覆盖21个业务／配置入口及390／475／846／1440四种屏宽，含未接入状态共89组，页面无横向溢出、无运行／控制台错误。配置预览13组、正式界面24组及外观偏好2组通过；正式界面9次模板写请求全部在浏览器拦截，不执行真实发布。

配置预览验证来源／映射保存与刷新、存储失败保留草稿、并发冲突阻止覆盖、实时查询、重置、页容量与连续侧栏。正式界面验证不透明游标完整传递、成员角色与范围、失权清除列表、读取失败重试、发布／默认版本切换结果未知时重试同一个命令、修改后校验失效、冲突重读、无效JSON保留、403禁止编辑以及四种屏宽控件32px／字体14px／操作行48px。

全站回归另发现原根主题组件在挂载后切换key，重复重建流式渲染的页面树，导致运行监测偶发hydration不一致。移除重复key重建，继续使用DS15原有偏好恢复；不修改设计系统、主题token或地域导航。独立验证深色／紧凑／大字号在刷新后的实际样式和偏好选中值一致，恢复标准后再次通过；最终89组全站回归无错误。

测试使用私有浏览器配置及独立本地服务；预览配置保存仅落测试浏览器，正式管理读取和模板写入采用请求拦截，不修改用户浏览器存储或正式配置。缺少正式会话的监测参数依赖应在显式预览且OIDC关闭的测试服务验证，不将无权限的参数读取当成可用数据。

## 后续接入条件

- 客户平台站址／设备同步、责任组织主档及权限管理，等待正式身份、授权数据与接口联调；现有只读或待接入状态不视为完成平台集成。
- 数据来源、对象映射、模板发布的正式执行沿用已有服务权限和存储条件，独立测试不替代真实环境验收。
- 大模型趋势研判与依赖缺失来源的需求、服务质量、履约、营收和成本能力继续暂缓；不制造分析结果或新增空页面。
- 原经营分析的样式迁移属于本轮遗漏，必须补齐；经营历史、报告正文、历史文件和本机留存继续可用。保留旧入口不等于完成迁移。

本轮不提交、推送、外部部署，不变更DDL、平台权限目录或生产配置。
