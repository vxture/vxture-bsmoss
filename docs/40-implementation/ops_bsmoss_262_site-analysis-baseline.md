日期：2026-11-08。用户确认按“先沉淀客户使用，再迁移共享利用”实施。

## 复用范围

沿用已安装的官方 `@vxture/design-system` 15.0.0，不新增按钮、卡片、表格基础原语，不修改全局 token，不同步覆盖其他项目的 DS。

`portals/app/app/site-analysis/` 提供本站业务组合：

- `workspace.tsx`：全宽标题、分析筛选、表格操作行、列表/卡片、实时搜索、分页、站址详情。
- `site-analysis.css`：以上组合的尺寸、排布与状态样式，全部以 `site-analysis-` 作用域隔离。
- `summary.tsx`：紧凑图标统计；指标名称、数值与单位由业务传入。
- `model.ts`：既有站址与关联资源快照读模型，客户使用保持原查询契约。

`AnalysisPresentation` 只接收页面标识、文案、指标、可选业务列及口径说明；概览通过渲染槽传入。通用组合不导入客户使用或共享利用的计算规则。运营商入驻分布仍归客户使用；共享结构和共享率分布归共享利用。

客户使用已改为使用这套组合，外观和操作不因抽取改变。共享利用是第二个消费者。其他页面后续逐个迁移，不一次性全局套样式。

## 共享利用口径

路由 `/sharing`，Launcher 经营域“共享利用”接入正式页面，页面与入口同用 `sharingIcon`。旧 `/capacity` 仍为容量质量，不改名、不撤销，其余待迁移入口继续显示。

`domains/sharing/rules.ts` 为纯规则：

- 按站址编码去重；同站重复记录合并运营商，同运营商重复关系去重。
- 铁塔是资源提供方，不计入入驻家数；有实际入驻关系的新服务商才参与统计。
- 入驻站址：至少一家运营商入驻的站址。
- 共享站址：至少两家运营商入驻的站址。
- 共享率：共享站址 / 入驻站址。
- 平均入驻家数：去重站址—运营商关系数 / 入驻站址。
- 共享结构：一家、两家、三家及以上；空分母的比率显示 `--`。

分析范围由地域、运营商和可用快照决定。选择运营商限定“包含该运营商的站址”，仍使用其全站入驻结构。表格搜索与精确家数筛选只改变明细，不重新定义概况、结构及区域共享率的分母。区域按行政编码升序，省→市→县→单站址，县级仍保留进度条与数值。

当前首版继续使用显式本地预览快照；正式环境显示数据待接入，不回退合成数据。只反映观察到的入驻关系，没有合同有效期、可出租能力或历史变化依据，不计算出租闲置、增租机会或虚构趋势。
