## 实现与口径

新增 `topic-rules.ts` 纯规则，按容量与质量、供电保障、能效观察输出严重／关注／平稳／未知，版本为
`bsmoss-demo-topics-v1`。阈值、分母未知的优先级及能效单位见 [地图规格](../20-specs/80-national-map-demo.md)。
规则仅用于合成场景观察，不生成故障诊断、节能金额、费用结算或现场操作指令。

服务复用现有 map 查询，按地域、区县、矩形选区、运营商、检索条件的交集构造同一站群；
每小时重新判定，汇总计数、地市分布、关注站业务量、最多 6 站优先核验列表。镜头 bbox 不改变分析。
关注站业务量不是损失流量；物理站址去重，单运营商电耗未分摊保持未知。

前端新增紧凑专题浮窗，包含三专题切换、四类计数、显式规则、24 小时交互柱、前 4 地市及前 4 站证据。
小时柱联动统一时间并暂停回放；地市分布可下钻；重点站点可进入单站运行检查或加入对比。
专题与区域／对比／单站面板整块切换，保留选区与对比清单；地域变化按原规则清理旧几何和站点。
URL 保存专题并与选区、对比 IDs 一起恢复，专题优先展示，非法专题忽略。

地图按专题结果着色，聚合点使用严重／关注／未知计数；专题期间隐藏热力、对比序号及旧选中提示，避免颜色混用。
全幅地图只调整相机 padding，不挤压容器。保持默认标准底图，影像仍仅用户手动点击后加载。
专题继续受原 `BSMOSS_PRODUCT_PREVIEW` 开关控制，不新增公开业务入口或数据库写入。
