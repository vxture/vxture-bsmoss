# I09持久队列与原子单步刷新

2026-11-02。承接290窗口纯核心与310组合完成证明，本批仅内部实现，无真实接入或外部部署。

## 代码

- refresh-jobs：可信快照到稳定任务身份、目标字段限制、租约／重试边界。
- pg-refresh-jobs：有界三元组范围、并发去重／抢占、数据库时间、续租／过期／重试／dead及不可变回执。
- refresh-execution：每次按data访问面重新解析平台与产品权限，重新加载最新快照和结果head，调用带租约的聚合store。
- pg-store：可选租约绑定；锁任务后原子提交结果、outbox、回执和任务状态，重复结果也能原子确认；失败全部回滚。
- baseline／97／98／Prisma：新增2表，当前33表；97既有analysis INSERT覆盖任务和回执，98新增严格队列列更新授权，不改证据权限。仅空库初始化，无旧库迁移。

## 验证

4项纯规则测试覆盖稳定身份、同对象不同anchor去重、可信快照不匹配、目标字段注入、参数上限、原始错误拒绝及授权范围拷贝。PG验证真实并发去重／抢占、不同workspace与三元组隔离、续租、重试延后与dead、适配器重建后过期接管、旧token拒绝、只读身份列与不可变回执、结果／outbox／回执事务、重复执行不增加outbox、回执失败回滚、并发修订的head冲突及锁等待后过期。

所有数据库测试仅使用专用本机PG创建的随机bsmoss_contract库，运行适配器SET ROLE bsmoss_svc。日志tmp/queue-{unit,db,types,build,http,prisma}.log和忽略目录内检查点为本轮复验依据，最终计数见agent记忆。不以本地契约替代真实服务身份／容量／业务验收。
