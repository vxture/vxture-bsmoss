# B01用量核验详细设计与共用基线修正

2026-11-04，B01-01。配套[业务规格90](../20-specs/90-usage-verification.md)、[技术设计235](../30-design/design_bsmoss_235_usage-verification.md)。

## 交付范围

已核对yucer证据工作区、业务复核和时间线交互，以及本产品波动规则、来源质量、正式授权、独立分析与导航。定义两个专业模块的职责、三层分类、独立于流程状态的证据有效性、逐小时持续零量、原量／基线／质量依据、查询与事件契约、本机隔离演示存储、正式权限接续及U01–12验收样例。状态为待核验、待复核、已复核三种，证据变化为独立标记，不另加一个会吞掉原状态的“失效”状态。

发现规格60要求至少3个有效历史样本，而evaluateWave仅4样本可计算。已扩展同一函数接受3／4：三样本中位数使用2倍中间值，四样本仍中间两数之和，统一分母2；双门槛、等号命中、超大整数与零基线语义沿用。不足3或超过4仍insufficient，非法计数仍拒绝。辅助函数只接受调用方已验证可比的样本，不在纯计算中伪造质量或来源完成依据。

STATION_PERIOD_VERSION更新为v2，使共用规则语义及新生成报告标识可追踪。既有四样本合成结果不变，旧版本输出及已下载HTML不被改写；本次无模板／DDL／权限／依赖变更。
