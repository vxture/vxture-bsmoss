## 3. 权限、持久化与边界

可信服务端先按授权区域、站址及品牌投影事实和具体客户，再形成读模型。服务关联站址不依赖当前入驻品牌反推，防止用当前品牌覆盖历史服务归属；无关具体客户名称也从受限载荷移除。捕获的品牌范围随载荷冻结，未捕获的品牌返回未知，不把完整性标记误当成全品牌已知零。查询不能传入工作区或授权。页面只向客户端传当前页事实及聚合，后台清单API不包含服务事实。

本地FileStore将服务载荷单独按内容哈希保存，清单和服务载荷原子写入。重启恢复原版；哈希错误或缺失载荷拒读，不重新播种。同步失败不发布半批，旧服务载荷及原物理版本保持可查。未执行DDL、正式存储接入、组织授权扩张、外部部署、提交或推送。
