## 页面与入口

新增两条路由，分别不超过三个页签：

- `/tower-service/sync?view=plans|snapshots|logs`：同步计划、快照版本、日志校验。可手动同步、编辑本地计划、查看版本及校验详情、失败重试，并打开固定版本资源或与前版比较。
- `/tower-service/rules?view=agreements|judgment|access`：计量协议、研判规则、组织权限。计量与共享口径共用一个版本列表；客户／服务目录为编辑侧栏，不增加新板块。组织页只展示范围并链接原权限页，不授予真实用户新权限。

使用现有PageHeading、PanelCard、SegmentedControl、DataTable、配置查询／侧栏、Button、Input及NativeSelect；不新增CSS、组件原语或主题。原数据更新和原分析规则页提供新底座链接，原Launcher名称／顺序／URL不变，T08才切换主导航。

## 发布与幂等

本地预览使用独立HTTP-only随机会话，服务端根据会话构造隔离工作区，客户端不能传workspace、grants或授权范围。预览写API仅在显式预览开启、loopback且Origin一致时开放；正式关闭时API不开放，也不返回演示载荷。当前无正式生产适配，不能以这套本地预览替代平台授权。

每次成功同步形成独立run和时间戳版本，业务存量时点仍为来源原时点；同一原时点再次同步是修订，不是新增业务量或历史趋势。重放相同请求键返回原run。定时按计划到期槽去重，成功后推进下次时点，失败保留校验且暂停计划；重试保留旧失败run并按请求键幂等。

捕获后先检查身份去重、设施归属冲突、必填字段／品牌编码、来源范围／时点以及源声明的站址／设备数。失败不追加可见快照；成功将完整载荷、清单、校验及审计在同一次受锁写入中原子切换。相同载荷按内容哈希复用，run及版本身份分别保留。重开文件仍读取原载荷；损坏文件拒绝读取，不自动重建覆盖历史。

本地文件适配在仓库忽略目录`tmp/tower-foundation/`，按工作区哈希分目录，位于`.next`之外。没有执行DDL、启动建表或配置生产数据库；正式快照清单和规则存储仍需后续受审适配。正式身份、权益和组织范围没有适配时保持关闭，不从请求接收授权。

定时宿主为`scripts/tower-preview-worker.ts`，需显式`BSMOSS_PRODUCT_PREVIEW=on`独立启动，只扫描本地预览工作区的到期计划。Next应用启动不建表、不拉客户平台、不自动启动生产定时器；本地宿主停止则计划暂停，页面不宣称生产计划已接通。

## 规则与范围

每次修改追加同系列新修订，不覆盖旧草稿／生效版。启用需具体客户标识属于同运营商目录、确认状态、原文引用、计量边界及有效期间；共享还需不重叠的租户档位、锚定条件和月中变化口径，研判需关注／严重阈值。相同客户／运营商／服务／规则类别／重叠区域及期间不能同时生效；不静默选择最新版。广电、其他没有默认计量或共享规则，仍需逐项确认。

目录支持添加具体客户及服务项目；服务允许单位从非金额量纲字典选择，规则只能引用存在的服务／单位。候选塔类、室分、传输、电力保障只是设计目录，没有据此生成已交付服务或已确认协议。共享系数按整数基点保存，本批不据此折算数量、电量或金额；租户月度事实与实际档位匹配在T03/T05落实。研判规则存储和版本在本批，业务命中与报告固定版本在T06。

服务边界按可信工作区、动作、有效期、省／市、运营商及站址列表求交；缩小范围时同步移除未授权品牌、设备、关系及全量校验数字，不只隐藏表格。真实组织层级和用户授权页面继续沿原权限实现，本批不修改平台角色或成员范围。正式适配必须先完成平台身份／权益及动作授权，再将范围提供给此服务。
