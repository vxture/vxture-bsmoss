# I08 设备瞬时值持久化

2026-11-03。[设计203](../30-design/design_bsmoss_203_gauge-persistence.md)。内部数据链路切片，未部署上线。

## 实施

字典新增第12个planned定义：设备环境温度、degC、gauge、不相加。测量服务校验fixed_point整数精度，物理设备拒绝服务／网络归属。gauge-period纯规则绑定来源审阅策略、有效映射网格、最高事实和质量、精确均值／极值、完整性和全对象完成证据；时间等价表示规范化，策略缺时长依据明确拒绝。

新增pg-gauge-snapshot、gauge-service／store和pg-gauge-store，复用结果事务仓库，接入可信刷新和正式单对象查询。DDL增加gauge_value约束，Prisma标量同步，仍36表空库基线。输入策略错误纳入持久source_unavailable退避分类。地图合成数据仍为11项，不伪造新温度样本。

## 验证

416单测（新增7项）、141项实际PostgreSQL报告测试（140子项＋父项，新增8项）、双层类型、生产构建、Prisma validate通过。新增PG验证运行角色下有符号53位以上精度、幂等与只读查询、确认／撤销／策略与质量失效、超过30位时间加权分子、修订移设备／移日期及日周期传播、有限授权／scale／映射／能力／窗口拒绝、结果与回执故障全回滚、并发旧快照保护、SQL形状与不可变权限。

首轮PG新夹具将小时作为修订订阅粒度，被既有日／周／月约束拒绝；调整为真实受支持的日周期验证，未扩大调度能力或放宽校验。最终HTTP、守卫、ASCII、密钥扫描、Git提交及运行SHA见检查点 artifacts/formal-checkpoints/gauge-persistence.json 和agent收尾。仅专用本机随机合同库；没有业务库操作、依赖变化或演示布局变化，不重复不变六场景UI验收。
