# 阶段2：服务资源快照与依据追溯

日期：2026-11-10。承接[阶段1基线](../20-specs/110-site-service-data-baseline.md)和[五批次计划](../70-workplan/60-site-service-batches.md)。本地展示已实现，真实服务来源尚未接入；没有将资源设备转换为已确认服务。

## 页面组织

复用 `/customer-use`，名称保持“客户使用”。默认服务资源，省级展示站址、铁塔设施、客户设备及地市资源；市级展示本市入驻品牌结构。品牌是快照分类，不是具体客户实体数量。地域及品牌约束全页，入驻家数、搜索和分页只约束明细。

单站使用既有侧栏，列入驻品牌、资源编码／规格／归属、服务依据缺口及快照版本；可进入既有站址档案。五类服务目录只作依据状态，不创建五个专页，不假定所有站都交付五类服务。缺少实际客户、订单、交付、有效期及变更时，不显示已确认在服数和期间增减，也不制造大批缺失案件。

原入驻／共享／通信用量在 `section=legacy` 完整保留。旧带周期、业务指标等参数的链接仍进入原分析；原三个锚点也能定位原内容。共享、用量别名路由显式补入原分析模式，重复参数仍保留并由目标页拒绝。没有改写历史报告或核验事件，六个待迁移入口标记保持。

## 数据和共用样式

`domains/site-registry/service-resource-rules.ts` 只汇总已观测站址及物理资源，按资源标识去重并拒绝跨站冲突身份，保留市级未归属桶。品牌去重不解释为客户实体去重。确认服务与变更字段保持空值，五类来源保持未接入。

`customer-use/resource-model.ts` 复用固定演示站址及 `resourceGraph`，固定同一来源版本与18时快照。全省1080站、5400项铁塔设施、3902台客户设备为合成演示，不是实际交付结果。品牌筛选选择站址集合，集合内共用设施只算一次，不按客户复制；设备规格也不是合同服务配置。仅向当前可见页下发详细证据，汇总使用完整授权演示范围。

复用官方设计系统的 PanelCard、DataTable、Dialog、Button、Select、Icon、Pagination，以及既有 SiteAnalysisWorkspace、AnalysisSummary 和 AnalysisOverview。共用概况行支持省略进度条，只有可解释的区域占比／品牌站址覆盖才使用进度条；设施数量不伪装完成率。没有新建CSS系统、全局令牌覆盖或并行组件。

没有DDL、依赖、正式接口、权限、生产配置、计价或结算变更。正式预览关闭时，新旧两种模式均不回退演示数据。

## 验证

- 869项应用单测通过；新增5项覆盖省市核对、物理去重、未归属、来源空值、局部筛选／分页、品牌范围和旧链接兼容。
- 64项HTTP检查通过，包含新入口、原别名、非法及重复查询、正式环境不泄露演示数据。
- Next生产构建及类型检查通过。最终服务仍在本机63333端口。
- 浏览器23组检查覆盖省市下钻／返回、品牌全局筛选、实时查询／重置、家数筛选、每页数量／第二页证据、侧栏切换／关闭、站址档案、原分析及旧锚点、390／475／984／1440宽度与明暗模式、既有监测进度条回归；无页面横向溢出或运行错误。证据位于 `artifacts/service-resources-qa/`，浏览器恢复全省、浅色及默认视口。

尚未实现真实服务项目来源接收、正式存储、有效期配置版本和变更统计，不能将以上快照测试作为阶段1全部真实业务场景验收。阶段3–5不在本次实现范围。
