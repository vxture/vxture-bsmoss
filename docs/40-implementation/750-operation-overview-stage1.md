# 运行总览提升首批

2026-11-04，用户确认七板块方案后执行首批。规格见[门户信息结构](../20-specs/50-information-architecture.md)。本次只优化已有数据与业务链接，不将核验人工闭环或正式接入记为完成。

## 实现

- 删除与header重复的大标题、决策分析按钮和快捷工作区；保留可访问的h1，外边距沿用DS 24px，不增加全局样式或依赖。
- 顶部陕西省／地市／县联动，URL仅接受city与county，市变更清空县；重复参数、非法省市县组合和未知参数显示无效范围，其他运行错误正常抛出。预览关闭不加载合成数据或输出数字。
- 同一范围用于资源、三域摘要、重点站址、趋势、运营商、地市与所有业务下钻。全日用量00:00–24:00和18:00状态分开；刷新读取同版来源，不以当前电脑时间推进数据。
- 资源读数进入台账、服务关系和共享筛选；关注数字定位本页重点区。窄屏以一张官方MetricListCard收拢四项资源，桌面使用MetricGrid。
- 运行参数增加既有物理站级备用供电和温度≥35°C数量，复用原场景数据，不从状态推导设备故障。运行汇总遍历完整选中站群，不依赖地图1500点截断。
- 重点站址前置，沿用状态／时段流量排序并过滤正常项，站名进入同范围运行档案；负载用进度条。当前仍是运行状态观察，不是用量核验待办，也没有虚构持续时长和原因。
- 流量／通话／短信同步联动24小时趋势、峰值、单位、运营商用量、占比、排序与进度条；只在同一指标内计算占比。无站址时显示空态，不绘零量峰值或空运营商结构。
- 地市比较支持负载／接通率切换，地市进入业务台账；首页不增加地图入口。本期报告沿用同范围用量报告入口，不宣称归档或发布。

## 验证与后续

新增4项数据契约测试：省市守恒、县级台账／专题对账、固定窗口及空县、非法范围拒绝；与既有独立分析5项共9项通过。初次测试误引用registry.total，改为实际summary.sites后通过。

HTTP回归发现4项历史文案断言仍要求“决策大屏”和“核验场景样例”，首页还要求已移除地图链接；同步既定业务名称和入口规则，补县级与无效范围断言，完整30项通过。首轮失败未作为验收成功。生产构建含类型检查、编号文档与ASCII／diff检查及最终浏览器证据见本轮记忆、tmp/overview-stage1-*和artifacts/overview-stage1-qa。
