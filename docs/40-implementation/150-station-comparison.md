# 多站对比与默认标准地图

2026-11-02。本批继续完善陕西客户演示，未修改数据库、依赖或正式接入路径。

## 实现

- 新增 comparison-rules 纯规则，统一 1–4 个唯一站点 ID 校验、上下文指纹与指标显示单位。
- 演示服务复用 queryStation，按同一地市／区县／选区／运营商／小时返回有序站点；越界或无服务返回不可用占位，不返回档案。
- 新增只读 `/api/product-preview/compare`，受原演示开关控制、参数白名单与长度限制，响应 no-store。
- Zustand 管理有序对比清单和浮窗；支持加入、去重、上限、移除、基准重排、关闭保留、地域／选区变更清空及 URL 恢复。
- 对比浮窗并列表格覆盖三类 8 项指标，状态／供电作为站点摘要；首站作基准，差值可隐藏，比率用百分点。
- ECharts 多线趋势可切换 8 项指标，点击图表区域联动统一小时；空电耗不连接成零值。
- 地图已选站点显示对应列色与序号；图层保持全幅，只改变相机 padding。地图点位、候选检索和单站详情均可加入。
- 用户追加要求：标准地图作为默认，Esri 影像改为点击卫星时才注册图源与图层，避免首次进入加载影像瓦片。

## 验证

新增 7 项行为测试，总计 276 单测通过；覆盖 ID 上限／重复／伪造参数、共同口径、范围隔离、无服务占位、检索与镜头独立、未知值、清单生命周期和镜头空间。
9 项 HTTP 测试（8 子项＋父项）通过，包括演示关闭时 404、同口径计数、选区隔离及错误参数拒绝。
浏览器已验证候选加入、四站上限、移除、精确检索、基准重排、运营商不可用／未分摊、进入单站与返回对比，以及统一小时和趋势指标切换。
最终生产构建、双层类型检查、文档编号／交付／SCA一致性／30表静态镜像守卫通过。
SCA一致性只核验扫描配置，未在本批执行在线漏洞扫描、容器镜像或实库测试。

浏览器最终实测：

- 1440×900 四站对比完整展示表格、趋势与候选，浮窗内容纵向溢出为 0；地图容器仍为 1440×900，表头无全局白底污染。
- 390×844 浮窗宽 327px、左 51px，页面宽高无溢出；四站表格内部横向滚动，页面本身不横滚。
- 真实点击多线图将 17 时切至 12 时，表格／时间轴联动；真实点击地图异常点加入第四站，状态及备用供电一致。
- 刷新恢复有序清单、运营商、选区与小时；关闭保留、站点下钻与返回对比已验证。
- 默认标准地图按钮激活且显示 OpenStreetMap 署名；手动切卫星出现 Esri 署名，切回标准恢复，控制台无错误。
