# 正式分析工作台与账户显示配置

接续 dd1f9b1，设计见 [222](../30-design/design_bsmoss_222_authorized-analysis-workspace.md)。本包完成 I11 的正式三类分析及本人显示偏好纵向切片，管理员模板发布、角色层级配置、I08 对象分布及分层规模仍待推进。

## 实现与边界

新增 views/analysis 纯规则、store 端口、PgAnalysisStore、独立授权门面和实际 RP 组合根，开放 /analysis 与 /api/analysis。正式根入口进入分析，preview 开关开启时仍进入陕西地图；没有改地图默认选站、底图、筛选或费用范围。

服务端固定 analysis:default 指向 page 模板，客户端只传分析时间，不接收来源、映射、租户或用户身份。每份查询在一个 REPEATABLE READ 事务读取模板、本人偏好及全部指标；绑定支持单对象聚合、受审区域汇总和未接入。三类章节、周期卡片、最近七个自然周期趋势与明细、设备状态时长分布、温度摘要和完整精确依据已实现。SQL／摘要损坏不转换成缺数；未接入、未发布、缺数、真实零、依据不可用及过期分别展示。

所有来源、站址、服务、设备、指标及实际依赖范围由正式授权裁剪；未授权面板不返回绑定或值，隐藏面板只返回经过对象授权的配置目录，不读取测量时序。区域直接比率按真实输入模式检查必要指标，不把未使用的分子分母指标强加到直接比率授权。物理站参数仍需独立开关，电耗不分摊。返回前复查本人身份、有效期、权益、权限与实际作用范围。

个人偏好仅显隐、顺序、单位、粒度和小数位，按租户／可信 subject／模板版本追加保存。CAS、唯一 commandId、同命令历史回执与当前 head 分开，重置也追加版本；旧命令不退回当前配置。并发 RR 快照在锁等待前建立时，以有限次数重试重新取得快照，最终只插入一份同命令回执或返回版本冲突。首次保存对模板选择加共享锁，末次撤权或 SQL 故障与偏好写入一并回滚。

既有 user_preference 表增加应用摘要、数据库 JSONB 摘要和真实 session_user。invoker／固定 search_path 触发器核对模板及租户／连续修订／原 expectedRevision，捕获数据库摘要、actor 和时间并禁止改删清空；按 subject／模板版本的命令唯一索引约束重放。总计仍 59 表，DDL 和 Prisma 同步，仅更新新产品空库基线，没有旧库升级或数据迁移。

HTTP 复用配置 Origin、16KiB 实际流、严格字段、no-store／nosniff／Vary Cookie；配置冲突明确 409，非法偏好 400，未知故障 503。界面保存不确定时保留原命令并锁定表单，允许原命令重试或刷新核对；明确 4xx 清理旧上下文。查询取消旧请求，切换时间不复用旧面板。显示换算使用 BigInt；仅趋势坐标及状态条宽度转成有界数值，精确表格保留原值，趋势不跨缺数或过期结果连线。
