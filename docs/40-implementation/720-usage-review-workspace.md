纯规则校验每小时窗口及前1–4周同星期同时槽，复用evaluateWave和同一双门槛；持续零量必须连续至少3个有效完整小时且各窗参考为正，缺数／服务无效／时间间隙打断，成员突降不重复列出。缺数优先于业务判断，基线不足独立，零基线不生成有限变化率。计数和计算分子使用十进制整数字符串及BigInt，图表仅作显示近似。

详情包括逐小时有效量、候选原值、四周原始参考／有效数量、质量与完成依据、相对／绝对门槛、来源／规则／基线／映射／服务关系版本及SHA256证据摘要。对照图明确单位并按时间正序展示；不可用当前量不进入图表，不补零。持续零量展示完整成员及合计参考，不能直接推断故障或业务停用。
