# 周期站址／区域排行与变化贡献

2026-11-02。沿用固定日／周／月及相邻完整基期，在同一筛选范围解释“哪些分项用量最高、哪些分项推动整体增减”。

## 口径

- 层级为市、县、物理站址；指标为流量、通话时长、短信，分别保留各自单位。当前选区与运营商过滤仍取交集，区域排行表示所选范围内的部分区域，不表示完整行政区。
- 本期用量排行按原始计数降序，增量来源按正变化降序、减量来源按负变化绝对值降序；同值按ID稳定排序。各取TOP 5，并保留其余分项合计及完整分项数量。
- 净变化＝全部正变化＋全部负变化；增／减／持平数量之和＝分项数量。TOP 5与其余合计能够还原完整变化，不把榜单误作全部来源。
- 拉动整体环比百分点＝分项变化／同范围基期总量×100；不采用分项变化／整体净变化，避免净变化为零或很小时失真。全范围基期为零时不给百分点。
- 月长不同，日均变化用精确分子`本期×基期天数−基期×本期天数`和分母`本期天数×基期天数`表示；日均贡献百分点分母为`基期总量×本期天数`。日均与总量的增减方向可能不同，分别排序与计数。
- 字节、变化分子、各类合计及尾项均由BigInt计算，序列化为十进制字符串；转换为显示单位和百分点时才使用浮点。比率不作为可加计数拆解；运营商电耗继续未分摊。

## 实施

新增period-contribution-rules纯规则与per-request collector，在已有当前期／基期样本遍历中收集单站三类计数；报告复用当前期遍历，不额外重复采集一个完整周期。分析前核对物理站址集合、分项计数与两期总量；不一致状态为evidence_mismatch，暂停输出。原环比不可比时贡献同样不可用。

comparison新增contribution，规则升为comparison-v2；日报／周月模板升为v3，报告摘要包含贡献结果。沿用period-comparison与reports接口及现有开关、参数白名单、失败状态、上下文隔离；无新增任意日期、客户端排名或基期参数。

环比分析内新增“环比概览／排行与贡献”切换，保留总量／日均共用控件和本期基期窗口。贡献面板提供市／县／站址、三业务指标、本期排行、净增减与百分点来源。报告内站址榜可定位单站，沿用现有地图小时，不把周期分析解释为单站面板已经切换到该历史周期。

离线HTML复用同一服务端结果，包含三级三指标、总量／日均、TOP 5、其余合计、原始计数与规则版本；折叠层级便于阅读，保留原6个顶层章节和动态转义。页面底图、品牌、底部信息及地图工具布局保持现有设计。
