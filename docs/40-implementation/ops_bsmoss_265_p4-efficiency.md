# P4 运行能效迁移

日期：2026-11-09。阶段编号采用用户最新指示，承载能力旧实施264保留历史编号。

## 目标与界面

/efficiency 以周期用电量、能耗强度和待核查站址为目标，迁移到 site-analysis 共用工作区，Launcher 纳入运行类并与标题共用 lightning 图标。顶部紧凑概况展示用电量、强度、关注、严重和已监测站址。能效关注包含高强度、正能耗零流量和能耗缺数；区域比较可切用电量或强度，支持地市/区县下钻及标题返回。单一周期图切换用电量与强度。

复用官方DS15及本站标题、48px操作行、32px控件、8/16px布局间距、4px滑块间距、图表虚线定位和置顶读数、表格/卡片、实时/回车搜索、重置、页容量、分页及连续侧栏。没有新增CSS、基础组件、依赖或全局token。侧栏显示周期、状态、原始电量/配对流量、全部流量、有效/缺失记录、周期序列及可展开小时原始记录。

## 规则与配置

新增纯 energyObservation / summarizeEnergy，先逐记录配对 energyWh 和 bytes，再汇总每站周期观测和等级。整数Wh/bytes计算，最终转kWh/GiB；不平均比值，缺失电量的流量不进入分母。已监测站址、可评估站址、记录完整度分别计数，站址不随小时数重复。正能耗且周期总流量为零单列待核查，强度不可评估；零电量和电量缺失区分。

复用MonitoringConfiguration和现有服务端权限/存储/API，无新增配置项、权限或DDL。全部概况、地域、序列、筛选、排序、行/卡片/详情及配色注入同一有效参数；同标签通知、跨标签、焦点和周期版本刷新复用 AnalysisParameterRefresh。配置页补充同时作用运行能效的说明。

全页统一时间窗口，时1点、日24小时、周/月实际日分组。共用分组与周期说明提取至domains/analysis/period，容量原分组导出保持兼容。默认日聚合，旧hour链接映射单小时；无记录日期定位最近有效窗口。周/月不虚构其它天。

物理总表不按运营商分摊；旧运营商筛选链接归一整站。明细搜索/筛选独立于概览范围，缺数允许与部分有效记录已有等级重叠。只给当前可见页附加序列及小时证据。历史/地图选区/旧供电专题链接保留；正式来源未接入继续待接入。没有节电收益、成本金额、因果结论、SLA或大模型分析。
