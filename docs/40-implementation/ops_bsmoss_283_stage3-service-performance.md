# 阶段3：服务履行与供电计量

日期：2026-11-10。属于[站址服务五批次](../70-workplan/60-site-service-batches.md)的**阶段3**，不与此前P1–P18改造批次混用。阶段1为口径基线，阶段2为服务资源；阶段4费用依据、阶段5收敛验收尚未开始。

## 目标与页面

沿用“客户使用”工作区，新增“服务履行”二级内容 `section=performance`，服务资源与原分析继续保留。无新增Launcher入口、独立电量域、维护页面或合同扣费功能。

省、市查看同一期间的整站区间电量、供电及电量记录覆盖、曾有蓄电池记录的站址。地市电量使用同一计量边界汇总，并可下钻及返回。时／日／周／月影响概况、地市、趋势、清单及单站记录，搜索和清单筛选仅改变明细。品牌与通信状态不参与物理电量归属，未提供品牌电量筛选。

单站侧栏展示区间电量、供电状态原始记录和来源版本；记录分页，允许进入已有站址档案。明确列出中断确认、保障、维护工单、实体表计绑定及客户计量归属待接入。蓄电池记录是起点状态，不能据小时采样推算中断开始、恢复、持续时间或客户受影响范围。

## 数据与计算

复用既有 `calendarSource` 和版本化演示日历；不将旧能效页单日采样重复冒充完整月数据。新工作区采用原已存在的日历物理样本，日／周／月分别在同一完整日历边界汇总。来源始终是合成演示，实体表计和真实服务证据没有因此接入。

`service-performance-rules.ts` 为纯规则，整站区间量使用整数字符串及BigInt累计；保留可靠零值与未接入的区别。相同身份幂等，冲突身份、重叠计量区间及未按边界裁剪的跨期电量拒绝累计。总表、分表和分摊没有混在同一集合，不向客户分配整站电量。展示层只对最终量换算kWh／MWh并保留两位小数。

确认影响规则独立接收已确认事件、受影响服务项目及有效区间：裁剪至查询期间、有效服务区间及截止时点，按事件去重，按站址和服务项目分别合并重叠区间。事件源或服务有效期未接入返回空值；已连接且无适用事件才为零；未确认或未映射事项不进入已确认影响。该规则仅以测试夹具验证，尚未与真实事件接收／存储接通，不把供电状态生成确认事件。

全省月度先实测约14秒，改用同版本既有 `physicalDaily` 精确汇总后模型约0.4秒，803520个小时样本的1829444652Wh保持一致。只为可见页生成小时证据；日汇总与逐小时证据已逐项核对。没有引入可跨工作区共享的业务缓存。

## 边界与阶段出口

当前能交付整站观测、省市汇总、原始记录追溯和确认影响的纯规则。客户分表／绑定／分摊、中断确认、应急保障及维护工单仍待来源接入；不输出履约合格率、客户电量、费用金额、扣费或结算判断。不将来源未接入制造为全量待办，也不将台账备注转换为维护工单。

复用官方DS及已有概况、周期、进度条、图表、表格、分页、侧栏和重置；没有并行样式组件、依赖、DDL、正式接口、权限、生产配置或外部部署变更。旧监测、能效、承载及历史报告和核验不改写，六个待迁移标记保留。
