# 回补与修订影响窗口核心

2026-11-02。I09内部第一批，不改变真实接入或上线状态。

新增`domains/aggregation/refresh-planning.ts`，沿用可信聚合日历规则：Asia/Shanghai、周一为周首、自然月。`planPeriodicRefresh`给出72小时扫描与生效期相交的已关闭日／周／月窗口；`planRevisionRefresh`给出可信受影响区间的全部相交自然窗口，包含更早历史修订，去重并稳定排序。半开区间结束点不多算下一日／月。

输入区间先排序归并，避免大量重复修订重复遍历长窗口。累计读数须由后续可信服务提供前后相邻两个受影响增量区间；核心不猜测读数间隔。旧、新对象变更分别规划，不静默遗漏旧范围。

显式时区、合法日历、有效范围、有限粒度、最多10000区间／候选窗口约束，超限抛错不截断。4项测试覆盖跨周月、闭合边界、有效期、闰年跨月、旧新修订、相邻累计区间、10000重复合并及错误／上限。

设计见`30-design/design_bsmoss_170_refresh-planning.md`。本批无任务表／租约／worker／定时器／outbox消费，不修改DDL；未执行数据库测试。任务持久化、可信目标枚举、权限重验、expectedRevision冲突重试、来源完成撤销传播仍待后续。不得把窗口规划的通过计为I09完成。
