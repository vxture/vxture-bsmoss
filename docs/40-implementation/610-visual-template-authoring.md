## 实现

/settings/templates 新增浏览器安全的编辑模型与实际React表单。按三类指标选择面板，支持标题、组件、单位、粒度、精度、显隐、上移／下移、增加／移除。稳定ID关联绑定，重排同步顺序；最多16面板、至少1面板。指标改变清原绑定为未接入；状态的设备数／时长使用表格；报告日周月全体粒度同步。来源／映射或受审汇总ID可显式填写，未接入不生成测量。

表单与高级JSON共用唯一内存草稿，修改清除原校验／候选／回执；非法结构保留原文并提示修复，未知字段不静默删弃。初次读取未发布编码后可新建三类未接入页面／报告草稿，既有版本仍不可原位修改。重新读取清除上一上下文的审阅依据；新增同步inFlight门闩避免异步调用重入。

校验按钮位于编辑区上方，桌面预览随页面滚动并在视窗内独立滚动，窄屏顺序展开。请求与503不确定命令期间整个表单／JSON锁定，沿原command重试；409清上下文。表单字典只提供配置选项，不代表来源已验收或账户拥有对象权限。服务端校验／真实归属和完整范围／独立权限／CAS／审计及末次授权继续沿224，无正式路由测试身份。
