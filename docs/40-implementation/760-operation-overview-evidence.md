## 确定性与性能

初次全省周／月计算约3.2／12.1秒。`prepare-overview-reports.mjs`在构建阶段从同一引擎生成三个不可变省级摘要，版本包含场景、日历、模板及比较规则；约10KB，提交入库以支持构建前开发／类型检查。运行时版本不匹配直接报错，不静默使用旧数据。地域子范围继续从同引擎计算。

生成脚本只使用合成数据，无数据库、凭据、网络或真实来源调用。摘要不会写正式报告账本。省级摘要与报告引擎精确对账测试覆盖全部三个周期及ID。优化后本地省级日／周／月首页汇总约576／515／485ms；这不代表11万站容量验收。
