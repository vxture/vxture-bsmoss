# 单站周期报告与波动证据导出

2026-11-02。五项持续交付中的第1项完成，限合成演示。

## 行为与口径

运行检查／经营统计选择日、周、月后，可以导出离线HTML。报告含六节：经营总量与日均环比、趋势与逐日明细、运营状态与运行参数、全部波动线索、逐小时原始计数、范围与规则引用。

页面只列前8条波动，导出保留全部达到门槛的小时，并保存全部小时三项业务的四个参考日期、四原值、中位数分子和变化分子。分母固定为2。原始字节及变化保持十进制整数串；显示换算不改变证据。电耗不按运营商摊分，比率合并分子分母。

规则沿用260记录：前四周同星期同小时中位数，15%相对门槛与1GiB／300秒／20条绝对门槛同时满足；零参考无百分比，参考不足不判断。自然周期环比与同星期参考分别计算。

## 代码与边界

`domains/map-demo/station-report-rules.ts`、`station-report-html.ts`与共享`station-period-display.ts`；service生成报告引用，页面和下载绑定相同引用。

`GET /api/product-preview/station/[id]/period/report?period=day|week|month&format=json|html`沿用站址／省市县／运营商／精确几何交集。严格白名单，越界404、非法400、过长413、演示关闭404。响应no-store／nosniff；HTML附件、静态内联SVG和CSS，不依赖脚本或网络，证据默认展开，打印可见。

引用为`DEMO-STATION-{PERIOD}-{sha256前20位}`，摘要绑定模板、分析快照和规范范围。镜头、地图小时与专题不改引用；站址、周期、运营商、范围或规则改变则重新绑定。报告仍为demo/draft，不是正式发布凭据。
