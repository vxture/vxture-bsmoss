# 塔服智判演示数据与查询优化

演示版使用固定陕西样本，覆盖 1,080 个站址、3,902 条服务关系及约 285 万条日用量事实。历史范围为 2024-11-01 至 2026-11-01（北京时间，右开），默认完整月份为 2026 年 10 月。首页服务健康分是演示站址在 18:00 的既有健康分平均值；用电变化用两个完整月份的日均值比较，避免月份天数影响。

构建时生成 118 个省市县首页摘要、590 个默认月份页面模型，以及按日、周、月、年和区县/运营商划分的服务汇总。用量使用整数，覆盖按站址标识去重，存量取期末。小时和非预生成查询沿用详情计算路径。演示数据打包进 BS-MOSS 镜像，作为只读文件；不引入数据库 DDL、实时来源或启动时生成。另附可查看与下载的示例报告和冻结规则。

线上演示由 `BSMOSS_DATA_MODE=demo` 启用，保留真实 OIDC；未登录页面进入登录入口，直接请求业务 API 返回 401。演示共享数据只读，本机 `BSMOSS_PRODUCT_PREVIEW=on` 继续提供原有预览工作区。标准健康检查、OIDC 回调和独立验签 Webhook 保留原路径。

`node --import tsx scripts/benchmark-demo.mjs` 测量读模型自身，不包含浏览器、登录和网络。一次本机结果：首页热读 P95 0.08ms，经营总览热读 P95 2.66ms，独立首次读取总览 31ms；原总览模型现场计算约 1.6–1.9s。未命中预计算、需要完整历史的首次读取约 4.4s，仍需单独优化并验证查询分页开销。

后续走查：运行监测按服务端分页传送站址和对应小时证据，概览、筛选计数仍使用完整范围。默认阈值下预生成 118 个区域首页；自定义阈值按配置和时段复用同一站址的判读结果。省级响应从约 3.57 MB 降至约 0.45 MB；保留本机自定义阈值时热态约 200ms，默认阈值预计算路径约 58–76ms，第二页约 190–210ms。均为本机生产构建 HTTP 测量，未包含浏览器渲染和线上网络。

资源详情不再读取服务趋势汇总文件。示例资源详情首次约 1.7s，重复约 130ms；周期趋势首次仍约 3s，热态约 30ms。下一步可将时间汇总按粒度拆包，减少切到趋势时的一次性解压和解析。
