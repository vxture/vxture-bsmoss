## 业务结果

资源设备与服务关系两页复用DS承载面板，可切全站或运营商、点击资源查看规格与引用、由共用设施反查服务关系。局部承载选择不修改全站档案和原调查；刷新恢复URL初始范围。资料来源页展示资源模型版本，既有经营量、24个月固定同群和报告引擎不变。

## 来源边界

当前固定合成清单不证明历史合同、安装、投运或拆除时间；站址、服务关系及设备有效起止均为null/unknown，显示待来源核实。原合成投运字段改称模型投运日期，不用于新增退出归因。

原清单把整站状态套用到无线设备，并以站级供电/温度推断设备状态。本轮全部设备改为未采集、中性徽章；供电、电耗和温度单列为站级关联观测，不冒充设备独立遥测或巡检。时点切换同步观测，刷新不推进固定来源水位。
