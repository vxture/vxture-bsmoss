# 多边形圈选分析

2026-11-02。在矩形与圆形基础上增加自定义站群观察范围，面向陕西客户合成演示。

## 实施与口径

- Selection增加PolygonSelection，geometry纯规则负责解析、验证、规范序列化、外接边界和点在多边形内判断。
- 参数为`selection=polygon:经度,纬度;经度,纬度;...`。支持3–32个顶点的简单凹／凸多边形，不含孔洞；边界与顶点包含。
- WGS84经纬度保留6位小数，按经纬度平面线段判断范围，不解释为无线覆盖或测量精度。纬度限±85°，经度跨度小于180°，不支持跨日期变更线。
- 拒绝非有限／越界坐标、重复点、相邻共线、坍缩／极小面积、自交及自接触。允许末尾重复首点作为闭合标记；最大2048字符。
- 统一逆时针方向与最小坐标起点；同一环的起点、绕向、闭合写法和6位精度内差异得到相同上下文和日报引用。
- 地图绘制条增加多边形：逐点添加、首点大圆标记、临时连线与有效闭合范围预览；撤销、完成、点首点闭合、取消，支持Enter／Backspace／Escape。
- 无效完成保留编辑状态与原已提交选区；取消恢复原分析，切换形状清空未提交顶点。完成新范围清除旧对比清单，刷新恢复范围与面板。
- 相机使用外接矩形，站点筛选使用真实多边形。行政区／运营商／检索交集、三类指标、专题、单站、对比、核查、日报与HTML下载继续复用同一选择规则。
- 区域面板仅圆形显示半径表单，多边形显示顶点数。标题、全幅地图、底部同行布局、四图标及默认标准底图保持现有设计。
