# 经营分析第二批：运营商贡献与站群对标

2026-11-05。用户授权继续第二批P2，按[设计236](../30-design/design_bsmoss_236_business-history.md)实施BA02，此处P2为批次称呼，与退役影响优先级无关。

## 实现

同一经营分析页面增加运营商分析和站群对标，与区域视角共用时间、区域、业务指标、运营商与资源条件。运营商结构包含份额、份额变化、同比增减、贡献百分点及正负增减量核对；站群支持业务场景、站型、互斥共享组、总量/单站日均/中位数/四分位、用量和增长分布、成员排序与分页、单站下钻和返回。

规则保持纯函数，资源筛选及参数校验由服务执行。站型与台账复用规则；流量BigInt字符串，分页/排序在服务端，逐站聚合不传浏览器。默认省级摘要构建生成并可在显示条件变化时复用。模型v2不改变calendar-v3测量值。

增长贡献为对象增减量÷范围上年同期总量，以百分点表示，保留正负抵消；份额变化也为百分点。零量独立、分位边界不拆并列、日均同比±10%分组、缺失及零基期不可比。分布分层只影响成员清单，页面提示完整范围；资源条件影响所有汇总。

固定同群无历史新增/退出证据，不虚构生命周期归因。正式OIDC及API隔离保持，仅显式preview开启；无新依赖/DDL/权限/真实来源，无push/外部部署/生产上线。BA03单站同类画像及核验证据、BA04跨域与历史报告继续待办。
