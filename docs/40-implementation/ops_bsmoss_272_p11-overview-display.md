# P11 总览设置迁入配置管理

## 定位与范围

按用户纠正，总览设置属于配置管理，统一在/settings/overview维护。移除先前首页侧栏方案。选择指标、显示顺序和合法单位仍只影响当前浏览器首页；延用24项指标及原口径、每类2–4项、原localStorage键及版本，不修改阈值、权限、测量或报告内容。

## 页面与交互

- 配置管理导航及管理总览提供“总览设置”，页面使用管理壳、统一标题、内容卡及编辑器。经营服务、运营状态、运行参数使用共用分段组切换。
- 同一个指标列表完成选择、单位和上下排序，选中项按当前顺序前置，不重复提供两套清单。长口径说明仅作为指标名称悬停提示。
- 保存后更新总览三类摘要；恢复默认只修改草稿，仍需保存。离开未保存的编辑页不修改原偏好。
- 首页标题区、指标明细与用户菜单移除独立设置动作。主题、密度、字号继续使用原外观偏好；业务页通过已有全局配置管理入口访问。
- 原/preferences/overview兼容跳转至/settings/overview，首页#overview-display旧锚点也转入相同配置页。个人显示设置无地域统计条件，不携带任务、报告或地域参数。
- 复用官方DS15和site-analysis的32px控件、14px字体、48px操作行及8/16px组间距；指标列表适配1/2/3列，无新增业务CSS或基础控件。

## 数据边界

原浏览器存储bsmoss.overview.display.v1不迁移不清理。载入完成前不允许保存。无效偏好以默认值显示但不自动覆盖原值；写入失败保留草稿，不宣称成功。跨标签页继续同步已保存值，未保存草稿不因外部保存被静默覆盖。仅显式演示模式开放原合成总览及其显示设置；正式未接入页不加载偏好编辑器。不新增接口、后台存储或权限。
