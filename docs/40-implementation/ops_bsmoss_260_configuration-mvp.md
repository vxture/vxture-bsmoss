# 配置管理 MVP：来源与映射

2026-11-07。遵循用户“先做MVP”的最新指令，停止继续扩展跨版本治理和审批功能。本批只完成用户能操作的两条流程。

## 页面与操作

/settings/sources：列表、名称／编码检索、状态筛选、详情；新增来源名称／编码／业务类别／接入方式／状态／备注，编辑和启停，保存后可重新打开或刷新查看。来源编码保存后固定。来源显示关联映射条数，直接进入对象映射。

/settings/mappings：列表、来源／状态筛选、对象／站址检索、分页和详情；新增或编辑来源、对象类型／外部编码、关联站址、状态／备注。站址沿用现有陕西1080座台账，可按名称／编码／区县检索，最多先列50座，未选择时不默认关联。来源对象以来源＋对象类型＋外部编码唯一，已有关系提示编辑原记录。三点菜单统一提供编辑、启停。

沿用官方DS ShellPageContainer／PageHeading／DataTable／Pagination／Drawer／ActionMenu／表单组件，无新增依赖和样式原语。详情和编辑同一抽屉，保存成功返回可查看状态。检索为空有空态，失败保留草稿，取消和关闭不写入。

## 保存范围

明确的产品预览开关开启才进入本机配置工作台，header原演示tag保留；页面不重复“演示”标题。标题区标明“本机保存 · 当前浏览器”，成功提示明确本机。localStorage独立bsmoss-preview-configuration-v1保存来源和映射同一份配置，两页共用，初次提供3来源／12映射样例；不写生产数据库、不发接收／分析任务、不改变业务统计数据。

关闭预览开关后仍走原正式身份和权限门槛，正式管理GET／POST方法限制不变。本批不接外部接口、不存凭据，不把启用状态称连接成功，不伪装为正式配置提交。来源启停不级联改变映射，以保留显式配置。

保存前重读本机记录并核对原修改时间，拒绝已经发生变化的旧编辑；正常浏览器storage事件同步页面。单次浏览器读改写不是跨客户端或并发事务，不声称多人协同数据库。存储失败不提示成功；存储内容损坏不静默覆盖。清除浏览器数据会丢失本机修改，正式持久化与真实接入留后续。

## 验证

规则测试覆盖创建／编辑／序列化重读／启停／关联保持、重复编码／重复对象／无效来源站址、旧编辑与损坏记录拒绝。HTTP烟测覆盖预览两页开放及正式接口不借用身份、关闭开关仍有原门槛。真实预览路由的独立无头浏览器检查来源新增编辑停用刷新重读、映射检索选择新增编辑及刷新、重复提示、两页关联计数、旧编辑冲突、保存失败保留草稿、两页与表单三种宽度。最终通过日志／截图／版本见artifacts/formal-checkpoints/configuration-mvp.json，不把验证计划当已通过。

最初类型检查发现非DS图标名已移除；首轮浏览器发现来源编码辅助文字影响可访问名称，第二轮发现备注文本影响详情字段名称，已显式补名称后重验。仅重跑本批相关规则／types／构建／HTTP与浏览器，不扩展数据库合同或审批基础。

无DDL、Prisma、权限或正式接口写入变更，无push／外部上线。下一步以用户体验这两条已完成流程后的反馈为准，不再自动接续259底层治理任务。
