# 全站页面与二级页面留白、标题和板块整理

## 范围与决定

用户授权将运行总览已确认的留白逻辑推广至全部页面，包括二级页面。本批处理布局与可读性，不推进B01核验写入闭环或正式上线状态。

- 共享`product-page-inset`承载DS基础space-lg和水平增量；48rem起增加space-md，80rem起增加space-xl。标准密度为水平24／40／56px，垂直24px；不修改DS全局token。产品局部CSS变量仅组合现有DS间距，组件内距仍由组件负责。
- 覆盖运行总览、决策分析、站址台账／服务关系、六层站址档案、容量质量、运行能效、运营商用量、周期报告、核验列表／证据、配置中心／显示设置、模板及两类任务工作区、正式分析／报告、地图指标辅助页和版权页。
- 保持全宽，移除旧模板／任务工作区独立最大宽度。旧报告／任务列表和详情改共享外留白＋内部space-lg间隔，详情不再叠加外边距。旧工作区字号收敛为DS正文、小正文、两级标题；继承门户字体及背景。
- 补齐业务分析、台账和核验的可见常态H1，保持标题、地域和时间信息及操作组可换行。无效筛选及未接入分支同样保留标题。
- 接入未开放／未登录工作区采用共同的官方ShellPageContainer、ViewHeader、PanelCard和Button组合；原来源、身份和权限门槛保持。
- 业务页窄屏摘要及档案资源／运行卡使用MetricRowsCard业务组合，内部仍为官方PanelCard、PanelList、PanelItem、LabeledValue；长数字和单位完整显示。桌面MetricGrid不改。
- 档案独立滚动正文隐藏原生滚动条、保留滚动及可聚焦region，解决标题区和正文因滚动条相差约15px；同级页面留白一致。台账侧栏浮动效果、收起后内容扩展、表内横滚保留。
- 版权辅助页改官方标题和卡片；指标辅助页只共享外留白，旧样式继续局部隔离。地图画布、header、launcher和地图浮层不使用页面内距。
