# 确定性日报与下载

2026-11-02。继续确定性业务，退服影响分析保持 P2。仅扩展陕西合成演示；费用、真实来源、调度、发布及部署范围不变。

## 实现

- `report-rules.ts` 复用全天运营商计量，计算 24 小时分布、站群同时忙时、小时比率极值、温度样本及备用供电观测、全天重点站址。
- 服务端复用地图站群筛选，排序站址后生成稳定报告引用；小时／bbox／专题不改变日报内容。
- `/api/product-preview/reports` 返回 JSON 或 attachment HTML，演示开关、字段白名单、日期及下载格式校验。
- `report-html.ts` 是代码生成的独立报告模板，动态文本转义，含三类章节、运营商表、逐小时表、依据和同一报告标识。
- `report-panel.tsx` 提供独立浮窗、三类概览、趋势定位、重点站址下钻、分项／证据章节和下载。
- 状态库／URL 互斥与相机 padding 扩展，地图容器保持全幅，个人显示偏好不改变报告模板。

报告固定样例日 2026-10-25，状态 demo / draft；备用供电是站时样本，不是持续时长或退服分析。
温度是物理站址小时样本均值；无基期不计算环比同比；单运营商电耗未知。详见地图规格最新章节。
