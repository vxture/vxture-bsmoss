# 客户使用、共享与用量整合

## 目标与页面

用户确认经营域入口收敛。以 `/customer-use`“客户使用”为唯一入口，连续展示入驻、共享和通信业务用量，沿用 DS15 与 site-analysis 共用组件，不增加三套整页页签。长期历史同比、站群对标继续留在经营分析。

顶部资源概况为入驻站址、关联设备、共享站址及共享率，业务概况为流量、通话、接通和短信，显示单位自适应、保留两位小数。入驻结构压缩为单家、双家、三家以上的数量和比例，点击只筛选下方明细。运营商与区域使用一对比较卡片，共用基础行高规则；运营商保留可配置名称、标识和站址、设备数量。区域比较可选入驻站址、共享率、业务用量，支持下钻和返回上级。

一处业务指标选择同时控制运营商比较、区域用量、趋势和站址用量列。明细列顺序为序号、站址、区域、入驻运营商与家数、设备、当前业务用量、操作。保留列表／卡片、实时与回车搜索、每页容量和分页。连续非模态侧栏合并四类业务量、运营商明细、趋势、原始计数与关联设备，不再增加独立指标选择器。

## 数据口径

- 地域和运营商约束全页；搜索、结构分组与精确家数只影响明细，上方概况和比较分母保持稳定。
- 运营商筛选后，入驻家数仍按全站全部运营商计算；业务计数与关联设备按所选运营商计算。共用设备按设备标识去重，跨运营商资源数量不能直接相加。
- 资源和入驻是固定快照；业务用量使用原有合成历史来源，按时、日、周、月真实聚合。页面分别标注资源快照和业务周期，资源数字不冒充历史入退驻记录。
- 整数计数、报告来源与历史计量模型保持。只有当前可见页携带逐站业务证据，不把全部历史序列发送到浏览器。

## 入口兼容与清理

Launcher 与导航删除单独的共享利用、业务用量入口。原 `/sharing` 和普通 `/operator-usage` 307 到客户使用，完整保留查询参数和重复值，由目标继续严格校验。地图空间选择和显式历史调查保留旧专用分支；报告历史文件继续可读，新生成报告的分析链接使用规范地址。调查返回上下文在筛选和指标切换中保留。

删除无消费者的两套旧工作区、概览和客户专用旧样式；报告仍使用的业务模型、显示规则和共享领域规则保留。正式未接入时只显示未接入状态，不回退到合成数据。
