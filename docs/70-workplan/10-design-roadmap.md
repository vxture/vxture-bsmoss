# 当前实施路线 V0.2

本阶段仅周期性用量分析。费用从当前交付移除，保留领域扩展。

| 阶段 | 工作包 | 出口条件 |
|---|---|---|
| M0 口径与来源 | 来源样例、站址/主体映射、指标字典、原生粒度 | 通话及流量含义、单位与窗口可验证 |
| M1 数据底座 | C1/C2/C3、范围权限、实体/服务关系/证据模型、适配器与 CI | 数据库约束及身份隔离测试通过 |
| M2 计量聚合 | 首个来源、重放、复位、迟到、质量、15 分钟/小时/日汇总 | 原生粒度不被虚构细化，重算不重复计量 |
| M3 周期分析 | 总览、趋势、主体与区域比较、日报/周报/月报 | 口径一致，缺数与零量区分，修订可追踪 |
| M4 异常及扩围 | 忙时、历史基线、原因核验、可选指标、导出、容量演练 | 权限与负载验收，分析引用证据 |

下一批先实现指标字典与有效期主数据，再实现版本化聚合，后台周期任务及门户查询。
调度建议与指标细则见 [周期用量设计](../20-specs/60-periodic-usage-analysis.md)。

## 待确认与默认处理

| 信息 | 当前设计处理 |
|---|---|
| 11 万对象是站址还是逻辑基站/小区 | 暂按站址规划，接入时校验 |
| 来源接口、脱敏样例、上报频率 | 原生粒度入库，只有可精确对齐数据才进入 15 分钟层 |
| 通话统计点、VoLTE/VoNR 与数据重叠、累计/增量 | 指标字典明确；未知语义隔离 |
| 其他主体实体、服务关系与有效期 | 以具体实体映射，不均摊待归属量 |
| 短信、电表、PRB 和连接数可用性 | 可选指标不阻塞核心闭环 |
| 保留期、补传时延、并发与部署条件 | 初始 72 小时滚动回补；保留期另行确认 |

费用扩展不依赖本阶段确认费率或合同，未来另立实施阶段。


## V0.3 增补

M0 增加三类指标目录与来源能力核验；M1 增加版本化指标定义、依赖、
测量类型与模板配置；M2 根据指标语义实现求和、加权、分子分母和状态时长聚合；
M3 建立三类可配置面板及日/周/月报告；M4 扩充跨类关联分析。
先用通话/流量/短信、利用率/接通率、电耗/设备状态验证三类完整路径，
仅有真实可用来源的指标才能标记已支持。
