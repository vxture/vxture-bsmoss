# Operator logo presets

The active defaults are 512 x 512 transparent PNG marks, centered with equal
32px canvas insets, preserving each mark's aspect ratio. The .svg files are
square wrappers embedding the matching PNG; they are not vector originals.
Uploaded custom logos remain separately stored through operator configuration.

Other. Existing transparent Mobile and Unicom artwork was preserved.

https://zh.wikipedia.org/wiki/File:CBN_CHINA.png

not modified. Defaults are local assets; display makes no third-party requests.
